# カテゴリの編集

記事のフロントマターには、全言語共通のカテゴリ識別子を指定します。

```yaml
categories: ["mathematics", "statistics"]
```

表示名は `content/categories/<識別子>/_index.<言語>.md` の `title` で管理します。日本語は `_index.md` です。たとえば `mathematics` は日本語で「数学」、英語で「Mathematics」、韓国語で「수학」と表示されます。

- 既存カテゴリは `content/categories/` のフォルダー名から選びます。同じ意味の識別子を追加しないでください。
- 新しいカテゴリを追加するときは、使用する各言語の表示名も定義します。製品名や一般的な略語は翻訳せず使用できます。
- `aliases` は過去のカテゴリURLからの転送先を維持するための設定です。表示名を調整する場合も残してください。
- 表示名を変更しても識別子は変えず、カテゴリURLと記事の分類を維持します。
