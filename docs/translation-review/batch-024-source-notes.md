## 数学・説明で確認した問題

- 孫子の23は最小非負解であり、すべての整数解は105を周期に持つ。128も正の解である。「解は23」だけで整数解が一つと受け取られないよう説明する。
- 整数CRTの存在の構成だけでなく、任意の二解の差が各法の倍数で、法が対ごとに互いに素なら積の倍数となる一意性も示す。単なる全法のgcd=1と対ごとの互いに素を区別する。
- 多項式で「体上に共通の根がない」と「gcdが定数」は一般には同値ではない。有理数体で両方を同じ `x^2+1` とすれば有理根はないがgcdはその2次式。これは初等的な符号と同一多項式のgcdによる厳密な反例で、CASを実行したとはしない。根の言い換えには代数閉包が必要。補間では異なる評価点と次数上限を明記する。
- RNSは法の積に対する剰余を表す。整数として復元する範囲が必要で、範囲を超える加算・乗算は折り返す。チャンネル間の桁上がりが不要であっても、各チャンネル内の2進演算まで桁上がりがないわけではない。比較・除算・変換の費用も区別する。
- RSA-CRTの指数だけを「秘密鍵の代わり」としない。相異なる奇素数、正しい鍵の条件、p/qとCRT係数も秘密鍵の一部であること、整数代表元とメッセージ符号化を分ける必要がある。約4倍は古典的な乗算・指数ビット長・再構成費用のモデル依存の見積もりで、実測や全環境の保証ではない。
- 英訳にはCrypto/graphyの途中から暗号資産記事へ飛ぶリンク、Euclide/anの途中から伝記へ飛ぶリンクがある。言語別の適切な記事と一次資料へ整理する。
