## Findings and changes

- The article title promised a recipe, but the body contained only the herb list. Expanded all 13 versions with the January 7 Jinjitsu custom, the seven spring herbs, a basic recipe for two to three servings, and safe preparation context.
- Clarified that this is a cultural food custom expressing a wish for health, not a disease-prevention or treatment claim.
- Standardized the ambiguous Hotokenoza entry: in the traditional spring-seven list it is ko-onitabirako (*Lapsanastrum apogonoides*). Added the scientific name and removed the unrelated Java-language links from the German and French versions.
- Added a wild-plant warning based on Japan’s Environment Ministry: look-alike plants can be toxic; use a food-labelled set or have foraged plants confirmed by a qualified expert.
- Added a two-to-three-serving recipe (75 g rice, 600 mL water, a commercially sold herb pack, salt; simmer 30–40 minutes) based on the cited Japanese recipe source. Pack contents may vary; follow product and rice-cooker directions.
- Removed the duplicate false 2026-09-24 date, retained the existing 2024-01-06 publication date, set `lastmod: 2026-11-23`, and changed the unrelated IT category to the existing lifestyle category.
