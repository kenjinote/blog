## 原文と英訳で確認した問題

- 「総和が1になる分布では、観測したすべての金額で交換が有利になる分布はない」という断定は、有限期待値という条件が抜けている。正規化と有限平均は別の条件である。
- 「例外は無限の金額を均等に割り当てる非正則な分布だけ」という断定も誤り。適切な確率分布で、各可能観測額に対する相手の条件付き期待額が自分の額を上回る例がある。
- 変数が場合によって異なる値を取ること自体は、確率変数の誤用ではない。未観測の大小の確率と、金額を条件とする確率を区別する必要がある。固定した少額を条件にした説明と、その少額自体がランダムなモデルも分ける。
- 交換比率の平均が5/4になる計算は成立する。しかし、それを条件付きの他方の金額や元の期待額へそのまま掛けることはできない。二回の交換の比率は互いに逆数で、独立ではない。
- 「金額が上がるほど倍額である確率は必ず下がる」は任意の事前分布では成立しない。有限予算は最上端の制約を与えるが、内側の事後確率の単調性までは与えない。
- 1万円を見て他方を半額・倍額それぞれ1/2とするには事前分布が必要。条件が合えば平均12,500円という計算自体は正しいが、利益の確実性は意味しない。
- 無限期待値を「論理の崩壊」とせず、非負変数の拡張期待値、符号付き差の未定義、積分可能性が必要な操作を区別する。無限サポートの分布でも、各実現額が無限大になるわけではない。
- 第1図の50%分岐は誤った推論であることを明示する必要がある。第2図は期待金額を50%ずつの円グラフで示しており、確率と金額の混同を招く。比較を明示する図へ改める。
