## 原文の訂正

- 正則性だけから領域全体で経路非依存になるという説明を、単連結性を含む十分条件へ訂正。
- 複素微分の極限は直線の方向だけでなく、複素平面内の任意の近づき方について同じであることを明確化。
- コーシー・リーマン方程式を無条件の必要十分条件とはせず、必要条件と、連続な1階偏導関数を仮定した十分条件に分けた。
- 積分を定義する曲線には区分的な滑らかさを明示。単連結領域では一般の閉曲線も扱う形にし、後の経路非依存性の証明で合成経路が自己交差しても矛盾しないようにした。
- F1=(u,-v) と F2=(v,u) の回転はそれぞれ -v_x-u_y と u_x-v_y。元の物理説明は同じ一方の方程式だけで両者が渦なしになるとしていたため訂正。発散が0であることと、循環が0であることを分けた。
- Greenの定理は正向きの区分的に滑らかな単純閉曲線と、閉領域の近傍でのC1仮定を明示。
- Goursatの説明から特定の年代・元の証明法への未確認の断定を外し、各点での複素微分可能性を仮定する数学的内容に集中。現代の三角形細分化の方法をGoursat本人の元の証明と同一視しない。
- 一点で微分可能なだけでは正則とは限らない。|z|²の原点での微分可能性と、近傍での非正則性を例に追加。
- 積分公式に正向き・曲線と内部での正則性・点aが内部にある条件を明示。曲線の内部と領域全体を混同しない説明に訂正。
- 穴があっても積分が必ず非零になるわけではない。反時計回りの単位円で1/zの積分は2πi、1/z²の積分は0という対比を追加。
- 自己リンクを除去し、数学的な一次資料を末尾に追加。重複dateは実際に使われていた後方の公開日を維持して整理。
