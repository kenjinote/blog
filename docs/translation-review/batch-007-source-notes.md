## 訂正

- 有限のテイラー多項式と無限のテイラー級数を区別。多項式と呼びながら無限に項を続けていた式を、次数nの有限式にした。
- 2階の係数は `P_n''(0)=2c₂` で決まる。高次項を含む一般の多項式について `P''(x)=2c₂` としていた誤りを訂正。
- 微分係数から級数を作ること、級数が収束すること、その和が元の関数に一致することを分けた。無限回微分可能という条件だけで等式を主張しない。
- 実数の指数・正弦・余弦の例は全実数で収束して関数に等しいこと、三角関数の角度はラジアンであることを明示。
- 収束半径は範囲そのものではなく中心からの距離を表す数Rとし、端点は別判定とした。`ln(1+x)` の半径1、x=1の条件収束、x=−1の発散を確認。
- 区間でC^(n+1)級という十分条件の下で、有限の多項式とラグランジュの剰余を追加。微分の上界から誤差を評価する方法を示した。
- `g(x)=exp(−1/x)`（x>0）、0（x≤0）は滑らかでも0での級数が元の関数を表さない例として追加。有限個の値を計算しただけで全階微分の性質を確認したとは扱わない。
- 振り子の等時性は小振幅近似内の結果であり、実際の周期は振幅依存であると訂正。
- Python `math` の内部が単純にテイラー級数を足すという断定と、チェビシェフ近似を単なる改良版とする表現を除去。CPythonのプラットフォームC数学ライブラリへの依存を公式文書で確認。
- Python例は0付近・少数項の学習用とした。計算アルゴリズムは維持し、`math.sin` の出力を「真の値」ではなく浮動小数点の比較値と明示。10項の打ち切り誤差上界1/21!と丸め誤差を区別。
- 関数のグラフをデータ構造のグラフ記事へ結ぶ誤リンクと自己リンクを除去。公開日は維持し、最終更新日を記録。

## 根拠

- [NIST DLMF §1.4(vi)](https://dlmf.nist.gov/1.4#vi): 実変数のテイラーの定理、C^(n+1)の仮定、ラグランジュ形と積分形の剰余。
- [MIT 18.100A Basic Analysis §4.3、§5.4](https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/mit18_100af20_basic_analysis.pdf): 級数の収束と元の関数への一致は別条件。Exercise 5.4.4は対数級数の端点、Exercise 5.4.11は上記の滑らかで非解析的な関数。
- [MIT 16.07 Lecture 24](https://ocw.mit.edu/courses/16-07-dynamics-fall-2009/c0c881f96f4ff4e21f082c88e8b015d6_MIT16_07F09_Lec24.pdf): 振り子の線形化は小振幅の近似。振幅による周期の補正も記載。
- [Python 3.12 math](https://docs.python.org/3.12/library/math.html): CPythonのmathは主にプラットフォームC数学関数のラッパー。特定の数値近似アルゴリズムを全環境へ一般化しない。
