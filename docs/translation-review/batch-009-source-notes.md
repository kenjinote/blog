## 原文で訂正した事項

- 任意の周期関数がすべての点で元の値へ収束するという説明を訂正。一周期内で有限分割した区間ごとのC1性と関数・導関数の有限な片側極限を十分条件として明示し、連続点・跳びの平均・周期の継ぎ目・ギブズ現象を説明した。
- 直流成分は a0 でなく a0/2。実数係数と複素係数の関係、両側級数の対称部分和を指定した。
- 周期を無限にする説明は直感的な橋渡しとし、極限・積分の交換の正当化を省いて一般の証明としない。
- 順変換の負号と逆変換の1/(2π)を一対の規約として明示。順変換の絶対可積分性、連続なfとf・F双方の絶対可積分性による反転の十分条件、Hzとrad/sを区別した。連続スペクトルの重みと単一の周期成分の振幅を混同しない。
- DFTを有限列の変換として定義し、逆DFTを追加。標本化周波数、ビン間隔、折り返し、スペクトル漏れを説明。FFTは同じDFTを効率よく計算する方法で、非可逆JPEGの基本方式はDCTと訂正した。
- Pythonは正の周波数を選ぶマスクで終わっていた。実数入力のrfft/rfftfreq、Nによる正規化、DCと偶数長ナイキストを除いた2倍、ピーク出力とプロットまで補った。窓なし・ビン一致の仮定を明示した。
- オイラーの公式を説明する記事へリンクを向け、原文の自己リンクとFFTリンクの重複を整理。公開日9月20日は維持して最終更新日を追加。
