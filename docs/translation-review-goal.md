# 全記事の翻訳校閲 goal

2026-10-24 に開始。

## 目標文

kenji.blog の全記事・全翻訳言語を対象に、優先指定の3記事から順に、原文と翻訳の意味・用語・数式・コード・リンクを照合し、確認できた不備を修正する。AIによる校閲と人による確認を区別し、確認日、原文と翻訳の版、確認範囲、根拠、残課題を台帳に記録する。未読・機械検査のみの翻訳を校閲済みにせず、全対象の校閲、検査、公開後確認を終えるまで継続する。

## 完了条件

- 原文を持つ各記事について、存在する全翻訳を本文全体まで読む。管理ページなど記事以外のページは別枠で集計する。
- 対応する原文の全体と意味・重要な条件・用語・数式・コード・リンクを照合する。
- 原文自体の誤りは、一次資料・再現可能な検査を用いて訂正し、その訂正を翻訳にも反映する。
- 修正不要の場合も、その判断の根拠と確認範囲を記録する。
- AI校閲記録には `reviewKind: ai` と制限事項を明記し、人による校閲済みと表示しない。
- 記録後に原文または翻訳が変わったものは再確認の対象とする。
- 実装・台帳・本文の検査を通し、公開後に確認して初めて当該バッチを完了とする。
- 全記事が完了するまで goal を complete にしない。

## 順序

1. `central-limit-theorem`（中心極限定理）×12翻訳言語
2. `cross-site-scripting-xss-csrf-security`（XSSとCSRF）×12翻訳言語
3. `history-of-unicode-encoding`（Unicodeの歴史）×12翻訳言語
4. その他の記事を、更新追随が必要なもの・誤記の影響が大きいものから順に処理

各言語は en、zh-cn、es、ko、pt、zh-tw、hi、fr、de、ar、ru、id。対象一覧の生成・構文や数式の自動比較は補助検査として扱い、本文を読んだ意味照合とは分ける。
