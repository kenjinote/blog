# llms.txt の管理

`static/llms.txt` は Hugo のビルド時にサイト直下の `/llms.txt` にコピーされます。
全言語で共通の案内として、サイト概要・主要ページ・カテゴリ・言語別トップページを掲載しています。
各ページの HTML head には `rel="describedby"` でこのファイルへのリンクを出力します。

形式は https://llmstxt.org/ の提案に従い、H1、概要の引用、補足説明、H2 ごとのリンク一覧で構成します。
記事の全件列挙や本文の複製は行わず、アーカイブとサイトマップに案内することで小さく保ちます。
リンク先は実際に公開される HTML ページまたは XML フィードです。

サイトの説明、主要ページの URL、カテゴリ、対応言語、RSS 件数を変更した場合は、このファイルも更新してください。
`llms.txt` は案内用であり、クローラーの制御やコンテンツの利用許諾は設定しません。

公開前には通常の本番ビルド（`hugo --minify --buildFuture`）を実行し、
生成された `public/llms.txt` とリンク先の存在、および HTML の `describedby` リンクを確認してください。
