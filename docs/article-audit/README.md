## 編集方針

- 記事の主題を表す既存カテゴリーを選ぶ。伝記は biography と主分野、技術解説は主分野と明確な専門分野を基本とし、関連語が一度出るだけのカテゴリーは追加しない。
- 全翻訳で同じ意味の識別子を使う。表示名は既存のカテゴリー翻訳定義で管理する。曖昧な分類は本文確認後に判断し、自動で一律置換しない。
- 内部リンクは同言語の公開記事へ。本文の説明を助ける最初の適切な箇所を優先し、反復リンク・自己リンクは削減する。参照先の存在だけでなく主題も確認する。
- ソースを再シリアライズせず、必要なカテゴリー欄・リンク記法だけを変更する。ラベルを保持し、コード、数式、Mermaid、画像、HTML属性、ショートコードを変更しない。見出しのリンク整理時は生成アンカーが変わらないことを検証する。
- `scripts/internal_links.py` を既存の保護処理として活用する。旧 `linkizer*.py` は使用しない。全出現箇所を自動リンク化する既定処理は無審査で全記事へ適用しない。
- 記事の事実関係の修正・全面改稿は今回の範囲外。問題に気づいた場合は別途記録する。
