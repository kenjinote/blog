## kenjinote 소개

kenji.blog의 저자 kenjinote입니다. 2008년부터 현재까지 IT 기업에 재직 중이며, C/C++를 이용한 Windows 애플리케이션 개발을 전문으로 합니다. 대학에서는 수학을 전공했습니다.

이 블로그에서는 프로그래밍, 소프트웨어 개발, AI, 수학을 중심으로 기술의 원리와 활용 방법을 소개합니다.

## 경력과 전문 분야

- 실무 경력: 2008년부터 현재까지 IT 기업 재직.
- 전문 분야: C/C++를 이용한 Windows 애플리케이션 개발.
- 학업 배경: 대학에서 수학 전공.

## Microsoft MVP 수상 경력

2017년부터 현재까지 매년 Microsoft MVP를 연속 수상했습니다.

- [Microsoft 공식 MVP 프로필](https://mvp.microsoft.com/ja-JP/mvp/profile/9da0e78b-4d15-e711-810b-3863bb36edf8)

## 주요 개발 작품 및 소프트웨어

개인 개발자로서 기능미와 초고속 성능을 추구하는 데스크톱 및 모바일 애플리케이션을 제작하고 있습니다. 많은 관심과 이용 부탁드립니다!

### 1. 텍스트 에디터 miu
**불필요한 요소를 극단적으로 덜어낸 미니멀 & 초경량 크로스 플랫폼 텍스트 에디터**

집중을 방해하지 않는 깔끔한 인터페이스와 번개처럼 빠른 실행 속도를 자랑합니다. 간단한 메모부터 전문적인 글쓰기 및 코딩 작업까지 몰입감 넘치는 쾌적한 텍스트 작업 환경을 선사합니다. Windows, iOS, Android에서 모두 이용 가능합니다.

- [Microsoft Store (Windows 버전)](https://apps.microsoft.com/detail/9nblggh35lxs)
- [App Store (iOS / Mac 버전)](https://apps.apple.com/jp/app/miu-minimal-text-editor/id6759484253)
- [Google Play (Android 버전)](https://play.google.com/store/apps/details?id=jp.hack.miu)

### 2. 채팅 메신저 chat.exe
**경쾌한 반응성과 편의성을 극대화한 모던 채팅 애플리케이션**

직관적인 사용성과 신속한 반응 속도에 집중한 차세대 커뮤니케이션 도구입니다. 웹 브라우저에서 바로 접속 가능한 웹 버전은 물론, Windows 환경에 최적화된 네이티브 앱(Microsoft Store)을 함께 제공하여 원활한 대화와 협업을 돕습니다.

- [chat.exe 공식 웹사이트](https://chatexe.net/)
- [Microsoft Store (Windows 버전)](https://apps.microsoft.com/detail/9mvjzsr56jjk)

### 3. 비디오 화면 보호기 (Video Screensaver)
**좋아하는 동영상을 고화질 Windows 화면 보호기로 간편하게 설정**

아름다운 자연 풍경, 애니메이션, 개인 소장 영상을 부드러운 고화질 화면 보호기로 자동 재생해 주는 유틸리티입니다. 가벼운 설계로 시스템 리소스를 거의 차지하지 않으며, PC 유휴 시간을 나만의 힐링 공간으로 바꿔줍니다.

- [Microsoft Store (Windows 버전)](https://apps.microsoft.com/detail/9n0mzq5l811m)
