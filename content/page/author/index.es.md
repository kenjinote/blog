## Acerca de kenjinote

Soy kenjinote, autor de kenji.blog. Trabajo en una empresa de TI desde 2008 y mi especialidad es el desarrollo de aplicaciones para Windows con C/C++. En la universidad estudié matemáticas como especialidad principal.

En este blog explico cómo funcionan las tecnologías y cómo utilizarlas, con especial atención a la programación, el desarrollo de software, la IA y las matemáticas.

## Trayectoria y especialidad

- Experiencia profesional: trabajo en una empresa de TI desde 2008 hasta la actualidad.
- Especialidad: desarrollo de aplicaciones para Windows con C/C++.
- Formación: estudios universitarios centrados en matemáticas.

## Reconocimientos Microsoft MVP

He recibido el reconocimiento Microsoft MVP todos los años desde 2017 hasta la actualidad.

## Principales proyectos y productos de software

Como desarrollador independiente, creo aplicaciones de escritorio y móviles optimizadas para ofrecer la máxima velocidad, ligereza y estética funcional. ¡Te invito a probarlas!

### 1. Editor de texto miu
**Un editor de texto minimalista, ágil y multiplataforma diseñado para escribir sin distracciones**

Combina una interfaz limpia y libre de ruidos visuales con una velocidad de inicio instantánea. Perfecto para tomar notas rápidas, redactar textos extensos o programar código con una fluidez excepcional. Disponible para Windows, iOS y Android.

- [Microsoft Store (Versión Windows)](https://apps.microsoft.com/detail/9nblggh35lxs)
- [App Store (Versión iOS / Mac)](https://apps.apple.com/jp/app/miu-minimal-text-editor/id6759484253)
- [Google Play (Versión Android)](https://play.google.com/store/apps/details?id=jp.hack.miu)

### 2. Aplicación de chat chat.exe
**Una moderna herramienta de comunicación diseñada para ofrecer una respuesta ultra-rápida**

Herramienta ágil e intuitiva pensada para facilitar un diálogo directo y fluido. Disponible tanto en versión web accesible desde cualquier navegador como en aplicación nativa optimizada para Windows en la Microsoft Store.

- [Sitio web oficial de chat.exe](https://chatexe.net/)
- [Microsoft Store (Versión Windows)](https://apps.microsoft.com/detail/9mvjzsr56jjk)

### 3. Video Screensaver
**Convierte tus vídeos favoritos en un elegante salvapantallas para Windows**

Una utilidad ligera que reproduce de forma fluida y en alta definición tus paisajes, grabaciones o animaciones preferidas como salvapantallas de Windows sin sobrecargar el rendimiento de tu equipo.

- [Microsoft Store (Versión Windows)](https://apps.microsoft.com/detail/9n0mzq5l811m)
