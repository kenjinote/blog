## Tentang kenjinote

Saya kenjinote, penulis kenji.blog. Saya bekerja di sebuah perusahaan TI sejak 2008 hingga sekarang dan memiliki keahlian dalam pengembangan aplikasi Windows menggunakan C/C++. Di universitas, saya mengambil jurusan matematika.

Di blog ini, saya menjelaskan cara kerja dan penggunaan teknologi, dengan fokus pada pemrograman, pengembangan perangkat lunak, AI, dan matematika.

## Pengalaman dan keahlian

- Pengalaman profesional: bekerja di sebuah perusahaan TI sejak 2008 hingga sekarang.
- Keahlian: pengembangan aplikasi Windows menggunakan C/C++.
- Latar belakang akademik: mengambil jurusan matematika di universitas.
