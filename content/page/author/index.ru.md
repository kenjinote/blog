## О kenjinote

Я kenjinote, автор kenji.blog. С 2008 года по настоящее время работаю в ИТ-компании и специализируюсь на разработке приложений для Windows на C/C++. В университете моей основной специальностью была математика.

В этом блоге я рассказываю об устройстве и использовании технологий, уделяя особое внимание программированию, разработке ПО, искусственному интеллекту и математике.

## Опыт и специализация

- Профессиональный опыт: работа в ИТ-компании с 2008 года по настоящее время.
- Специализация: разработка приложений для Windows на C/C++.
- Академическая подготовка: изучение математики как основной специальности в университете.

## Награды Microsoft MVP

С 2017 года по настоящее время я ежегодно, без перерывов, получаю награду Microsoft MVP.

## Основные программные продукты и разработки

Как независимый разработчик, я создаю минималистичные и высокопроизводительные приложения для ПК и мобильных устройств. Обязательно попробуйте их в работе!

### 1. Текстовый редактор miu
**Минималистичный и сверхбыстрый кроссплатформенный текстовый редактор для работы без отвлечений**

Сочетает в себе лаконичный интерфейс и мгновенный запуск. Отлично подходит как для быстрых заметок, так и для вдумчивого написания текстов и программирования. Доступен на платформах Windows, iOS и Android.

- [Microsoft Store (Версия для Windows)](https://apps.microsoft.com/detail/9nblggh35lxs)
- [App Store (Версия для iOS / Mac)](https://apps.apple.com/jp/app/miu-minimal-text-editor/id6759484253)
- [Google Play (Версия для Android)](https://play.google.com/store/apps/details?id=jp.hack.miu)

### 2. Чат-сервис chat.exe
**Современный и отзывчивый сервис обмена сообщениями для комфортного общения**

Создан для быстрого и интуитивного взаимодействия. Сервис доступен как в виде веб-приложения в любом браузере, так и в виде нативного Windows-приложения в Microsoft Store.

- [Официальный сайт chat.exe](https://chatexe.net/)
- [Microsoft Store (Версия для Windows)](https://apps.microsoft.com/detail/9mvjzsr56jjk)

### 3. Видео-заставка (Video Screensaver)
**Превратите любимые видеоролики в эффектную экранную заставку Windows**

Компактная утилита для Windows, позволяющая плавно и в высоком качестве воспроизводить красивые пейзажи, анимацию или памятные видеозаписи в режиме ожидания экрана с минимальной нагрузкой на систему.

- [Microsoft Store (Версия для Windows)](https://apps.microsoft.com/detail/9n0mzq5l811m)
