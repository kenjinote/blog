# MS-DOS 4.00 소스 코드 공개

2024년 4월 25일, Microsoft는 IBM과 협력해 MS-DOS 4.00의 소스 코드를 공개했습니다. 코드 대부분은 8086 어셈블리로 작성되어 있어 역사적인 운영체제의 구현을 살펴볼 수 있습니다. 공개 배경은 [Microsoft Open Source 블로그](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/)에서 확인할 수 있습니다.

## GitHub 저장소 구성

[Microsoft MS-DOS 저장소](https://github.com/microsoft/MS-DOS)에는 MS-DOS 4.00 소스 코드와 컴파일된 바이너리, 문서, 디스크 이미지가 들어 있습니다. Microsoft 발표에 따르면 Ray Ozzie가 보관하던 미공개 베타 바이너리도 함께 공개됐습니다. 저장소에는 MS-DOS 1.25와 2.0 자료도 포함되어 있습니다.

## 라이선스와 아카이브 상태

저장소의 파일은 MIT 라이선스로 공개되었습니다. 자세한 조건은 [v4.0 라이선스 파일](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE)을 확인하세요. GitHub에 따르면 저장소는 2024년 4월 25일 아카이브되어 현재 읽기 전용입니다. 역사 자료로 참고하거나 포크해 살펴볼 수 있습니다.
