# Publicado el código fuente de MS-DOS 4.00

El 25 de abril de 2024, Microsoft publicó el código fuente de MS-DOS 4.00 en colaboración con IBM. La mayor parte está escrita en ensamblador 8086 y permite estudiar la implementación de un sistema operativo histórico. Microsoft explica la publicación en su [blog de código abierto](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## Contenido del repositorio de GitHub

El [repositorio MS-DOS de Microsoft](https://github.com/microsoft/MS-DOS) incluye el código fuente de MS-DOS 4.00, binarios compilados, documentación e imágenes de discos. Según el anuncio de Microsoft, también se publicaron binarios beta inéditos que conservaba Ray Ozzie. El repositorio contiene además materiales de MS-DOS 1.25 y 2.0.

## Licencia y estado del archivo

Los archivos del repositorio se distribuyen bajo la licencia MIT. Consulta el [archivo de licencia de v4.0](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE) para conocer las condiciones. GitHub indica que el repositorio se archivó el 25 de abril de 2024 y ahora es de solo lectura. Puedes consultarlo como referencia histórica o crear una bifurcación para estudiarlo.
