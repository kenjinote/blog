# MS-DOS 4.00 source code released

On April 25, 2024, Microsoft released the MS-DOS 4.00 source code in partnership with IBM. Most of the code is written in 8086 assembly, offering a historical example of an operating system's implementation. Microsoft describes the release in its [Open Source Blog](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## What's in the GitHub repository?

The [Microsoft MS-DOS repository](https://github.com/microsoft/MS-DOS) contains the MS-DOS 4.00 source, compiled binaries, documents, and disk images. Microsoft's announcement says the release also includes previously unreleased beta binaries preserved by Ray Ozzie. The repository includes materials for MS-DOS 1.25 and 2.0 as well.

## License and archive status

The files in the repository are released under the MIT License. See the [v4.0 license file](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE) for the terms. GitHub shows that the repository was archived on April 25, 2024, so it is now read-only. You can consult it as a historical reference or fork it for further study.
