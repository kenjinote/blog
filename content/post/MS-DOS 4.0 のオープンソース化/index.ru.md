# Опубликован исходный код MS-DOS 4.00

25 апреля 2024 года Microsoft совместно с IBM опубликовала исходный код MS-DOS 4.00. Большая его часть написана на ассемблере 8086 и представляет исторический интерес для изучения реализации операционной системы. Microsoft описала публикацию в [блоге Open Source](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## Что находится в репозитории GitHub?

[Репозиторий MS-DOS от Microsoft](https://github.com/microsoft/MS-DOS) содержит исходный код MS-DOS 4.00, скомпилированные двоичные файлы, документацию и образы дисков. По сообщению Microsoft, в публикацию также вошли ранее не выпускавшиеся бета-версии двоичных файлов, сохраненные Рэем Оззи. В репозитории есть и материалы по MS-DOS 1.25 и 2.0.

## Лицензия и статус архива

Файлы репозитория опубликованы под лицензией MIT. Условия приведены в [файле лицензии v4.0](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE). GitHub указывает, что репозиторий архивирован 25 апреля 2024 года и теперь доступен только для чтения. Его можно изучать как исторический материал или форкнуть для собственных исследований.
