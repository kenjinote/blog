# Publication du code source de MS-DOS 4.00

Le 25 avril 2024, Microsoft a publié le code source de MS-DOS 4.00 en partenariat avec IBM. La majeure partie est écrite en assembleur 8086 et permet d’étudier l’implémentation d’un système d’exploitation historique. Microsoft explique cette publication sur son [blog Open Source](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## Contenu du dépôt GitHub

Le [dépôt MS-DOS de Microsoft](https://github.com/microsoft/MS-DOS) comprend le code source de MS-DOS 4.00, des binaires compilés, de la documentation et des images de disquettes. Selon l’annonce de Microsoft, la publication inclut également des binaires bêta inédits conservés par Ray Ozzie. Le dépôt contient aussi des documents sur MS-DOS 1.25 et 2.0.

## Licence et archivage

Les fichiers du dépôt sont publiés sous licence MIT. Consultez le [fichier de licence v4.0](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE) pour en connaître les conditions. GitHub indique que le dépôt a été archivé le 25 avril 2024 et qu’il est désormais en lecture seule. Vous pouvez le consulter comme document historique ou le forker pour l’étudier.
