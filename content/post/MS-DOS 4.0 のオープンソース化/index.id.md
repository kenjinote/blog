# Kode sumber MS-DOS 4.00 dirilis

Pada 25 April 2024, Microsoft merilis kode sumber MS-DOS 4.00 bersama IBM. Sebagian besar kode ditulis dalam Assembly 8086 dan menjadi bahan sejarah untuk mempelajari implementasi sistem operasi lama. Microsoft menjelaskan rilis ini di [blog Open Source](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## Isi repositori GitHub

[Repositori MS-DOS Microsoft](https://github.com/microsoft/MS-DOS) memuat kode sumber MS-DOS 4.00, biner hasil kompilasi, dokumentasi, dan citra disket. Menurut pengumuman Microsoft, rilis ini juga menyertakan biner beta yang sebelumnya belum dirilis dan disimpan oleh Ray Ozzie. Repositori tersebut juga berisi materi MS-DOS 1.25 dan 2.0.

## Lisensi dan status arsip

Berkas dalam repositori dirilis dengan lisensi MIT. Baca [berkas lisensi v4.0](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE) untuk mengetahui ketentuannya. GitHub menunjukkan bahwa repositori diarsipkan pada 25 April 2024 dan kini hanya-baca. Anda dapat memakainya sebagai rujukan sejarah atau membuat fork untuk mempelajarinya.
