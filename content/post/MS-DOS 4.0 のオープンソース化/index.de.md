# Quellcode von MS-DOS 4.00 veröffentlicht

Am 25. April 2024 veröffentlichte Microsoft den Quellcode von MS-DOS 4.00 in Zusammenarbeit mit IBM. Der größte Teil ist in 8086-Assembler geschrieben und ermöglicht Einblicke in die Implementierung eines historischen Betriebssystems. Microsoft beschreibt die Veröffentlichung im [Open-Source-Blog](https://opensource.microsoft.com/blog/2024/04/25/open-sourcing-ms-dos-4-0/).

## Inhalt des GitHub-Repositorys

Das [MS-DOS-Repository von Microsoft](https://github.com/microsoft/MS-DOS) enthält den Quellcode von MS-DOS 4.00, kompilierte Binärdateien, Dokumente und Diskettenabbilder. Laut Microsofts Ankündigung gehören auch zuvor unveröffentlichte Beta-Binärdateien aus Ray Ozzies Sammlung dazu. Das Repository enthält außerdem Material zu MS-DOS 1.25 und 2.0.

## Lizenz und Archivstatus

Die Dateien im Repository stehen unter der MIT-Lizenz. Die Bedingungen finden Sie in der [Lizenzdatei für v4.0](https://github.com/microsoft/MS-DOS/blob/main/v4.0/LICENSE). GitHub kennzeichnet das Repository seit dem 25. April 2024 als archiviert; es ist daher schreibgeschützt. Sie können es als historische Quelle verwenden oder zum eigenen Studium forken.
