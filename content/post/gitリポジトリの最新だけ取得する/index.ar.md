# الحصول على أحدث إصدار من مستودع git فقط

يمكنك الحصول على أحدث إصدار من المستودع فقط باستخدام الأمر التالي.
هذا مفيد إذا كنت ترغب في جلب المستودع بسرعة لتوفير مساحة القرص.

```
git clone --depth 1 <عنوان URL للمستودع>
```
