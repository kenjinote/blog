# Клонирование репозитория с неглубокой историей

`git clone --depth 1` создаёт неглубокий клон с глубиной истории один от вершины выбранной ветки. По умолчанию выбирается ветка репозитория, настроенная как основная. Это сокращает объём передаваемой истории коммитов, но Git всё равно загружает текущие файлы и необходимые объекты; поэтому репозиторий с крупными файлами может оставаться большим.

```sh
git clone --depth 1 <repository-url>
```

Чтобы выбрать ветку явно, укажите её имя:

```sh
git clone --depth 1 --single-branch --branch <branch> <repository-url>
```

Позже можно получить больше истории, например так:

```sh
git -C <directory> fetch --deepen=50 origin <branch>
```

Замените `<directory>` и `<branch>` своими именами. Параметр `--depth` также подразумевает `--single-branch`, если не переопределить это поведение. Подробности, в том числе о `--unshallow`, см. в официальных руководствах [`git clone`](https://git-scm.com/docs/git-clone) и [`git fetch`](https://git-scm.com/docs/git-fetch).
