# Получить только последнюю версию репозитория

Вы можете получить только последнюю версию репозитория с помощью следующей команды.
Это полезно, когда вы хотите быстро загрузить репозиторий для экономии дискового пространства.

```
git clone --depth 1 <URL репозитория>
```
