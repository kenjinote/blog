# गिट रिपॉजिटरी का केवल नवीनतम संस्करण प्राप्त करें

आप निम्नलिखित कमांड का उपयोग करके रिपॉजिटरी का केवल नवीनतम संस्करण प्राप्त कर सकते हैं।
यह तब उपयोगी होता है जब आप डिस्क स्थान बचाने के लिए जल्दी से रिपॉजिटरी प्राप्त करना चाहते हैं।

```
git clone --depth 1 <रिपॉजिटरी URL>
```
