# 저장소의 최신 커밋만 가져오기

다음 명령어로 저장소의 최신 커밋만 가져올 수 있습니다.
디스크 용량을 절약하기 위해, 빠르게 저장소를 가져오고 싶을 때 유용합니다.

```
git clone --depth 1 <저장소 URL>
```
