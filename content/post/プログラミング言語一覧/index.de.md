## OCaml
Eine Art funktionale Programmiersprache, die am INRIA (Nationales französisches Forschungsinstitut für Informatik und Automatisierung) entwickelt wurde.

## Clojure
Eine Programmiersprache und ein Dialekt der LISP-Sprachfamilie.

## Scheme
Eine einfache Programmiersprache.

## Erlang
Eine nebenläufige, Open-Source-Software (OSS) Programmiersprache und Laufzeitumgebung, die für allgemeine Zwecke auf Computern verwendet werden kann.

## Forth
Stack-orientierte Programmiersprache.

## D
Die D-Sprache ist eine stark statisch typisierte Sprache.

## Eiffel
Eiffel ist eine objektorientierte Programmiersprache.

## Ada
Ada ist eine objektorientierte Programmiersprache.

## Pascal
Pascal ist eine prozedurale Programmiersprache.

## COBOL
Gibt es schon lange. Es ist eine universelle Programmiersprache.

## Fortran
Auf numerische Berechnungen spezialisierte Programmiersprache.

## Assembly
Programmiersprache mit Eins-zu-Eins-Entsprechung zur Maschinensprache.

## BASIC
Eine prozedurale Programmiersprache. Der Name ist ein Akronym für "beginners' all-purpose symbolic instruction code".

## Smalltalk
Objektorientierte Programmiersprache.

## Lisp
Programmiersprache, die in Präfixnotation geschrieben wird.

## ML
ML ist eine funktionale Programmiersprache.

## Prolog
Programmiersprache, die zur Definition von Beziehungen und zur Lösung von Problemen verwendet wird.

## GLSL
Die Shader-Sprache von OpenGL.

## SQL
Eine Sprache zur Manipulation relationaler Daten.

## PostScript
Eine von Adobe entwickelte Skriptsprache für den Druck.

## PowerShell

## Salesforce APEX
