## OCaml
Um tipo de linguagem funcional desenvolvida no INRIA (Instituto Nacional de Pesquisa em Informática e Automação da França).

## Clojure
Uma linguagem de programação e um dos dialetos da família de linguagens LISP.

## Scheme
Uma linguagem de programação simples.

## Erlang
Uma linguagem de programação de software de código aberto (OSS) voltada para concorrência e ambiente de execução que pode ser usada para propósitos gerais em computadores.

## Forth
Linguagem de programação orientada a pilhas.

## D
A linguagem D é uma linguagem fortemente tipada estaticamente.

## Eiffel
Eiffel é uma linguagem de programação orientada a objetos.

## Ada
Ada é uma linguagem de programação orientada a objetos.

## Pascal
Pascal é uma linguagem de programação procedural.

## COBOL
Existe há muito tempo. É uma linguagem de programação de uso geral.

## Fortran
Linguagem de programação especializada em cálculos numéricos.

## Assembly
Linguagem de programação com correspondência de 1 para 1 com a linguagem de máquina.

## BASIC
Uma linguagem de programação procedural. O nome é um acrônimo para "beginners' all-purpose symbolic instruction code".

## Smalltalk
Linguagem de programação orientada a objetos.

## Lisp
Linguagem de programação escrita com notação de prefixo.

## ML
ML é uma linguagem de programação funcional.

## Prolog
Linguagem de programação usada para definir relacionamentos e resolver problemas.

## GLSL
Linguagem de shader do OpenGL.

## SQL
Linguagem para manipulação de dados relacionais.

## PostScript
Linguagem de script para impressão desenvolvida pela Adobe.

## PowerShell
Instalado por padrão no Windows. Pode manipular objetos.

## Salesforce APEX

Uma linguagem muito semelhante ao Java.
