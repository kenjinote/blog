## OCaml
INRIA(프랑스 국립 정보학 자동 제어 연구소)에서 개발되고 있는 함수형 언어의 일종.

## Clojure
프로그래밍 언어이자 LISP 계열 언어의 방언 중 하나

## Scheme
심플한 프로그래밍 언어

## Erlang
컴퓨터에서 범용적인 용도로 사용할 수 있는 병행 처리 지향 오픈 소스 소프트웨어(영: Open Source Software, 약: OSS) 프로그래밍 언어 및 실행 환경.

## Forth
스택 지향 프로그래밍 언어

## D
D 언어는 강력한 정적 타입 언어

## Eiffel
Eiffel은 객체 지향 프로그래밍 언어 중 하나

## Ada
Ada는 객체 지향 프로그래밍 언어 중 하나

## Pascal
Pascal은 절차적 프로그래밍 언어 중 하나

## COBOL
예전부터 있었다. 범용 프로그래밍 언어이다.

## Fortran
수치 계산에 특화된 프로그래밍 언어

## Assembly
기계어와 1대1로 대응하는 프로그래밍 언어

## BASIC
절차적 프로그래밍 언어 중 하나. 이름은 「beginners' all-purpose symbolic instruction code」의 배크로님이다.

## Smalltalk
객체 지향 프로그래밍 언어

## Lisp
전위 표기법으로 기술하는 프로그래밍 언어

## ML
ML은 함수형 프로그래밍 언어 중 하나

## Prolog
관계를 정의하고 문제를 풀기 위해 사용되는 프로그래밍 언어

## GLSL
OpenGL 셰이더 언어

## SQL
관계형 데이터를 조작하기 위한 언어

## PostScript
Adobe가 개발한 인쇄용 스크립트 언어

## PowerShell
Windows에 표준으로 설치되어 있다. 객체를 다룰 수 있다.

## Salesforce APEX

Java와 매우 흡사한 언어
