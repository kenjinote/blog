## O que é o Problema de Monty Hall?
O Problema de Monty Hall é um dos jogos apresentados no programa de televisão americano "Let's Make a Deal", e consiste no seguinte problema:

Pré-requisitos: Atrás de uma das 3 portas há um prêmio, e as outras 2 estão vazias (prêmios de consolação).

1. O participante escolhe uma das 3 portas.
2. O apresentador abre uma das 2 portas não escolhidas pelo participante, revelando que ela está vazia.
3. Ao participante é perguntado se ele deseja trocar a porta escolhida.

O problema é determinar se é melhor para o participante trocar de porta ou não.

## Solução
A solução para o Problema de Monty Hall é a seguinte:

1. Se o participante não trocar a porta escolhida inicialmente:
   - Probabilidade de ganhar: 1/3
   - Probabilidade de perder: 2/3

2. Após o apresentador abrir uma porta vazia:
    - Se não trocar, a probabilidade de ganhar: 1/3 (permanece a mesma probabilidade do passo 1)
    - Se trocar, a probabilidade de ganhar: 2/3 (a probabilidade de qualquer outra porta do passo 1)

Portanto, a probabilidade de ganhar é maior se o participante trocar de porta.
