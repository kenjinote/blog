# A Transformação do IPv4 para o IPv6

O IPv6 é um protocolo de internet de próxima geração projetado para expandir o espaço de endereçamento esgotado do IPv4.

## Expansão do Espaço de Endereçamento

O comprimento do endereço IPv6 é de 128 bits, fornecendo um número astronômico de endereços.

```mermaid
graph TD;
    V4["IPv4 (32-bit: ~4.3 Billion Addresses)"] --> Need["Address Exhaustion (NAT usage)"];
    Need --> V6["IPv6 (128-bit: ~3.4×10^38 Addresses)"];
```

## Representação Matemática

O número total de endereços IPv6 $A_{IPv6}$ é 2 elevado à 128ª potência.

$$ A_{IPv6} = 2^{128} \approx 3.4 \times 10^{38} $$

Isso torna possível atribuir um endereço IP global único a praticamente todos os dispositivos ativos.
