# egui란

Rust에서 사용할 수 있는 GUI 라이브러리입니다.

# egui 사용해보기

다음 명령어로 egui 샘플을 실행할 수 있습니다.

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

이제 샘플 코드를 만지면서 여러 가지를 테스트해 볼 수 있습니다.
