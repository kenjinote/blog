# egui란

egui는 Rust용 즉시 모드 GUI 라이브러리입니다. 공식 프레임워크 eframe은 egui 앱을 네이티브 또는 웹에서 실행하도록 통합합니다.

# egui 사용해보기

다음 명령어로 egui 샘플을 실행할 수 있습니다.

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

이제 샘플 코드를 만지면서 여러 가지를 테스트해 볼 수 있습니다.
