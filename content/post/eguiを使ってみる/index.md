# eguiとは

eguiはRust向けの即時モードGUIライブラリです。公式フレームワークeframeはeguiアプリをネイティブまたはWebで動かす統合機能を提供します。

# eguiを使ってみる

下記のコマンドで、eguiのサンプルを実行できます。

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

あとはサンプルコードを触りながらいろいろ試せます。
