# ¿Qué es egui?

Es una librería GUI que se puede utilizar con Rust.

# Probando egui

Puedes ejecutar el ejemplo de egui con los siguientes comandos.

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

Después de eso, puedes probar varias cosas mientras juegas con el código de ejemplo.
