# ¿Qué es egui?

egui es una biblioteca GUI de modo inmediato para Rust. Su framework oficial, eframe, integra aplicaciones para ejecutarlas de forma nativa o en la web.

# Probando egui

Puedes ejecutar el ejemplo de egui con los siguientes comandos.

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

Después de eso, puedes probar varias cosas mientras juegas con el código de ejemplo.
