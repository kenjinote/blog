# Was ist egui

egui ist eine GUI-Bibliothek im Immediate Mode für Rust. Das offizielle Framework eframe integriert egui-Apps für die native Ausführung oder das Web.

# egui ausprobieren

Sie können das egui-Beispiel mit den folgenden Befehlen ausführen.

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

Danach können Sie verschiedene Dinge ausprobieren, während Sie mit dem Beispielcode spielen.
