# Was ist egui

Es ist eine GUI-Bibliothek, die in Rust verwendet werden kann.

# egui ausprobieren

Sie können das egui-Beispiel mit den folgenden Befehlen ausführen.

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

Danach können Sie verschiedene Dinge ausprobieren, während Sie mit dem Beispielcode spielen.
