# Apa itu egui

Ini adalah pustaka GUI yang dapat digunakan dengan rust.

# Mencoba egui

Anda dapat menjalankan contoh egui dengan perintah berikut.

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

Setelah itu, Anda dapat mencoba berbagai hal sambil bermain-main dengan kode contohnya.
