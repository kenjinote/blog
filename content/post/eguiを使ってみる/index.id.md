# Apa itu egui

egui adalah pustaka GUI immediate-mode untuk Rust. Framework resmi eframe mengintegrasikan aplikasi egui agar dapat dijalankan secara native atau di web.

# Mencoba egui

Anda dapat menjalankan contoh egui dengan perintah berikut.

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

Setelah itu, Anda dapat mencoba berbagai hal sambil bermain-main dengan kode contohnya.
