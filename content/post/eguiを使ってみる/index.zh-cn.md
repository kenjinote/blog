# egui 是什么

这是一个可以在 rust 中使用的 GUI 库。

# 尝试使用 egui

使用以下命令可以运行 egui 的示例。

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

之后就可以一边修改示例代码，一边进行各种尝试了。
