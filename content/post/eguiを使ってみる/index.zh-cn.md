# egui 是什么

egui 是面向 Rust 的即时模式 GUI 库。官方框架 eframe 集成 egui 应用，可在原生环境或 Web 上运行。

# 尝试使用 egui

使用以下命令可以运行 egui 的示例。

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

之后就可以一边修改示例代码，一边进行各种尝试了。
