# 什麼是 egui

egui 是適用於 Rust 的即時模式 GUI 函式庫。官方框架 eframe 整合 egui 應用程式，可在原生環境或網頁執行。

# 試用 egui

您可以使用以下指令執行 egui 的範例。

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

之後，您可以在把玩範例程式碼的同時進行各種嘗試。
