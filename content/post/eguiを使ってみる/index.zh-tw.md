# 什麼是 egui

這是一個可以在 Rust 中使用的 GUI 函式庫。

# 試用 egui

您可以使用以下指令執行 egui 的範例。

```
git clone https://github.com/emilk/eframe_template/ egui_test
cd egui_test
cargo run
```

之後，您可以在把玩範例程式碼的同時進行各種嘗試。
