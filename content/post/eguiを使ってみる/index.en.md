# What is egui

egui is an immediate-mode GUI library for Rust. Its official framework, eframe, integrates egui apps for native or web use.

# Trying out egui

You can run the egui sample with the following commands.

```
git clone https://github.com/emilk/eframe_template.git egui_test
cd egui_test
cargo run --release
```

After that, you can try various things while tinkering with the sample code.
