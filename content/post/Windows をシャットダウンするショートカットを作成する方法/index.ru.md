Я покажу вам, как создать ярлык для завершения работы Windows.

Удобно иметь возможность завершить работу, дважды щелкнув по созданному ярлыку на рабочем столе.

## Способ создания

#### 1. Щелкните правой кнопкой мыши на рабочем столе и выберите `Создать` > `Ярлык`

![img_1.png](img_1.png)

#### 2. Появится экран создания ярлыка. Введите `shutdown.exe -s -f -t 0` и нажмите `Далее`

![img_2.png](img_2.png)

#### 3. Введите имя ярлыка `Завершение работы` и нажмите `Готово`

![img_3.png](img_3.png)

#### 4. Измените значок созданного ярлыка

![img_4.png](img_4.png)

Щелкните правой кнопкой мыши созданный ярлык и выберите `Свойства`

![img_5.png](img_5.png)

Нажмите `Сменить значок`

![img_6.png](img_6.png)

Выберите красный квадратный значок и нажмите `ОК`, затем снова нажмите `ОК`, чтобы закрыть окно свойств.

На этом всё.

![img.png](img.png)

При двойном щелчке по созданному ярлыку работа Windows будет завершена.

Примечание: диалоговое окно подтверждения завершения работы не отображается.
