Windows를 종료하는 바로 가기를 만드는 방법을 소개합니다.

생성된 바로 가기를 바탕 화면 등에 두고 두 번 클릭하면 종료할 수 있어 편리합니다.

## 만드는 방법

#### 1. 바탕 화면을 마우스 오른쪽 버튼으로 클릭하고 `새로 만들기` ＞ `바로 가기`를 선택

![img_1.png](img_1.webp)

#### 2. 바로 가기 만들기 화면이 표시되면 `shutdown.exe -s -f -t 0`을 입력하고 `다음`을 클릭

![img_2.png](img_2.webp)

#### 3. 바로 가기 이름에 `시스템 종료`를 입력하고 `마침`을 클릭

![img_3.png](img_3.webp)

#### 4. 생성된 바로 가기의 아이콘 변경하기

![img_4.png](img_4.webp)

생성된 바로 가기를 마우스 오른쪽 버튼으로 클릭하고 `속성`을 선택

![img_5.png](img_5.webp)

`아이콘 변경`을 클릭

![img_6.png](img_6.webp)

빨간색 사각형 아이콘을 선택하고 `확인`을 클릭한 후, 다시 `확인`을 클릭하여 속성을 닫음

이상입니다.

![img.png](img.webp)

생성된 바로 가기를 두 번 클릭하면 Windows가 종료됩니다.

※주의：시스템 종료 확인 대화 상자가 표시되지 않습니다.
