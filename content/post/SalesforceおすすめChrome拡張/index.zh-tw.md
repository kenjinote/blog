以下介紹兩款可用於 Salesforce 開發的 Chrome 擴充功能。兩者都是 Salesforce 以外開發者提供的第三方產品。以下資訊依據**2026-11-24**查閱的商店頁面；功能與權限可能變動。連接工作組織前，請先查看最新權限與隱私揭露，並取得 Salesforce 管理員核准。

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![Salesforce DevTools 查詢介面](img_2.webp)

Chrome 線上應用程式商店頁面介紹 SOQL 與 Apex 撰寫、物件和欄位搜尋、定義資訊匯出等功能。頁面標示版本 3.12.1、最後更新於 2026-07-23，並在資料處理項目中列出 Location 與 Web history。安裝前請查看最新權限與開發者隱私權政策。

[Salesforce DevTools — Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

頁面介紹透過 Salesforce REST API 搜尋 Apex 類別、觸發器、Visualforce 頁面/元件及其他 Salesforce 程式碼的功能。頁面標示版本 1.30、最後更新於 2024-11-06。開發者隱私權政策指出，擴充功能會將 Salesforce 執行個體 URL 與存取/更新權杖儲存在瀏覽器本機儲存空間，以呼叫 Salesforce API。連接工作組織前，請確認 OAuth 授權範圍並遵守組織安全政策。

[Salesforce advanced Code searcher — Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [開發者隱私權政策](https://sf-advanced-code-searcher.web.app/)
