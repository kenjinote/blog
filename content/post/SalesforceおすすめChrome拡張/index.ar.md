فيما يلي إضافتان لمتصفح Chrome لتطوير Salesforce. كلتاهما من جهات خارجية ومستقلتان عن Salesforce. تستند المعلومات إلى صفحات المتجر التي راجعناها في **2026-11-24**؛ وقد تتغير الميزات والأذونات. قبل ربط أي منهما بمؤسسة العمل، راجع الأذونات وإفصاحات الخصوصية الحالية واحصل على موافقة مسؤول Salesforce.

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![واجهة استعلام Salesforce DevTools](img_2.webp)

تذكر صفحة Chrome Web Store أدوات لإنشاء SOQL وApex، والبحث عن الكائنات والحقول، وتصدير التعريفات. تعرض الإصدار 3.12.1 وآخر تحديث بتاريخ 2026-07-23، وتُدرج Location وWeb history ضمن البيانات التي تتعامل معها. راجع الأذونات الحالية وسياسة خصوصية المطور قبل التثبيت.

[Salesforce DevTools — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

تصف الصفحة البحث عن فئات Apex والمشغلات وصفحات/مكونات Visualforce وشيفرات Salesforce الأخرى باستخدام ميزات Salesforce REST API. وتعرض الإصدار 1.30 وآخر تحديث بتاريخ 2024-11-06. تذكر سياسة خصوصية المطور أن الإضافة تحفظ عنوان مثيل Salesforce ورموز الوصول والتحديث في التخزين المحلي للمتصفح لاستدعاء Salesforce APIs. تحقّق من نطاق تفويض OAuth وسياسة أمان مؤسستك قبل الاتصال.

[Salesforce advanced Code searcher — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [سياسة خصوصية المطور](https://sf-advanced-code-searcher.web.app/)
