Here are two Chrome extensions for Salesforce development. Both are third-party products, independent of Salesforce. The details below reflect the store listings checked on **2026-11-24**; features and permissions can change. Before connecting either extension to a work org, review the current store permissions and privacy disclosures and get approval from your Salesforce administrator.

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![Salesforce DevTools query interface](img_2.webp)

The Chrome Web Store listing describes tools for composing SOQL and Apex, searching objects and fields, and exporting definitions. The listing shows version 3.12.1, last updated 2026-07-23, and discloses handling Location and Web history data. Review the latest permissions and the developer’s privacy policy before installing.

[Salesforce DevTools — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

The listing describes searching Apex classes, triggers, Visualforce pages/components, and other Salesforce code using Salesforce REST API features. It shows version 1.30, last updated 2024-11-06. The developer’s privacy policy says the extension stores the Salesforce instance URL and access/refresh tokens in browser local storage to call Salesforce APIs. Check the OAuth authorization scope and your organization’s security policy before connecting a work org.

[Salesforce advanced Code searcher — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [Developer privacy policy](https://sf-advanced-code-searcher.web.app/)
