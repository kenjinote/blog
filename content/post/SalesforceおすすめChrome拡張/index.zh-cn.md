下面介绍两款可用于 Salesforce 开发的 Chrome 扩展。它们都是由 Salesforce 以外的开发者提供的第三方产品。以下信息依据**2026-11-24**查看的商店页面；功能和权限可能变化。连接工作组织前，请查看最新权限与隐私说明，并征得 Salesforce 管理员批准。

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![Salesforce DevTools 查询界面](img_2.webp)

Chrome 网上应用店页面介绍了 SOQL 和 Apex 编写、对象与字段搜索以及定义信息导出等功能。页面显示版本 3.12.1、最后更新于 2026-07-23，并在数据处理说明中列出 Location 和 Web history。安装前请查看最新权限和开发者隐私政策。

[Salesforce DevTools — Chrome 网上应用店](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

页面介绍了通过 Salesforce REST API 搜索 Apex 类、触发器、Visualforce 页面/组件及其他代码的功能。页面显示版本 1.30、最后更新于 2024-11-06。开发者隐私政策说明，此扩展会把 Salesforce 实例 URL 和访问令牌、刷新令牌保存在浏览器本地存储中，用于调用 Salesforce API。连接工作组织前，请确认 OAuth 授权范围并遵守组织安全政策。

[Salesforce advanced Code searcher — Chrome 网上应用店](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [开发者隐私政策](https://sf-advanced-code-searcher.web.app/)
