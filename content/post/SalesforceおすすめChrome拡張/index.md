Salesforce開発で使えるChrome拡張を2つ紹介します。どちらもSalesforceとは別の開発者が提供する製品です。以下は**2026-11-24に確認したストア掲載情報**で、機能や権限は今後変わる可能性があります。業務用組織に接続する前に、Chromeウェブストアの権限・プライバシー情報を確認し、組織の管理者に利用可否を確認してください。

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![Salesforce DevTools query interface](img_2.webp)

Chromeウェブストアでは、SOQLやApexの作成、オブジェクトや項目の検索、定義情報のエクスポートなどを案内しています。掲載ページはバージョン3.12.1、最終更新日2026-07-23と表示し、データの取り扱いとしてLocationとWeb historyを挙げています。インストール前に最新の権限と開発者のプライバシーポリシーを確認してください。

[Salesforce DevTools — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

掲載ページでは、Apexクラス、トリガー、Visualforceページ／コンポーネントなどの検索や、Salesforce REST APIを使う機能を説明しています。バージョン1.30、最終更新日2024-11-06の表示を確認しました。開発者のプライバシーポリシーによると、SalesforceのインスタンスURLとアクセストークン類をブラウザーのローカルストレージに保存し、API呼び出しに使います。業務用組織で使う場合は特に、OAuth認可の範囲と組織のセキュリティポリシーを確認してください。

[Salesforce advanced Code searcher — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [開発者のプライバシーポリシー](https://sf-advanced-code-searcher.web.app/)
