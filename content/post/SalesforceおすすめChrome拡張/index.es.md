Aquí se presentan dos extensiones de Chrome para desarrollar con Salesforce. Son productos de terceros, independientes de Salesforce. La información corresponde a las fichas consultadas el **2026-11-24**; las funciones y los permisos pueden cambiar. Antes de conectar una organización de trabajo, revisa los permisos y avisos de privacidad vigentes y pide autorización al administrador de Salesforce.

## Salesforce DevTools

![Salesforce DevTools](img_1.webp)

![Interfaz de consulta de Salesforce DevTools](img_2.webp)

La ficha de Chrome Web Store describe funciones para crear SOQL y Apex, buscar objetos y campos y exportar definiciones. Indica la versión 3.12.1 y la última actualización del 2026-07-23; declara que trata datos de ubicación e historial web. Revisa los permisos actuales y la política de privacidad del desarrollador antes de instalar.

[Salesforce DevTools — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)

## Salesforce advanced Code searcher

![Salesforce advanced Code searcher](img.webp)

La ficha describe búsquedas de clases Apex, triggers, páginas/componentes Visualforce y otro código de Salesforce mediante funciones de Salesforce REST API. Muestra la versión 1.30 y una última actualización del 2024-11-06. La política de privacidad del desarrollador indica que guarda la URL de la instancia de Salesforce y los tokens de acceso y actualización en el almacenamiento local del navegador para llamar a las API de Salesforce. Comprueba el alcance OAuth y la política de seguridad de tu organización antes de conectarla.

[Salesforce advanced Code searcher — Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-advanced-code/lnkgcmpjkkkeffambkllliefdpjdklmi) · [Política de privacidad del desarrollador](https://sf-advanced-code-searcher.web.app/)
