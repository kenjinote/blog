# Mathematica 입문

## 방정식 풀기

```
Solve[x^2 - 3 x + 2 == 0, x]
```

출력
```
{{x -> 1}, {x -> 2}}
```

## 정수 범위에서 방정식의 해 구하기
```
Solve[x^2 - 3 x + 2 == 0 && 0 <= x <= 2, x, Integers]
```
출력
```
{{x -> 1}, {x -> 2}}
```

## 연립방정식 풀기
```
Solve[{x + y == 3, x - y == 1}, {x, y}]
```
출력
```
{{x -> 2, y -> 1}}
```

## 부등식 풀기
```
Reduce[x^2 - 3 x + 2 > 0, x]
```
출력
```
x < 1 || x > 2
```

## 미분하기
```
D[x^2, x]
```
출력
```
2 x
```

## 적분하기
```
Integrate[x^2, x]
```
출력
```
x^3/3
```

## 극한 구하기
```
Limit[1/x, x -> 0]
```
출력
```
Infinity
```

## 급수 구하기
```
Sum[1/n^2, {n, 1, Infinity}]
```
출력
```
π^2/6
```

## 행렬 만들기
```
m = {{1, 2}, {3, 4}}
```

## 행렬의 곱 구하기
```
m . m
```
출력
```
{{7, 10}, {15, 22}}
```

## 역행렬 구하기
```
Inverse[m]
```
출력
```
{{-2, 1}, {1.5, -0.5}}
```

## 고유값과 고유벡터 구하기
```
Eigensystem[m]
```
출력
```
{{5, 0}, {{1, 1}, {1, -1}}}
```

## 벡터의 내적 구하기
```
{1, 2} . {3, 4}
```
출력
```
11
```

## 벡터의 외적 구하기
```
Cross[{1, 2, 3}, {4, 5, 6}]
```
출력
```
{-3, 6, -3}
```

## 벡터의 크기 구하기
```
Norm[{1, 2, 3}]
```
출력
```
√14
```

## 벡터의 각도 구하기
```
ArcCos[{1, 2} . {3, 4}/(Norm[{1, 2}] Norm[{3, 4}])]
``` 

출력
```
ArcCos[11/(√5 √25)]
```

## 벡터의 사영 구하기
```
{1, 2} . {3, 4}/Norm[{3, 4}] {3, 4}/Norm[{3, 4}]
```
출력
```
{11/5, 22/5}
```

## 벡터의 회전 구하기
```
RotationMatrix[π/2].{1, 0}
```

출력
```
{0, 1}
```

## 벡터의 평행이동 구하기

출력
```

```

## 벡터의 확대 축소 구하기

```
출력
```
{2, 3}
```

## 벡터의 반전 구하기
```
ReflectionTransform[{1, 1}][{1, 1}]
```
출력
```
{0, 0}
```

```
출력
```
{0.123456, 0.234567, ..., 0.987654}
```

## 배열의 요소에 함수 적용하기
```
Map[Sqrt, {1, 4, 9}]
Sqrt /@ {1, 4, 9}
Map[#^(1/2)&, {1, 4, 9}]
```
출력
```
{1, 2, 3}
```

## 람다식을 사용하여 함수 정의하기
```
f = Function[x, x^2]
f[3]
```
출력
```
9
```

## 함수 합성하기
```
f = Function[x, x^2]
g = Function[x, x + 1]
h = Function[x, f[g[x]]]
h[3]
```
출력
```
16
```
