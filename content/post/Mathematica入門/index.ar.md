# مقدمة في Mathematica

## حل المعادلات

```
Solve[x^2 - 3 x + 2 == 0, x]
```

الخرج
```
{{x -> 1}, {x -> 2}}
```

## إيجاد حلول المعادلات في نطاق الأعداد الصحيحة
```
Solve[x^2 - 3 x + 2 == 0 && 0 <= x <= 2, x, Integers]
```
الخرج
```
{{x -> 1}, {x -> 2}}
```

## حل نظام من المعادلات
```
Solve[{x + y == 3, x - y == 1}, {x, y}]
```
الخرج
```
{{x -> 2, y -> 1}}
```

## حل المتباينات
```
Reduce[x^2 - 3 x + 2 > 0, x]
```
الخرج
```
x < 1 || x > 2
```

## التفاضل
```
D[x^2, x]
```
الخرج
```
2 x
```

## التكامل
```
Integrate[x^2, x]
```
الخرج
```
x^3/3
```

## إيجاد النهاية
```
Limit[1/x, x -> 0]
```
الخرج
```
Infinity
```

## إيجاد المتسلسلة
```
Sum[1/n^2, {n, 1, Infinity}]
```
الخرج
```
π^2/6
```

## إنشاء مصفوفة
```
m = {{1, 2}, {3, 4}}
```

## إيجاد ضرب المصفوفات
```
m . m
```
الخرج
```
{{7, 10}, {15, 22}}
```

## إيجاد المصفوفة المعكوسة
```
Inverse[m]
```
الخرج
```
{{-2, 1}, {1.5, -0.5}}
```

## إيجاد القيم الذاتية والمتجهات الذاتية
```
Eigensystem[m]
```
الخرج
```
{{5, 0}, {{1, 1}, {1, -1}}}
```

## إيجاد الضرب النقطي للمتجهات
```
{1, 2} . {3, 4}
```
الخرج
```
11
```

## إيجاد الضرب التقاطعي للمتجهات
```
Cross[{1, 2, 3}, {4, 5, 6}]
```
الخرج
```
{-3, 6, -3}
```

## إيجاد مقدار المتجه
```
Norm[{1, 2, 3}]
```
الخرج
```
√14
```

## إيجاد زاوية المتجه
```
ArcCos[{1, 2} . {3, 4}/(Norm[{1, 2}] Norm[{3, 4}])]
``` 

الخرج
```
ArcCos[11/(√5 √25)]
```

## إيجاد الإسقاط المتجهي
```
{1, 2} . {3, 4}/Norm[{3, 4}] {3, 4}/Norm[{3, 4}]
```
الخرج
```
{11/5, 22/5}
```

## إيجاد دوران المتجه
```
RotationMatrix[π/2].{1, 0}
```

الخرج
```
{0, 1}
```

## إيجاد تحجيم المتجه

```

## إيجاد انعكاس المتجه
```
ReflectionTransform[{1, 1}][{1, 1}]
```
الخرج

{0, 0}
```

## تطبيق دالة على عناصر المصفوفة
```
Map[Sqrt, {1, 4, 9}]
Sqrt /@ {1, 4, 9}
Map[#^(1/2)&, {1, 4, 9}]
```
الخرج
```
{1, 2, 3}
```

## تعريف دالة باستخدام تعبير لامبدا
```
f = Function[x, x^2]
f[3]
```
الخرج
```
9
```

## تركيب الدوال
```
f = Function[x, x^2]
g = Function[x, x + 1]
h = Function[x, f[g[x]]]
h[3]
```
الخرج
```
16
```

## الإشارة إلى نتيجة الحساب السابق
```
% + 1
```
الخرج
```
17
```

## دوال نقية
```
(#+3)&[5]
```
الخرج
```
8
```

## استخراج من المصفوفة

Select[{1, 2, 3, 4, 5}, EvenQ]
Select[{1, 2, 3, 4, 5}, Mod[#,2]==0&]
```
الخرج
```
{2, 4}
