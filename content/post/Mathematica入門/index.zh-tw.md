# Mathematica 入門

## 解方程式

```
Solve[x^2 - 3 x + 2 == 0, x]
```

輸出
```
{{x -> 1}, {x -> 2}}
```

## 在整數範圍內求方程式的解
```
Solve[x^2 - 3 x + 2 == 0 && 0 <= x <= 2, x, Integers]
```
輸出
```
{{x -> 1}, {x -> 2}}
```

## 解聯立方程式
```
Solve[{x + y == 3, x - y == 1}, {x, y}]
```
輸出
```
{{x -> 2, y -> 1}}
```

## 解不等式
```
Reduce[x^2 - 3 x + 2 > 0, x]
```
輸出
```
x < 1 || x > 2
```

## 微分
```
D[x^2, x]
```
輸出
```
2 x
```

## 積分
```
Integrate[x^2, x]
```
輸出
```
x^3/3
```

## 求極限
```
Limit[1/x, x -> 0]
```
輸出
```
Infinity
```

## 求級數
```
Sum[1/n^2, {n, 1, Infinity}]
```
輸出
```
π^2/6
```

## 建立矩陣
```
m = {{1, 2}, {3, 4}}
```

## 求矩陣乘積
```
m . m
```
輸出
```
{{7, 10}, {15, 22}}
```

## 求反矩陣
```
Inverse[m]
```
輸出
```
{{-2, 1}, {1.5, -0.5}}
```

## 求特徵值與特徵向量
```
Eigensystem[m]
```
輸出
```
{{5, 0}, {{1, 1}, {1, -1}}}
```

## 求向量內積
```
{1, 2} . {3, 4}
```
輸出
```
11
```

## 求向量外積
```
Cross[{1, 2, 3}, {4, 5, 6}]
```
輸出
```
{-3, 6, -3}
```

## 求向量的大小
```
Norm[{1, 2, 3}]
```
輸出
```
√14
```

## 求向量的角度
```
ArcCos[{1, 2} . {3, 4}/(Norm[{1, 2}] Norm[{3, 4}])]
``` 

輸出
```
ArcCos[11/(√5 √25)]
```

## 求向量的投影
```
{1, 2} . {3, 4}/Norm[{3, 4}] {3, 4}/Norm[{3, 4}]
```
輸出
```
{11/5, 22/5}
```

## 求向量的旋轉
```
RotationMatrix[π/2].{1, 0}
```

輸出
```
{0, 1}
```

## 求向量的平移
```
TranslationTransform[{1, 2}][{3, 4}]
```
輸出
```
{4, 6}
```

## 求向量的縮放
```
ScalingTransform[{2, 3}][{1, 1}]
```
輸出
```
{2, 3}
```

## 求向量的反射
```
ReflectionTransform[{1, 1}][{1, 1}]
```
輸出
```
{0, 0}
```

```
RandomReal[]
```

```
0.123456
```

```
RandomInteger[]
```

```
123456
```

```
RandomReal[{1, 10}]
```

```
5.6789
```

## 產生亂數（整數、指定範圍）

```
RandomInteger[{1, 10}]
```

```
5
```

## 產生亂數（指定分佈）
```
RandomVariate[NormalDistribution[0, 1]]
```
輸出
```
0.123456
```

## 產生亂數（指定分佈、指定數量）
```
RandomVariate[NormalDistribution[0, 1], 10]
```

```

```

## 產生亂數（指定分佈、指定數量、指定種子）
```

```
輸出
```
{0.123456, 0.234567, ..., 0.987654}
```

## 將函數套用至陣列元素
```
Map[Sqrt, {1, 4, 9}]
Sqrt /@ {1, 4, 9}
Map[#^(1/2)&, {1, 4, 9}]
```
輸出
```
{1, 2, 3}
```

## 使用 Lambda 運算式定義函數
```
f = Function[x, x^2]
f[3]
```
輸出
```
9
```

## 合成函數
```
f = Function[x, x^2]
g = Function[x, x + 1]
h = Function[x, f[g[x]]]
h[3]
```
輸出
```
16
```

## 參考前一次的計算結果
```
% + 1
```
輸出
```
17
```

## 純函數
```
(#+3)&[5]
```
輸出
```
8
```

## 擷取陣列
```
Select[{1, 2, 3, 4, 5}, EvenQ]
Select[{1, 2, 3, 4, 5}, Mod[#,2]==0&]
```
輸出
```
{2, 4}
```
