# Введение в Mathematica

## Решение уравнений

```
Solve[x^2 - 3 x + 2 == 0, x]
```

Вывод
```
{{x -> 1}, {x -> 2}}
```

## Поиск решений уравнений в целых числах
```
Solve[x^2 - 3 x + 2 == 0 && 0 <= x <= 2, x, Integers]
```
Вывод
```
{{x -> 1}, {x -> 2}}
```

## Решение систем уравнений
```
Solve[{x + y == 3, x - y == 1}, {x, y}]
```
Вывод
```
{{x -> 2, y -> 1}}
```

## Решение неравенств
```
Reduce[x^2 - 3 x + 2 > 0, x]
```
Вывод
```
x < 1 || x > 2
```

## Дифференцирование
```
D[x^2, x]
```
Вывод
```
2 x
```

## Интегрирование
```
Integrate[x^2, x]
```
Вывод
```
x^3/3
```

## Вычисление пределов
```
Limit[1/x, x -> 0]
```
Вывод
```
Infinity
```

## Вычисление рядов
```
Sum[1/n^2, {n, 1, Infinity}]
```
Вывод
```
π^2/6
```

## Создание матриц
```
m = {{1, 2}, {3, 4}}
```

## Умножение матриц
```
m . m
```
Вывод
```
{{7, 10}, {15, 22}}
```

## Вычисление обратной матрицы
```
Inverse[m]
```
Вывод
```
{{-2, 1}, {1.5, -0.5}}
```

## Поиск собственных значений и векторов
```
Eigensystem[m]
```
Вывод
```
{{5, 0}, {{1, 1}, {1, -1}}}
```

## Скалярное произведение векторов
```
{1, 2} . {3, 4}
```
Вывод
```
11
```

## Векторное произведение векторов
```
Cross[{1, 2, 3}, {4, 5, 6}]
```
Вывод
```
{-3, 6, -3}
```

## Вычисление длины вектора
```
Norm[{1, 2, 3}]
```
Вывод
```
√14
```

## Вычисление угла между векторами
```
ArcCos[{1, 2} . {3, 4}/(Norm[{1, 2}] Norm[{3, 4}])]
``` 

Вывод
```
ArcCos[11/(√5 √25)]
```

## Проекция вектора
```
{1, 2} . {3, 4}/Norm[{3, 4}] {3, 4}/Norm[{3, 4}]
```
Вывод
```
{11/5, 22/5}
```

## Вращение вектора
```
RotationMatrix[π/2].{1, 0}
```

Вывод
```
{0, 1}
```

## Параллельный перенос вектора
```
TranslationTransform[{1, 2}][{3, 4}]
```
Вывод
```
{4, 6}
```

## Масштабирование вектора
```
ScalingTransform[{2, 3}][{1, 1}]
```
Вывод
```
{2, 3}
```

## Отражение вектора
```
ReflectionTransform[{1, 1}][{1, 1}]
```
Вывод
```
{0, 0}
```

## Генерация случайных чисел
```
RandomReal[]
```
Вывод
```
0.123456
```

## Генерация случайных чисел (целые числа)
```
RandomInteger[]
```
Вывод
```
123456
```

## Генерация случайных чисел (с указанием диапазона)
```
RandomReal[{1, 10}]
```
Вывод
```
5.6789
```

## Генерация случайных чисел (целые числа, с указанием диапазона)
```
RandomInteger[{1, 10}]
```
Вывод
```
5
```

## Генерация случайных чисел (с указанием распределения)
```
RandomVariate[NormalDistribution[0, 1]]
```
Вывод
```
0.123456
```

## Генерация случайных чисел (с распределением и количеством)
```
RandomVariate[NormalDistribution[0, 1], 10]
```
Вывод
```
{0.123456, 0.234567, ..., 0.987654}
```

## Генерация случайных чисел (распределение, количество, seed)
```
SeedRandom[12345]
RandomVariate[NormalDistribution[0, 1], 10]
```
Вывод
```
{0.123456, 0.234567, ..., 0.987654}
```

## Применение функции к элементам массива
```
Map[Sqrt, {1, 4, 9}]
Sqrt /@ {1, 4, 9}
Map[#^(1/2)&, {1, 4, 9}]
```
Вывод
```
{1, 2, 3}
```

## Определение функции с помощью лямбда-выражения
```
f = Function[x, x^2]
f[3]
```
Вывод
```
9
```

## Композиция функций
```
f = Function[x, x^2]
g = Function[x, x + 1]
h = Function[x, f[g[x]]]
h[3]
```
Вывод
```
16
```

## Ссылка на результат предыдущего вычисления
```
% + 1
```
Вывод
```
17
```

## Чистые функции
```
(#+3)&[5]
```
Вывод
```
8
```

## Извлечение из массива
```
Select[{1, 2, 3, 4, 5}, EvenQ]
Select[{1, 2, 3, 4, 5}, Mod[#,2]==0&]
```
Вывод
```
{2, 4}
```
