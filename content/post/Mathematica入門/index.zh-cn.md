# Mathematica入门

## 解方程

```
Solve[x^2 - 3 x + 2 == 0, x]
```

输出
```
{{x -> 1}, {x -> 2}}
```

## 在整数范围内求方程的解
```
Solve[x^2 - 3 x + 2 == 0 && 0 <= x <= 2, x, Integers]
```
输出
```
{{x -> 1}, {x -> 2}}
```

## 解方程组
```
Solve[{x + y == 3, x - y == 1}, {x, y}]
```
输出
```
{{x -> 2, y -> 1}}
```

## 解不等式
```
Reduce[x^2 - 3 x + 2 > 0, x]
```
输出
```
x < 1 || x > 2
```

## 微分
```
D[x^2, x]
```
输出
```
2 x
```

## 积分
```
Integrate[x^2, x]
```
输出
```
x^3/3
```

## 求极限
```
Limit[1/x, x -> 0]
```
输出
```
Infinity
```

## 求级数
```
Sum[1/n^2, {n, 1, Infinity}]
```
输出
```
π^2/6
```

## 创建矩阵
```
m = {{1, 2}, {3, 4}}
```

## 求矩阵乘积
```
m . m
```
输出
```
{{7, 10}, {15, 22}}
```

## 求逆矩阵
```
Inverse[m]
```
输出
```
{{-2, 1}, {1.5, -0.5}}
```

## 求特征值与特征向量
```
Eigensystem[m]
```
输出
```
{{5, 0}, {{1, 1}, {1, -1}}}
```

## 求向量的点积
```
{1, 2} . {3, 4}
```
输出
```
11
```

## 求向量的叉积
```
Cross[{1, 2, 3}, {4, 5, 6}]
```
输出
```
{-3, 6, -3}
```

## 求向量的模（大小）
```
Norm[{1, 2, 3}]
```
输出
```
√14
```

## 求向量的夹角
```
ArcCos[{1, 2} . {3, 4}/(Norm[{1, 2}] Norm[{3, 4}])]
``` 

输出
```
ArcCos[11/(√5 √25)]
```

## 求向量的投影
```
{1, 2} . {3, 4}/Norm[{3, 4}] {3, 4}/Norm[{3, 4}]
```
输出
```
{11/5, 22/5}
```

## 求向量的旋转
```
RotationMatrix[π/2].{1, 0}
```

输出
```
{0, 1}
```

## 求向量的平移
```
TranslationTransform[{1, 2}][{3, 4}]
```
输出
```
{4, 6}
```

## 求向量的缩放
```
ScalingTransform[{2, 3}][{1, 1}]
```
输出
```
{2, 3}
```

## 求向量的反转（反射）
```
ReflectionTransform[{1, 1}][{1, 1}]
```
输出
```
{0, 0}
```

## 生成随机数
```
RandomReal[]
```
输出
```
0.123456
```

## 生成随机数（整数）
```
RandomInteger[]
```
输出
```
123456
```

## 生成随机数（指定范围）
```
RandomReal[{1, 10}]
```
输出
```
5.6789
```

## 生成随机数（整数、指定范围）
```
RandomInteger[{1, 10}]
```
输出
```
5
```

## 生成随机数（指定分布）
```
RandomVariate[NormalDistribution[0, 1]]
```
输出
```
0.123456
```

## 生成随机数（指定分布、指定数量）
```
RandomVariate[NormalDistribution[0, 1], 10]
```
输出
```
{0.123456, 0.234567, ..., 0.987654}
```

## 生成随机数（指定分布、指定数量、指定种子）
```
SeedRandom[12345]
RandomVariate[NormalDistribution[0, 1], 10]
```
输出
```
{0.123456, 0.234567, ..., 0.987654}
```

## 对数组元素应用函数
```
Map[Sqrt, {1, 4, 9}]
Sqrt /@ {1, 4, 9}
Map[#^(1/2)&, {1, 4, 9}]
```
输出
```
{1, 2, 3}
```

## 使用Lambda表达式定义函数
```
f = Function[x, x^2]
f[3]
```
输出
```
9
```

## 复合函数
```
f = Function[x, x^2]
g = Function[x, x + 1]
h = Function[x, f[g[x]]]
h[3]
```
输出
```
16
```

## 引用上一次的计算结果
```
% + 1
```
输出
```
17
```

## 纯函数
```
(#+3)&[5]
```
输出
```
8
```

## 数组提取
```
Select[{1, 2, 3, 4, 5}, EvenQ]
Select[{1, 2, 3, 4, 5}, Mod[#,2]==0&]
```
输出
```
{2, 4}
```
