# 🎬 Сценарий стрима на YouTube (Разработка приложения для создания новогодних открыток, Часть 1)

0. Начало трансляции (первые 2–3 минуты)

### Краткое приветствие
"Всем привет. С сегодняшнего дня я начинаю серию трансляций по постепенной разработке приложения для создания новогодних открыток на C++."
"Я пока не знаю, сколько стримов понадобится до завершения, но мы будем двигаться вперед шаг за шагом в формате серии."
"В основном я буду работать молча, поэтому надеюсь, что вы сможете смотреть это в качестве фона для своей работы."

### Обзор целевого приложения
"В этом приложении я хочу сделать возможным дизайн обратной стороны новогодних открыток."
"Я планирую добавить вставку фотографий, настройку шрифтов, использование ИИ для обработки изображений и генерации иллюстраций, и в конечном итоге загрузить его в Microsoft Store."

### Цели работы на сегодня
"Сегодня, в первой части, мы подготовим окружение и заложим основу."
"В частности:

- Создание GIT репозитория
- Создание главного окна
- Отображение диалогового окна информации о версии
- Создание меню и реализация команды выхода
- Инициализация и освобождение ресурсов Direct2D, а также отображение HelloWorld

Я планирую двигаться по этому списку."
