# 🎬 Guion para la transmisión de YouTube (Desarrollo de app de tarjetas de Año Nuevo - Parte 1)

0. Inicio de la transmisión (Primeros 2-3 minutos)

### Saludo breve
"Hola. Hoy comenzaremos a transmitir el desarrollo paso a paso de una aplicación para crear tarjetas de Año Nuevo en C++."
"No sé cuántas transmisiones tomará hasta completarlo, pero avanzaremos poco a poco como una serie."
"Básicamente, trabajaré en silencio, así que espero que puedan verlo como música de fondo (BGM) para trabajar."

### Descripción general de la aplicación deseada
"En esta aplicación, quiero que sea posible diseñar la parte posterior de la tarjeta de Año Nuevo."
"Planeamos incorporar la inserción de fotos, arreglos de fuentes y procesamiento de imágenes o generación de ilustraciones usando IA, y finalmente subirla a la Microsoft Store."

### Objetivos de trabajo de hoy
"Hoy, en la primera sesión, prepararemos el entorno y crearemos la base."
"Específicamente,

- Crear el repositorio GIT
- Crear la ventana principal
- Mostrar el diálogo de información de la versión
- Crear el menú e implementar el comando de salida
- Procesamiento de inicialización/liberación de Direct2D y visualización de HelloWorld

Me gustaría avanzar con esto."

### Sobre la publicación del código fuente
"El código fuente está publicado en GitHub. Si están interesados, echen un vistazo."
→ https://github.com/kenjinote/NengaCardApp/

1. Parte de trabajo (En silencio)

Crear repositorio en GitHub → Commit inicial

Crear plantilla de la ventana principal

Crear diálogo de versión, menú e implementar comando de salida

Procesamiento de inicialización y liberación de Direct2D → Confirmar visualización de HelloWorld

Hacer push a GitHub cuando sea apropiado

※ Básicamente en silencio, agregando explicaciones breves solo cuando sea necesario

2. Antes de finalizar la transmisión (Últimos 1-2 minutos)

### Resumen del progreso de hoy
"Hoy, creamos el repositorio GIT e implementamos la ventana, el botón de salida y el diálogo de versión."
"Llegamos hasta mostrar HelloWorld con Direct2D."

### Conexión con la próxima vez
"A partir de la próxima vez, espero avanzar con la organización de la interfaz de usuario, la objetivación de cadenas de texto, etc."

### Anunciar nuevamente el enlace de GitHub
→ https://github.com/kenjinote/NengaCardApp/

### Cierre
"Gracias por mirar. Continuaremos trabajando de manera constante la próxima vez, así que se los encargo."
