# 🎬 Naskah Siaran YouTube (Pengembangan Aplikasi Pembuatan Kartu Tahun Baru・Bagian 1)

0. Mulai Siaran (2-3 menit pertama)

### Sapaan Singkat
"Halo. Mulai hari ini, saya akan memulai siaran pengembangan aplikasi pembuatan kartu Tahun Baru dengan C++ sedikit demi sedikit."
"Saya tidak tahu berapa banyak siaran yang akan dilakukan sampai selesai, tapi kita akan maju secara bertahap sebagai sebuah seri."
"Pada dasarnya saya akan bekerja dalam diam, jadi saya harap Anda dapat menonton ini sebagai BGM untuk bekerja."

### Gambaran Umum Aplikasi yang Dituju
"Dalam aplikasi ini, saya ingin membuat desain sisi belakang kartu Tahun Baru menjadi mungkin."
"Saya berencana untuk menyertakan penyisipan foto, penyesuaian font, dan menggunakan AI untuk pemrosesan gambar dan pembuatan ilustrasi, serta pada akhirnya mengunggahnya ke Microsoft Store."

### Target Pekerjaan Hari Ini
"Hari ini, di bagian pertama, kita akan menyiapkan lingkungan dan membangun fondasi."
"Secara spesifik,

- Pembuatan repositori GIT
- Pembuatan jendela utama
- Menampilkan dialog informasi versi
- Pembuatan menu dan implementasi perintah keluar
- Inisialisasi dan pelepasan Direct2D serta menampilkan HelloWorld

Saya berencana untuk memajukan hal-hal ini."

### Tentang Publikasi Kode Sumber
"Kode sumber dipublikasikan di GitHub. Jika Anda tertarik, silakan lihat."
→ https://github.com/kenjinote/NengaCardApp/

1. Bagian Bekerja (Diam)

Membuat repositori GitHub → Komit awal (Initial commit)

Membuat cetakan jendela utama

Membuat dialog versi dan menu serta implementasi perintah keluar

Proses inisialisasi dan pelepasan Direct2D → Konfirmasi tampilan HelloWorld

Mendorong (Push) ke GitHub sesuai kebutuhan

※ Pada dasarnya diam, memberikan penjelasan singkat hanya saat dibutuhkan

2. Sebelum Akhir Siaran (1-2 menit terakhir)

### Ringkasan Kemajuan Hari Ini
"Hari ini, kita membuat repositori GIT, mengimplementasikan jendela, tombol keluar, dan dialog versi."
"Kita berhasil menampilkan HelloWorld menggunakan Direct2D."

### Menghubungkan ke Waktu Berikutnya
"Mulai waktu berikutnya, saya ingin merapikan bagian UI dan maju ke hal-hal seperti membuat objek dari string."
