# 🎬 YouTube 방송용 대본 (연하장 작성 앱 개발・제1회)

0. 방송 시작 (도입부 2~3분)

### 가벼운 인사
"안녕하세요. 오늘부터 연하장 작성 앱을 C++로 꾸준히 만들어가는 방송을 시작하겠습니다."
"완성까지 몇 번 방송하게 될지는 모르겠지만, 시리즈로 조금씩 진행해 나가겠습니다."
"기본적으로는 말없이 작업할 예정이므로, 작업용 BGM으로 봐주시면 감사하겠습니다."

### 목표로 하는 앱의 개요
"이 앱에서는 연하장의 뒷면을 디자인할 수 있도록 만들고자 합니다."
"사진 삽입이나 폰트 어레인지, AI를 사용한 이미지 가공이나 일러스트 생성도 도입하여, 최종적으로는 Microsoft Store에 업로드할 예정입니다."

### 오늘의 작업 목표
"제1회인 오늘은 환경을 정비하고 기반을 만들어 가겠습니다."
"구체적으로는,

- GIT 리포지토리 생성
- 메인 윈도우 생성
- 버전 정보 다이얼로그 표시
- 메뉴 생성 및 종료 명령 구현
- Direct2D의 초기화・해제 처리와 HelloWorld 표시

를 진행하고자 합니다."

### 소스 코드 공개에 대하여
"소스 코드는 GitHub에 공개하고 있습니다. 관심 있으신 분들은 꼭 한번 들여다봐 주세요."
→ https://github.com/kenjinote/NengaCardApp/

1. 작업 파트 (무언)

GitHub 리포지토리 생성 → 초기 커밋

메인 윈도우의 템플릿 생성

버전 다이얼로그나 메뉴 생성과 종료 명령 구현

Direct2D의 초기화와 해제 처리 → HelloWorld 표시 확인

적절히 GitHub에 push

※기본은 무언, 필요할 때만 짧게 해설을 넣음
