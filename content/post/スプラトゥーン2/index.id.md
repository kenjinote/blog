# Splatoon 2
Mungkin Splatoon 2 adalah game yang paling lama saya mainkan seumur hidup saya.
Saya hampir tidak memainkan mode ceritanya, tetapi matchmaking untuk pertandingan online 4 vs 4 sangat bagus, di mana saya bisa bermain melawan orang-orang dengan tingkat keterampilan yang sama,
sehingga memberikan keseruan yang tidak membosankan. Selain itu, menyenangkan juga membaca pergerakan lawan dan rekan setim untuk memikirkan strategi kemenangan.

# Senjata
Senjata yang sering saya gunakan, secara berurutan adalah "Foil Squeezer", "Splattershot Jr.", "Splat Roller", dan "Foil Flingza Roller".
"Splattershot Jr." adalah senjata untuk pemula, dan saya sering menggunakannya di awal permainan.

Poin tinta untuk masing-masing senjata ada di bawah ini.

# Tentang Level
Rasanya saya terus bergerak di antara A+ dan S+, dan terus berada dalam kondisi di mana saya tidak bisa naik ke posisi atas S+,
tetapi saya lebih menikmati pertandingannya daripada mencoba naik ke peringkat atas.
(Jika saya terlalu tinggi, lawan akan menjadi lebih kuat dan akan ada ketegangan, sehingga mengurangi keseruannya)

# Waktu Bermain
Waktu bermain saya sudah melebihi 2500 jam.

# Tujuan Masa Depan
Saya ingin mempertahankan level permainan dan memainkannya dengan menyenangkan, tetapi saya juga ingin mencapai batas maksimum untuk uang dan perlengkapan.
Sejak Splatoon 3 dirilis, matchmaking memakan waktu lebih lama atau tidak menemukan pertandingan sama sekali,
jadi saya ingin terus bermain sambil berharap jumlah pemain tidak berkurang lagi.
