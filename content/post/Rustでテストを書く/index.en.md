To write a test in Rust, create a function and add the `#[test]` attribute on the line above the test function definition.

```rust
fn plus(a:i32,b:i32)->i32 {
  a+b
}

#[test]
fn plus_test() {
  assert_eq!(plus(1, 1), 2);
}
```

You can run test codes with `cargo test`. If the test succeeds, it outputs `ok`.
If it fails, it outputs `FAILED`.
