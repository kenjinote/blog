## Excel 달력 템플릿 (공휴일 지원 버전)을 만들었습니다!

연도와 월을 입력하면 해당 월 달력의 공휴일이 표시되는 Excel 템플릿을 만들었습니다.

다운로드하여 사용해 주세요.
[カレンダー.xlsx](/downloads/excel-japan-holidays-calendar.xlsx)

## 호환성 및 데이터 출처

이 템플릿은 연도를 변경할 때 Excel의 `WEBSERVICE` 함수로 외부 서비스인 ExcelAPI에서 일본 공휴일을 가져옵니다. 인터넷 연결이 필요하며, 조회와 데이터 갱신은 해당 서비스의 이용 가능 여부에 따라 달라집니다. Microsoft 설명에 따르면 이 함수는 Windows 기능에 의존하므로 Excel for Mac에서는 결과를 반환하지 않습니다. Microsoft의 [WEBSERVICE 함수 문서](https://support.microsoft.com/en-us/excel/functions/webservice-function)와 [공휴일 목록 API 문서](https://excelapi.org/en/docs/datetime/holiday-list/)를 확인하세요.
