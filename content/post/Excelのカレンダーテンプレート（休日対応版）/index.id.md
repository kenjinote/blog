## Kompatibilitas dan sumber data

Saat tahun diubah, templat ini mengambil hari libur Jepang melalui fungsi `WEBSERVICE` Excel dan layanan eksternal ExcelAPI. Koneksi internet diperlukan; pengambilan dan pembaruan data bergantung pada ketersediaan layanan tersebut. Microsoft menyatakan fungsi ini bergantung pada fitur Windows dan tidak memberikan hasil di Excel untuk Mac. Lihat [dokumentasi fungsi WEBSERVICE dari Microsoft](https://support.microsoft.com/en-us/excel/functions/webservice-function) dan [dokumentasi API daftar hari libur](https://excelapi.org/en/docs/datetime/holiday-list/).
