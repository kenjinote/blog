# Usar plantillas web de HTML5 UP

Partir de una plantilla bien diseñada permite probar antes la estructura y el aspecto de un sitio que si se construye cada página desde cero. HTML5 UP publica plantillas adaptables creadas con HTML5 y CSS3. El catálogo y la disponibilidad pueden cambiar; consulta el [sitio oficial](https://html5up.net/) para ver las opciones actuales.

## Elegir una plantilla

Abre la demostración en vivo de los diseños que te interesen y revisa la navegación, la estructura de las páginas y su aspecto en un teléfono. Comprueba también si puedes incorporar las páginas y funciones que necesitas sin rehacer demasiado.

## Descargar y personalizar

Usa el enlace «Free Download» del sitio, revisa los archivos HTML, CSS e imágenes y sustituye el contenido de demostración por el tuyo. Considera la descarga como un punto de partida: elimina los textos y enlaces de ejemplo que no correspondan y revisa cada página en los tamaños de pantalla que usan tus visitantes.

## Licencia y atribución

HTML5 UP publica sus plantillas con la licencia Creative Commons Attribution 3.0 (CC BY 3.0), que permite el uso personal y comercial y las modificaciones. Acredita el diseño al utilizarlo. Lee la [licencia oficial](https://html5up.net/license) y comprueba también las licencias de los recursos o bibliotecas independientes incluidos en la descarga.
