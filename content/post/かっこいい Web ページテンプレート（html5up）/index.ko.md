# HTML5 UP 웹사이트 템플릿 사용하기

잘 만들어진 템플릿에서 시작하면 모든 페이지를 처음부터 만들 때보다 레이아웃과 디자인을 빠르게 시험할 수 있습니다. HTML5 UP은 HTML5와 CSS3로 만든 반응형 웹사이트 템플릿을 제공합니다. 목록과 배포 상태는 바뀔 수 있으므로 최신 목록은 [공식 사이트](https://html5up.net/)에서 확인하세요.

## 템플릿 고르기

마음에 드는 디자인의 라이브 데모를 열어 내비게이션, 페이지 구성, 휴대전화에서의 표시를 살펴보세요. 필요한 페이지와 기능을 큰 구조 변경 없이 넣을 수 있는지도 확인합니다.

## 다운로드하고 수정하기

사이트의 “Free Download” 링크로 파일을 받은 뒤 HTML, CSS, 이미지 구성을 살펴보고 데모 내용을 자신의 내용으로 바꿉니다. 다운로드 파일은 출발점입니다. 필요 없는 예시 문구와 링크를 지우고 방문자가 사용하는 화면 크기에서 각 페이지를 확인하세요.

## 라이선스와 출처 표시

HTML5 UP 템플릿은 개인 및 상업적 이용과 수정이 허용되는 Creative Commons Attribution 3.0(CC BY 3.0)으로 제공됩니다. 사용할 때 디자인 출처를 표시하세요. 자세한 조건은 [공식 라이선스](https://html5up.net/license)를 확인하고, 다운로드에 별도 리소스나 라이브러리가 들어 있다면 해당 라이선스도 살펴보세요.
