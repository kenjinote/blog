# 使用 HTML5 UP 网站模板

从设计成熟的模板开始，可以比从零制作每个页面更快地尝试网站布局和视觉效果。HTML5 UP 发布使用 HTML5 和 CSS3 构建的响应式网站模板。目录和下载情况可能变化，请到[官方网站](https://html5up.net/)查看当前列表。

## 选择模板

打开感兴趣设计的在线演示，检查导航、页面结构以及手机上的显示效果。也要考虑所需页面和功能能否融入模板，而不必进行大量重构。

## 下载并定制

点击网站上的“Free Download”获取文件，查看 HTML、CSS 和图片，再用自己的内容替换演示内容。把下载文件当作起点：删除不适用的示例文字和链接，并在访客常用的屏幕尺寸下检查每个页面。

## 许可与署名

HTML5 UP 的模板采用 Creative Commons Attribution 3.0（CC BY 3.0）许可，允许个人和商业使用，也允许修改。使用时请注明设计来源。请阅读[官方许可说明](https://html5up.net/license)；如果下载包还包含独立素材或库，也要检查它们各自的许可。
