# HTML5 UPのWebテンプレートを使う

Webサイトを一から組み立てる代わりに、完成度の高いテンプレートを土台にすると、レイアウトや見た目の検討を早く始められます。HTML5 UPでは、HTML5とCSS3を使ったレスポンシブなサイトテンプレートを公開しています。掲載内容や配布状況は変わるため、最新の一覧は[公式サイト](https://html5up.net/)で確認してください。

## テンプレートを選ぶ

一覧から気になるデザインのライブデモを開き、ナビゲーション、ページ構成、スマートフォンでの見え方を確かめます。見た目だけでなく、自分のサイトに必要なページや機能を無理なく組み込めるかも確認しましょう。

## ダウンロードして編集する

公式サイトの「Free Download」からファイルを取得し、HTML、CSS、画像などの構成を確認してから自分の内容に置き換えます。テンプレートは出発点です。公開前に不要なデモ文言やリンクを整理し、各ページを実際の画面幅で確認してください。

## ライセンスとクレジット

HTML5 UPはテンプレートをCreative Commons Attribution 3.0（CC BY 3.0）で提供しており、個人・商用利用や改変ができます。利用時はデザインのクレジットを表示してください。詳しい条件は[公式ライセンス](https://html5up.net/license)を読み、配布物に別の素材やライブラリが含まれる場合は、それぞれのライセンスも確認しましょう。
