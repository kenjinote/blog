# 使用 HTML5 UP 網站範本

從設計成熟的範本開始，可以比從頭製作每個頁面更快地嘗試網站版面與視覺效果。HTML5 UP 提供以 HTML5 和 CSS3 建置的響應式網站範本。目錄和下載狀態可能變動，請前往[官方網站](https://html5up.net/)查看目前的清單。

## 挑選範本

開啟感興趣設計的線上展示，檢查導覽、頁面結構，以及手機上的呈現方式。也要確認所需頁面與功能能否融入範本，而不必大幅重做。

## 下載並自訂

使用網站上的「Free Download」連結取得檔案，檢視 HTML、CSS 和圖片，再將展示內容換成自己的內容。把下載檔案當作起點：移除不適用的示範文字和連結，並在訪客常用的螢幕尺寸下檢查每個頁面。

## 授權與標示

HTML5 UP 的範本採用 Creative Commons Attribution 3.0（CC BY 3.0）授權，允許個人與商業用途，也可修改。使用時請標示設計來源。請閱讀[官方授權說明](https://html5up.net/license)；若下載內容另含素材或程式庫，也要確認各自的授權條款。
