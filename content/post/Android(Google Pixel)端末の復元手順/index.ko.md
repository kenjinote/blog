# Google 공식 도구로 Pixel 소프트웨어 업데이트 또는 재설치하기

> **데이터 삭제 중요 안내(2026년 11월 23일 확인):** Google 도구에는 **Update**와 **Reinstall**이 있습니다. Update는 초기화 없이 최신 소프트웨어를 설치할 수 있는 경우가 있습니다. Reinstall은 휴대전화를 초기화하고 데이터를 삭제합니다. 실행 전에 백업하고 Google 계정 정보를 확인하세요. Google의 현재 도움말은 Pixel 4a 이후 모델(Fold 포함)을 지원 대상으로 안내합니다. 최신 지원 범위와 도구의 화면 안내를 확인하세요.

[Pixel Update and Software Repair](https://pixelrepair.withgoogle.com/)는 지원되는 Pixel 기기의 공식 업데이트·재설치 도구입니다. 모든 부팅 반복이나 시작 문제를 해결한다고 보장하지는 않습니다. 초기화 전에는 재시작, Android 업데이트, 안전 모드, 저장 공간 확인 등 Google의 [공식 문제 해결 방법](https://support.google.com/pixelphone/answer/4582729)을 먼저 시도하세요.

## 1. 지원 기기 확인

[공식 도구](https://pixelrepair.withgoogle.com/)에서 기기에 제공되는 작업을 확인하세요. 지원 여부와 옵션은 모델이나 지역에 따라 다를 수 있으므로 도구와 [Google 공식 도움말](https://support.google.com/pixelphone/answer/4596836)의 최신 안내를 따르세요.

## 2. 시작 전 준비

- 휴대전화를 사용할 수 있다면 데이터를 백업하고 Google 계정 비밀번호와 화면 잠금 정보를 확인하세요.
- 데이터 전송을 지원하는 USB 케이블과 컴퓨터를 준비하고 가능하면 직접 연결하세요.
- 초기화한다면 Google의 일반 안내는 배터리를 70% 이상 충전하도록 권장합니다. 도구에 다른 조건이 표시되면 그 안내를 따르세요.
- Windows에서 기기를 인식하지 못할 때는 필요한 경우 Google의 공식 [USB 드라이버 안내](https://developer.android.com/studio/run/win-usb)를 확인하세요.

## 3. 연결하고 화면 안내 따르기

1. 컴퓨터에서 [Pixel Update and Software Repair](https://pixelrepair.withgoogle.com/)를 엽니다.
2. 도구가 요청하면 휴대전화의 전원을 끕니다. 현재 안내는 전원과 볼륨 크게 버튼을 길게 눌러 전원을 끄는 방법입니다.
3. 전원과 볼륨 작게 버튼을 약 3초간 함께 눌러 Fastboot 모드로 들어갑니다. 모델별 안내가 다르면 화면 지침을 따르세요.
4. USB로 연결하고 **Connect device**를 눌러 올바른 기기를 선택합니다. 이름을 확인한 뒤 브라우저 연결을 허용하세요.
5. **Update** 또는 **Reinstall**을 선택합니다. Update는 데이터를 보존할 수도 있습니다. Reinstall은 초기화하고 데이터를 삭제하므로 백업 후에만 선택하세요. 처리 중에는 케이블을 분리하지 마세요.

도구가 연결되지 않거나 휴대전화가 계속 시작되지 않으면 설치를 반복하지 말고 Google의 [공식 Pixel 지원 안내](https://support.google.com/pixelphone/answer/4596836)를 확인하세요.

## 요약

작업 전에 도구와 Google 도움말의 최신 안내를 확인하세요. Update와 Reinstall은 데이터에 미치는 영향이 다르며, Reinstall은 데이터를 삭제합니다. 초기화 전에 백업하고 계정 정보를 확인하세요.
