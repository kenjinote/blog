# परिचय
Go एक अपेक्षाकृत नई प्रोग्रामिंग भाषा है जिसे Google ने 2009 में जारी किया था।
Go के कंपाइलर, टूल और लाइब्रेरी ओपन सोर्स के रूप में उपलब्ध हैं।
इसके अलावा, Go, C या Java जैसी एक स्टैटिकली टाइप्ड भाषा है, लेकिन यह C भाषा की तरह पॉइंटर्स का उपयोग नहीं करती है।

# पहला प्रोग्राम

निम्नलिखित प्रोग्राम को `hello.go` के रूप में सेव करें।

```go
package main

import "fmt"

func main() {
  fmt.Printf("Hello World\n")
}
```

कमांड प्रॉम्प्ट या टर्मिनल से `go run hello.go` चलाने पर, `Hello, world!` आउटपुट होगा।

कंपाइल करने के लिए, `go build hello.go` चलाने पर `hello.exe` उत्पन्न होगा।
`hello.exe` चलाने पर, `Hello, world!` आउटपुट होगा।

# जापानी दस्तावेज़

[http://go.shibu.jp/](http://go.shibu.jp/)

Go सीखने के लिए आवश्यक स्पष्टीकरण उपरोक्त लिंक (जापानी अनुवाद संस्करण) में समेकित किए गए हैं।
Go से संबंधित तकनीक इतनी खुली और समृद्ध है कि पेपर टेक्स्ट खरीदने की लगभग कोई आवश्यकता नहीं है।

तो फिर, अपने Go जीवन का आनंद लें!
