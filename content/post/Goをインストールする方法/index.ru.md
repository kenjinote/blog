# Введение
Go - это относительно новый язык программирования, выпущенный Google в 2009 году.
Компилятор, инструменты и библиотеки Go имеют открытый исходный код.
Кроме того, Go - это язык со статической типизацией, как C или Java, но он не использует указатели, как C.

# Первая программа

Сохраните следующую программу как `hello.go`.

```go
package main

import "fmt"

func main() {
  fmt.Printf("Hello World\n")
}
```

Когда вы запустите `go run hello.go` из командной строки или терминала, будет выведено `Hello, world!`.

Если вы хотите скомпилировать, запуск `go build hello.go` создаст `hello.exe`.
Запуск `hello.exe` выведет `Hello, world!`.
