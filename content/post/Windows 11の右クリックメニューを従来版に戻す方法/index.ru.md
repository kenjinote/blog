# Открытие классического контекстного меню в Windows 11

В Windows 11 щёлкните элемент правой кнопкой мыши и выберите «Показать дополнительные параметры», чтобы открыть классическое контекстное меню. Также можно выбрать элемент и нажать `Shift`+`F10` либо удерживать `Shift` при щелчке правой кнопкой, чтобы открыть «Показать дополнительные параметры». Сначала используйте встроенные способы.

> Изменение реестра ниже — неофициальный обходной способ, позволяющий сделать классическое меню основным. Это не поддерживаемая Microsoft процедура, и в некоторых версиях Windows она может не работать. Перед изменением создайте резервную копию реестра.

## Шаги обходного способа с реестром

1. Откройте Редактор реестра.

Нажмите `Win` + `R`, введите `regedit` и нажмите `Enter`.
![img_1.png](img_1.webp)　

2. Перейдите к `HKEY_CURRENT_USER\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}`. Если этого ключа нет, создайте его.


3. Перейдите к `HKEY_CURRENT_USER\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32`. Если этого ключа нет, создайте его.
4. Убедитесь, что значение `(По умолчанию)` в `InprocServer32` пустое.

![img_2.png](img_2.webp)

5. Перезагрузите компьютер.
6. Убедитесь, что контекстное меню вернулось к классическому виду.

Чтобы отменить изменение, удалите созданный вами раздел `{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}` и перезапустите Проводник. Перед изменением существующих параметров сохраните их резервную копию.
