# 使用 CS Academy Graph Editor 繪製圖論圖形

[CS Academy Graph Editor](https://csacademy.com/app/graph_editor/) 是一款可在瀏覽器中呈現圖論頂點與邊的工具。

下圖是本文保存的操作範例。在頁面的輸入區指定圖形資料，選擇 `Directed` 建立有向圖，用滑鼠調整頂點位置，再透過 `Download as PNG` 儲存圖片。
