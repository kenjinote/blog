# Создание графов в CS Academy Graph Editor

[CS Academy Graph Editor](https://csacademy.com/app/graph_editor/) — браузерный инструмент для визуализации вершин и рёбер из теории графов.

На изображении ниже показан пример, сохранённый вместе со статьёй. Введите данные графа на странице, выберите `Directed`, чтобы создать ориентированный граф, переместите вершины мышью и сохраните изображение через `Download as PNG`.

![Пример ориентированного графа, сохранённого в PNG](img_1.webp)

> **Примечание о проверке (24 ноября 2026 г.):** Страница инструмента вернула сообщение с просьбой включить JavaScript. Автоматический просмотр только текста не позволил проверить текущий интерфейс и работу функций. Описание выше основано на сохранённом изображении и прежнем тексте статьи; текущая страница может отличаться.
