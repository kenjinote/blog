# 使用 CS Academy Graph Editor 绘制图论图形

[CS Academy Graph Editor](https://csacademy.com/app/graph_editor/) 是一款在浏览器中可视化图论顶点和边的工具。

下图是本文保存的操作示例。在页面的输入区指定图数据，选择 `Directed` 创建有向图，用鼠标调整顶点位置，再通过 `Download as PNG` 保存图片。
