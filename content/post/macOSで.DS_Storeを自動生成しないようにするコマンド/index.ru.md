Apple описывает эту настройку как способ ускорить просмотр SMB-ресурсов: macOS будет **не читать файлы `.DS_Store` на SMB-ресурсах**. Это не запрещает создание новых файлов и не удаляет уже существующие. Отображение и сортировка в Finder могут измениться.

### Отключить чтение на SMB-ресурсах

Выполните эту команду в Terminal:

```bash
defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool TRUE
```

Чтобы изменение вступило в силу, выйдите из учётной записи macOS и войдите снова. При показе папок Finder будет использовать основные сведения, а не метаданные `.DS_Store`.

### Снова включить чтение

Установите значение `FALSE`, чтобы вернуть поведение по умолчанию:

```bash
defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool FALSE
```

Затем выйдите из учётной записи и войдите снова. Apple описывает этот параметр как настройку просмотра SMB-ресурсов и указывает, что руководство предназначено прежде всего для администраторов организаций и учебных заведений. См. [поддержку Apple](https://support.apple.com/en-us/102064).
