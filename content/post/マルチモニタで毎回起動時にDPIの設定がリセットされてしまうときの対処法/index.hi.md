※ यह Windows 11 के लिए सेटअप प्रक्रिया है।

1. कंट्रोल पैनल खोलें
2. पावर ऑप्शंस चुनें
3. "पावर बटन क्या करते हैं, चुनें" पर क्लिक करें
4. "वर्तमान में अनुपलब्ध सेटिंग्स बदलें" पर क्लिक करें
5. "तेज़ स्टार्टअप चालू करें (अनुशंसित)" को अनचेक करें
6. "परिवर्तन सहेजें" पर क्लिक करें
