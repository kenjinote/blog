※ Il s'agit de la procédure de configuration pour Windows 11.

1. Ouvrez le Panneau de configuration
2. Sélectionnez Options d'alimentation
3. Cliquez sur "Choisir l'action des boutons d'alimentation"
4. Cliquez sur "Modifier des paramètres actuellement non disponibles"
5. Décochez "Activer le démarrage rapide (recommandé)"
6. Cliquez sur "Enregistrer les modifications"
