# Оптимизированные параметры преобразования ffmpeg для iOS

Представляем команду `ffmpeg` для преобразования видео, чтобы оно плавно воспроизводилось на устройствах iOS (iPhone и iPad).

```bash
ffmpeg -i input.mp4 \
-c:v libx264 -profile:v high -level 4.1 \
-vf "scale=1920:-2" -r 30 \
-crf 20 -preset slow \
-c:a aac -b:a 128k -ar 48000 \
-movflags +faststart output.mp4
```

### Значение каждого параметра (краткое объяснение)

| Параметр | Описание |
| ---------------------------- | ------------------------------------------- |
| `-i input.mp4` | Входной файл (исходное видео) |
| `-c:v libx264` | Кодирование видео в H.264 (поддерживается iOS) |
| `-profile:v high -level 4.1` | Широко совместимый профиль и уровень для iOS |
| `-vf "scale=1920:-2"` | Изменение размера до 1920 пикселей по ширине, высота настраивается автоматически с сохранением соотношения сторон |
| `-r 30` | Преобразование частоты кадров в 30 кадров в секунду |
| `-crf 20` | Качество видео (чем ниже значение, тем выше качество, рекомендуется 18–23) |
| `-preset slow` | Баланс между скоростью кодирования и степенью сжатия (slow — высокое сжатие и качество) |
| `-c:a aac` | Кодирование звука в формате AAC |
| `-b:a 128k` | Установка битрейта звука 128 кбит/с |
| `-ar 48000` | Установка частоты дискретизации звука 48 кГц (рекомендуется для iOS) |
| `-movflags +faststart` | Помещает индекс в начало видео, чтобы ускорить ** потоковое воспроизведение в Интернете и на iOS ** |

---

Ожидается, что видео, преобразованные с этими настройками, будут иметь высокую совместимость и плавное воспроизведение на устройствах Apple, таких как iPhone и iPad.

---

При необходимости вы можете настроить размер файла и качество изображения, изменив разрешение или битрейт. Если вам нужно высокое качество, попробуйте установить `-crf` около 18, а если вы хотите уменьшить размер файла, установите его на 22–25.
