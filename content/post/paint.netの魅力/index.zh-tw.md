# Paint.NET 的功能、用途與下載方式

Paint.NET 是 Windows 的影像與相片編輯軟體。本文整理我在開發工作中使用過的功能，以及目前的取得方式。功能與需求可能更新，安裝前請查看官方頁面。

## Paint.NET 可以做什麼

- 使用圖層合成與編輯影像
- 以魔術棒依相近色彩選取區域，或進行更精確的選取
- 調整亮度、對比、色相、飽和度、色階與曲線
- 套用模糊、銳化、紅眼修正、扭曲、雜訊等效果
- 支援 PNG、JPEG、WebP、AVIF、TIFF 等常見格式；外掛程式可增加格式與效果
- 透過歷程記錄復原與重做編輯

## 與 Microsoft Paint 的差異

Windows 11 的 Microsoft Paint 也支援圖層與透明 PNG。可以嘗試 Paint.NET 的原因包括魔術棒、仿製印章、曲線調整、色彩管理與外掛擴充等工具。功能可能因版本而異，請查看官方功能清單。

## 下載與更新

官方下載頁提供免費的傳統版，以及付費的 Microsoft Store 版。傳統版可在應用程式內更新；Store 版會透過 Microsoft Store 在背景更新。Store 版價格可能因地區而異。請確認 Price 欄顯示 Free 或 Paid，再選擇合適的發行方式。下載選項可能變更，請以目前官方頁面為準，不要依賴舊截圖。

## 查看系統需求

目前官方需求列出 Windows 11、Windows 10 21H2 或更新版本等系統，另有 64 位元 CPU、支援 Direct3D 11 的 GPU 與儲存裝置條件。安裝前請查看官方[系統需求](https://paint.net/doc/latest/SystemRequirements.html)。效能也會受到電腦、影像大小與編輯操作影響。
