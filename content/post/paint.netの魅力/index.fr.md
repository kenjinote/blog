Je vais vous présenter le logiciel de retouche d'images paint.net, que j'utilise souvent dans mon travail de développement.

![img_1.png](img_1.png)

# Points utiles impossibles avec Paint de Windows
- Peut gérer la transparence et l'opacité
- Peut effectuer une sélection automatique de formes de zones complexes
- Peut gérer les calques
- Peut ajuster la correction de niveau, la luminosité, le contraste, etc.
- Peut appliquer divers effets (flou, distorsion, bruit, etc.)

# Autres caractéristiques
- Utilisation gratuite
- Fonctionnement relativement léger
- Intuitif à utiliser et n'a pas beaucoup de particularités
- Japonais (support multilingue)

C'est un logiciel très fonctionnel mais facile à utiliser. Je ne maîtrise pas encore moi-même toutes les fonctionnalités.

# Installer ici
[https://www.getpaint.net/download.html](https://www.getpaint.net/download.html)

Si vous choisissez la version gratuite, veuillez cliquer sur la partie encadrée en rouge ci-dessous dans le lien.

![img_2.png](img_2.png)

Il semble que si vous l'installez via le Microsoft Store, cela deviendra payant, mais en contrepartie, les mises à jour automatiques seront possibles.
Même avec la version gratuite, il vous informera des dernières informations de mise à jour, vous pouvez donc le mettre à jour assez facilement.
