# Paint.NET: funciones, usos y opciones de descarga

Paint.NET es un editor de imágenes y fotografías para Windows. Este artículo resume las herramientas que he usado en tareas de desarrollo y las formas actuales de obtener la aplicación. Las funciones y los requisitos cambian; consulta las páginas oficiales antes de instalarla.

## Qué puedes hacer con Paint.NET

- Componer y editar imágenes con capas
- Seleccionar zonas por similitud de color con la varita mágica o hacer selecciones más precisas
- Ajustar brillo, contraste, tono, saturación, niveles y curvas
- Aplicar efectos como desenfoque, nitidez, eliminación de ojos rojos, distorsión y ruido
- Abrir formatos comunes como PNG, JPEG, WebP, AVIF y TIFF; los complementos pueden añadir formatos y efectos
- Deshacer y rehacer ediciones con el historial

## Diferencias con Microsoft Paint

Microsoft Paint en Windows 11 también admite capas y PNG transparentes. Algunas razones para probar Paint.NET son herramientas como la varita mágica y el tampón de clonar, los ajustes de curvas, la gestión del color y las extensiones. Las funciones pueden variar según la versión; consulta la lista oficial.

## Descarga y actualizaciones

La página oficial ofrece una versión clásica gratuita y otra de pago en Microsoft Store. La versión clásica se actualiza desde la aplicación; la de Store se actualiza en segundo plano mediante Microsoft Store. El precio de Store puede variar según la región. Comprueba si la columna Price indica Free o Paid y elige la distribución adecuada. Consulta la página actual, no capturas antiguas, para identificar la descarga.

## Consulta los requisitos del sistema

Los requisitos actuales indican Windows 11 y Windows 10 versión 21H2 o posterior, entre otros sistemas compatibles. También hay requisitos para la CPU de 64 bits, una GPU compatible con Direct3D 11 y el almacenamiento. Consulta los [requisitos oficiales](https://paint.net/doc/latest/SystemRequirements.html) antes de instalar. El rendimiento depende del equipo, el tamaño de la imagen y las operaciones realizadas.
