Les presento paint.net, un software de edición de imágenes que utilizo a menudo durante mis tareas de desarrollo.

![img_1.png](img_1.png)

# Puntos valiosos que no se pueden hacer con Paint estándar de Windows
- Puede manejar transparencias y niveles de opacidad
- Puede realizar selecciones automáticas de formas complejas
- Puede manejar capas
- Puede ajustar niveles, brillo, contraste, etc.
- Puede aplicar varios efectos (desenfoque, distorsión, ruido, etc.)

# Otras características
- Se puede usar de forma gratuita
- El funcionamiento es relativamente ligero
- Uso intuitivo y sin muchas peculiaridades
- Soporte multilingüe

Es un software avanzado pero fácil de usar. Yo mismo aún no he dominado todas sus funciones.

# Instálalo aquí
[https://www.getpaint.net/download.html](https://www.getpaint.net/download.html)

Si deseas elegir la versión gratuita, haz clic en la parte enmarcada en rojo del enlace a continuación.

![img_2.png](img_2.png)

Si lo instalas a través de Microsoft Store tiene un costo, pero a cambio permite actualizaciones automáticas.
Incluso con la versión gratuita, te notifica sobre la información de actualización más reciente, por lo que puedes actualizar de manera muy sencilla.
