# Paint.NET 的功能、用途与下载方式

Paint.NET 是面向 Windows 的图像和照片编辑软件。本文整理我在开发工作中使用过的功能以及当前的获取方式。功能和系统要求会变化，安装前请查看官方页面。

## Paint.NET 可以做什么

- 使用图层合成和编辑图像
- 使用魔棒按相似颜色选区，也可进行更精确的选取
- 调整亮度、对比度、色相、饱和度、色阶和曲线
- 应用模糊、锐化、红眼修复、扭曲、噪点等效果
- 支持 PNG、JPEG、WebP、AVIF、TIFF 等常见格式；插件可扩展格式和效果
- 通过历史记录撤销和重做编辑

## 与 Microsoft Paint 的区别

Windows 11 的 Microsoft Paint 也支持图层和透明 PNG。可以尝试 Paint.NET 的理由包括魔棒、克隆图章、曲线调整、色彩管理和插件扩展等工具。功能可能因版本而异，请查看官方功能列表。

## 下载与更新

官方页面提供免费的经典版本和付费的 Microsoft Store 版本。经典版在应用内更新；Store 版通过 Microsoft Store 在后台更新。Store 版价格可能因地区而异。请查看价格栏中的 Free 或 Paid，选择合适的发行方式。下载选项可能会变化，请以当前官方页面为准，不要依赖旧截图。

## 查看系统要求

当前官方要求列出 Windows 11、Windows 10 21H2 或更高版本等系统，并对 64 位 CPU、支持 Direct3D 11 的 GPU 和存储设备有要求。安装前请查看官方[系统要求](https://paint.net/doc/latest/SystemRequirements.html)。运行表现也会受电脑、图片尺寸和编辑操作影响。
