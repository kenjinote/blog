Ниже приведены пять известных математических результатов с точными условиями. $p,n,k$ — целые числа, $i^2=-1$, а $\\pi$ — число пи.

## Теорема Вильсона

Для простого числа $p$ выполняется $(p-1)!\equiv -1 \pmod p$. Точнее, целое число $m>1$ является простым тогда и только тогда, когда $(m-1)!\equiv -1 \pmod m$. Здесь $r!$ — произведение целых чисел от 1 до $r$.

## Формула и тождество Эйлера

Для вещественного $x$, измеряемого в радианах, формула Эйлера имеет вид $e^{ix}=\cos x+i\sin x$. При $x=\pi$ получается частный случай — тождество Эйлера: $e^{i\pi}+1=0$.

## [Великая теорема Ферма](https://kenji.blog/ru/p/fermat/)

Для любого целого $n\ge 3$ не существует положительных целых чисел $x,y,z$, удовлетворяющих равенству $x^n+y^n=z^n$. Условия положительности и показателя не меньше 3 существенны.

## Базельская задача

Бесконечная сумма обратных квадратов всех положительных целых чисел равна $\displaystyle \sum_{k=1}^{\infty}\frac{1}{k^2}=\frac{\pi^2}{6}$.

## Многочлен Эйлера для порождения простых чисел

Многочлен $n^2+n+41$ дает простое число при целых $n=0,1,\ldots,39$. Это неверно для всех целых чисел: при $n=40$ значение равно $1681=41^2$, то есть является составным.
