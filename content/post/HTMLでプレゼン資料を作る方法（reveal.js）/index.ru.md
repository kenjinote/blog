# Как создать презентацию с помощью HTML

reveal.js — это инструмент для создания презентаций с использованием HTML и Markdown, который обладает следующими функциями:

- Разнообразные функции презентации, такие как математические формулы, анимации и управление смахиванием
- Возможность настройки тем и макетов
- Функции навигации, поддерживающие несколько устройств, такие как мышь, клавиатура и сенсорная панель
- Предоставление расширенных функций, таких как автовоспроизведение слайдов и встраивание видео
- Возможность экспорта в формат PDF

Благодаря этим функциям пользователи могут легко создавать интерактивные и привлекательные презентации.

# Установка и использование reveal.js

Самый простой способ использования — скачать весь ZIP-архив со следующей страницы и распаковать его.

1. Откройте [https://revealjs.com/installation](https://revealjs.com/installation) и скачайте `master.zip` по ссылке
2. Откройте index.html из распакованной папки в браузере
3. Отредактируйте index.html, чтобы создать свою собственную презентацию

※ Демонстрационный HTML-код написан в demo.html, так что вы можете использовать его в качестве справки.

# Способы применения

Созданную презентацию можно опубликовать как веб-страницу без изменений или экспортировать в виде PDF.
Кроме того, поскольку исходный код презентации — это текст, им легко управлять с помощью систем контроля версий.

Кажется, презентации также можно создавать в формате Markdown.

# Создание простых слайдов

Проще всего скачать последнюю ZIP-версию Basic Setup, распаковать её и отредактировать `index.html`. Как в примере HTML ниже, поместите каждый слайд в `<section>`. В демонстрационный файл Basic Setup уже включены нужные стили и код инициализации.

```html
<div class="reveal">
  <div class="slides">
    <section>Slide 1</section>
    <section>Slide 2</section>
    <section>Reveal this item <span class="fragment">when activated</span></section>
  </div>
</div>
```

# Слайды в формате Markdown

Встроенный плагин Markdown позволяет писать Markdown прямо в HTML-файле. Разделяйте горизонтальные слайды с помощью `---` и добавьте пример ниже в `index.html`. Для загрузки внешнего файла Markdown нужен локальный веб-сервер.

```html
<section data-markdown>
  <textarea data-template>
## Slide 1
---
## Slide 2
  </textarea>
</section>
```

# Настройка разработки

Если нужны локальный сервер или инструменты для разработки исходного кода, используйте официальный Full Setup. Выполните команды ниже, затем откройте в браузере `http://localhost:8000`.

```sh
git clone https://github.com/hakimel/reveal.js.git
cd reveal.js
npm install
npm start
```

# Экспорт в PDF

Добавьте `?print-pdf` в конец URL. В окне печати Chrome или Chromium выберите сохранение в PDF, альбомную ориентацию, отсутствие полей и включение фоновой графики. В официальном руководстве подтверждены Chrome и Chromium.

# Заметки докладчика

Нажмите `S`, чтобы открыть режим докладчика в отдельном окне. Добавляйте заметки в `<aside class="notes">` на слайде. Для локального режима докладчика нужен веб-сервер.

```html
<section>
  <h2>Slide</h2>
  <aside class="notes">Notes visible to the presenter only</aside>
</section>
```
