## Catatan lisensi

Tautan dan informasi lisensi diperiksa pada 24 November 2026. Google Material Symbols menggunakan Apache License 2.0; GitHub Octicons dan Sargam Icons menggunakan MIT License. Ikon Open Iconic menggunakan MIT License, sedangkan font-nya menggunakan SIL Open Font License.

Lisensi gratis Icon-Icons mewajibkan atribusi kepada pembuat. Flaticon menawarkan paket gratis dan berbayar; ketentuannya dapat berbeda menurut paket dan format, jadi periksa informasi terbaru saat mengunduh. Lisensi Iconfinder berbeda untuk setiap ikon, dan label penggunaan komersial dapat memiliki syarat tambahan. Di iconfont, periksa pembuat dan lisensi setiap koleksi.

Sebelum menggunakan ikon secara komersial, baca lisensi file yang dipakai, termasuk kewajiban atribusi dan batasan redistribusi. Logo dan merek perusahaan dapat memiliki aturan terpisah dari lisensi aset ikon.
