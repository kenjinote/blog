# Extensions Chrome Recommandées

Voici les extensions Chrome que j'utilise actuellement. Bien qu'elles soient pour Chrome, elles fonctionnent également sur Microsoft Edge.

## 1. simpleGestures

![img_2.png](img_2.png)

C'est une extension qui vous permet d'utiliser les gestes de la souris.
Vous pouvez contrôler le navigateur sans utiliser le clavier ni viser les boutons de la barre d'outils.

Par exemple, vous pouvez revenir en arrière en faisant glisser la souris vers la gauche tout en maintenant le bouton droit enfoncé, ou avancer en faisant glisser vers la droite avec le bouton droit maintenu.

Comme elle est open source, elle est également très fiable.

- [simpleGestures](https://chrome.google.com/webstore/detail/simplegestures/flfminafiamnggnldfpilnfnmbgmiegn)
- [github](https://github.com/RyutaKojima/simpleGestures)

## 2. uBlock Origin

![img_3.png](img_3.png)

Une extension pour bloquer les publicités. Étant open source, elle est très fiable. De plus, elle utilise peu de processeur et de mémoire, ce qui permet une navigation fluide.

- [uBlock Origin](https://microsoftedge.microsoft.com/addons/detail/ublock-origin/odfafepnkmbhccpbejgmiehpchacaeak)
- [github](https://github.com/gorhill/uBlock/)

## 3. Traducteur DeepL

![img.png](img.png)

Une extension Chrome qui vous permet de traduire des pages à l'aide du célèbre service de traduction DeepL. Lorsque vous sélectionnez le texte à traduire dans le navigateur, l'icône DeepL apparaît, et un simple clic lance la traduction automatique.

- [DeepL Translator](https://chrome.google.com/webstore/detail/deepl-translate-reading-w/cofdbpoegempjloogbagkncekinflcnj?hl=ja)

## 4. ChatGPT Sidebar

![img_5.png](img_5.png)

Une extension qui permet d'utiliser ChatGPT dans une barre latérale. Vous pouvez afficher la barre latérale avec Ctrl+P et poser immédiatement des questions à l'IA.
S'il y a du texte sélectionné sur la page, il est copié directement dans la zone de question, vous pouvez donc l'envoyer immédiatement avec Ctrl+Enter.

- [ChatGPT Sidebar](https://chrome.google.com/webstore/detail/chatgpt-sidebar-support-g/difoiogjjojoaoomphldepapgpbgkhkb)

## 5. Salesforce DevTools

![img_1.png](img_1.png)

Une extension qui ajoute des fonctionnalités utiles pour le développement Salesforce.
Je pense que ce n'est pas nécessaire pour ceux qui n'utilisent pas Salesforce.

- [Salesforce DevTools](https://chrome.google.com/webstore/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)
