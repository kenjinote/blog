# Extensões Recomendadas do Chrome

Aqui estão as extensões do Chrome que uso atualmente. Apesar de serem para o Chrome, também podem ser usadas no Microsoft Edge.

## 1. simpleGestures

![img_2.png](img_2.png)

É uma extensão que permite usar gestos do mouse.
Você pode operar o navegador sem usar o teclado ou mirar nos botões da barra de ferramentas.

Por exemplo, você pode voltar deslizando o mouse para a esquerda enquanto segura o botão direito, ou avançar deslizando para a direita enquanto segura o botão direito.

Como também é de código aberto, é altamente confiável.

- [simpleGestures](https://chrome.google.com/webstore/detail/simplegestures/flfminafiamnggnldfpilnfnmbgmiegn)
- [github](https://github.com/RyutaKojima/simpleGestures)

## 2. uBlock Origin

![img_3.png](img_3.png)

Uma extensão para bloquear anúncios. Por ser de código aberto, é altamente confiável. Além disso, usa pouca CPU e memória, funcionando de forma rápida e confortável.

- [uBlock Origin](https://microsoftedge.microsoft.com/addons/detail/ublock-origin/odfafepnkmbhccpbejgmiehpchacaeak)
- [github](https://github.com/gorhill/uBlock/)

## 3. Tradutor DeepL

![img.png](img.png)

Uma extensão do Chrome que permite traduzir a página usando o mundialmente famoso serviço de tradução DeepL. Quando você seleciona o texto que deseja traduzir no navegador, o ícone do DeepL aparece e, ao clicar, ele é traduzido automaticamente.

- [DeepL Translator](https://chrome.google.com/webstore/detail/deepl-translate-reading-w/cofdbpoegempjloogbagkncekinflcnj?hl=ja)

## 4. ChatGPT Sidebar

![img_5.png](img_5.png)

Uma extensão para usar o ChatGPT em uma barra lateral. Você pode exibir a barra lateral com Ctrl+P e fazer perguntas à IA imediatamente.
Se houver texto selecionado na página, ele será copiado diretamente para a pergunta, então você pode perguntar imediatamente com Ctrl+Enter.

- [ChatGPT Sidebar](https://chrome.google.com/webstore/detail/chatgpt-sidebar-support-g/difoiogjjojoaoomphldepapgpbgkhkb)

## 5. Salesforce DevTools

![img_1.png](img_1.png)

Uma extensão que adiciona recursos úteis para o desenvolvimento no Salesforce.
Acredito que não seja necessária para quem não usa o Salesforce.

- [Salesforce DevTools](https://chrome.google.com/webstore/detail/salesforce-devtools/ehgmhinnhggigkogkbhnbodhbfjgncjf)
