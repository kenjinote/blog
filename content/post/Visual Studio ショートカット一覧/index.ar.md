# اختصارات لوحة المفاتيح في Visual Studio 2022

تعتمد هذه القائمة على ملف التعريف الافتراضي **General** في Visual Studio 2022 لنظام Windows. تختلف هذه الاختصارات عن Visual Studio for Mac وVisual Studio Code. وقد يغيّر تخطيط لوحة المفاتيح وملف التعريف المحدد والتخصيصات الاختصارات.

قارنّا القائمة السابقة بالإعدادات الافتراضية الرسمية من Microsoft وصححنا اختصارات الإشارات المرجعية والبناء والبحث والاستبدال غير الدقيقة.

## التعليمات

| Shortcut | Command |
|---|---|
| `F1` | فتح التعليمات |

## البناء وتصحيح الأخطاء

| Shortcut | Command |
|---|---|
| `Ctrl+Shift+B` | إنشاء الحل |
| `F5` | بدء التصحيح/متابعته |
| `Ctrl+F5` | البدء دون تصحيح |
| `F9` | تبديل نقطة التوقف |
| `Ctrl+F9` | تمكين نقطة التوقف |
| `Ctrl+Shift+F9` | حذف جميع نقاط التوقف |
| `F10` | تجاوز الخطوة |
| `F11` | الدخول إلى الخطوة |
| `Shift+F11` | الخروج من الدالة |

## التنقل في التعليمات البرمجية

| Shortcut | Command |
|---|---|
| `F12` | الانتقال إلى التعريف |

## التحرير والتنقل

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+C` | إضافة تعليق إلى التحديد |
| `Ctrl+K, then Ctrl+U` | إزالة التعليق من التحديد |

## البحث والاستبدال

| Shortcut | Command |
|---|---|
| `Ctrl+F` | بحث |
| `Ctrl+H` | استبدال |
| `Ctrl+Shift+F` | البحث في الملفات |
| `Ctrl+Shift+H` | الاستبدال في الملفات |

## التنقل بين الأسطر

| Shortcut | Command |
|---|---|
| `Ctrl+G` | الانتقال إلى السطر |

## التحرير والتنقل

| Shortcut | Command |
|---|---|
| `Ctrl+L` | قص السطر الحالي |
| `Ctrl+D` | تكرار |
| `Ctrl+Shift+V` | التنقل بين عناصر سجل الحافظة |

## التنقل في التعليمات البرمجية

| Shortcut | Command |
|---|---|
| `Ctrl+]` | الانتقال إلى القوس المطابق |
| `Ctrl+Shift+]` | توسيع التحديد حتى القوس المطابق |
| `Alt+Up/Down Arrow` | تحريك الأسطر المحددة لأعلى/لأسفل |
| `Shift+Alt+Up/Down Arrow` | توسيع تحديد العمود لأعلى/لأسفل |

## نوافذ الأدوات وGit

| Shortcut | Command |
|---|---|
| `Ctrl+Tab` | نافذة المستند التالية |
| `Ctrl+Alt+L` | فتح مستكشف الحلول |
| `Ctrl+Shift+E` | فتح عرض الموارد |
| `Ctrl+0, then Ctrl+G` | الانتقال إلى Git Changes |
| `Ctrl+0, then Ctrl+O` | الانتقال إلى Git Commits |

## الإشارات المرجعية

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+K` | تبديل الإشارة المرجعية |
| `Ctrl+K, then Ctrl+N` | الإشارة المرجعية التالية |
| `Ctrl+K, then Ctrl+P` | الإشارة المرجعية السابقة |
| `Ctrl+K, then Ctrl+L` | مسح جميع الإشارات المرجعية |

## عرض الاختصار أو تغييره

في Visual Studio، افتح **Tools > Options > Environment > Keyboard** وابحث عن أمر لمعرفة اختصاره في ملف التعريف الحالي. في الاختصارات المتسلسلة، اضغط المفاتيح بالترتيب مع توقف قصير بين كل تسلسل. وقد يؤثر تخطيط لوحة المفاتيح واللغة في أسماء المفاتيح.

- [Keyboard shortcuts in Visual Studio (Windows)](https://learn.microsoft.com/en-us/visualstudio/ide/default-keyboard-shortcuts-in-visual-studio?view=vs-2022)
