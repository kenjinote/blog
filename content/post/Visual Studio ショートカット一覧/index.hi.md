# Visual Studio 2022 कीबोर्ड शॉर्टकट

यह सूची Windows के Visual Studio 2022 के डिफ़ॉल्ट **General** प्रोफ़ाइल पर आधारित है। ये शॉर्टकट Visual Studio for Mac और Visual Studio Code से अलग हैं। कीबोर्ड लेआउट, चुना गया प्रोफ़ाइल और कस्टम मैपिंग उन्हें बदल सकते हैं।

हमने पिछली सूची को Microsoft के आधिकारिक डिफ़ॉल्ट से मिलाकर गलत बुकमार्क, बिल्ड, खोज और बदलने वाले शॉर्टकट ठीक किए हैं।

## सहायता

| Shortcut | Command |
|---|---|
| `F1` | मदद खोलें |

## बिल्ड और डिबग

| Shortcut | Command |
|---|---|
| `Ctrl+Shift+B` | सॉल्यूशन बिल्ड करें |
| `F5` | डिबगिंग शुरू/जारी रखें |
| `Ctrl+F5` | डिबगिंग के बिना शुरू करें |
| `F9` | ब्रेकपॉइंट टॉगल करें |
| `Ctrl+F9` | ब्रेकपॉइंट सक्षम करें |
| `Ctrl+Shift+F9` | सभी ब्रेकपॉइंट हटाएँ |
| `F10` | स्टेप ओवर |
| `F11` | स्टेप इन |
| `Shift+F11` | स्टेप आउट |

## कोड नेविगेशन

| Shortcut | Command |
|---|---|
| `F12` | परिभाषा पर जाएँ |

## संपादन और नेविगेशन

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+C` | चयन पर टिप्पणी करें |
| `Ctrl+K, then Ctrl+U` | चयन से टिप्पणी हटाएँ |

## खोजें और बदलें

| Shortcut | Command |
|---|---|
| `Ctrl+F` | खोजें |
| `Ctrl+H` | बदलें |
| `Ctrl+Shift+F` | फ़ाइलों में खोजें |
| `Ctrl+Shift+H` | फ़ाइलों में बदलें |

## पंक्ति पर जाएँ

| Shortcut | Command |
|---|---|
| `Ctrl+G` | लाइन पर जाएँ |

## संपादन और नेविगेशन

| Shortcut | Command |
|---|---|
| `Ctrl+L` | वर्तमान लाइन काटें |
| `Ctrl+D` | डुप्लिकेट करें |
| `Ctrl+Shift+V` | क्लिपबोर्ड रिंग को क्रम से चक्रित करें |

## कोड नेविगेशन

| Shortcut | Command |
|---|---|
| `Ctrl+]` | मिलते हुए ब्रैस पर जाएँ |
| `Ctrl+Shift+]` | मिलते हुए ब्रैस तक चयन बढ़ाएँ |
| `Alt+Up/Down Arrow` | चुनी हुई लाइनें ऊपर/नीचे ले जाएँ |
| `Shift+Alt+Up/Down Arrow` | कॉलम चयन ऊपर/नीचे बढ़ाएँ |

## टूल विंडो और Git

| Shortcut | Command |
|---|---|
| `Ctrl+Tab` | अगली दस्तावेज़ विंडो |
| `Ctrl+Alt+L` | Solution Explorer खोलें |
| `Ctrl+Shift+E` | Resource View खोलें |
| `Ctrl+0, then Ctrl+G` | Git Changes पर जाएँ |
| `Ctrl+0, then Ctrl+O` | Git Commits पर जाएँ |

## बुकमार्क

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+K` | बुकमार्क टॉगल करें |
| `Ctrl+K, then Ctrl+N` | अगला बुकमार्क |
| `Ctrl+K, then Ctrl+P` | पिछला बुकमार्क |
| `Ctrl+K, then Ctrl+L` | सभी बुकमार्क साफ़ करें |

## शॉर्टकट देखें या बदलें

Visual Studio में **Tools > Options > Environment > Keyboard** खोलें और कमांड खोजें; इससे मौजूदा प्रोफ़ाइल का शॉर्टकट दिखेगा। क्रमिक शॉर्टकट में कुंजियाँ दिए गए क्रम से दबाएँ और क्रमों के बीच थोड़ा रुकें। कीबोर्ड लेआउट और भाषा सेटिंग से कुंजियों के नाम बदल सकते हैं।

- [Keyboard shortcuts in Visual Studio (Windows)](https://learn.microsoft.com/en-us/visualstudio/ide/default-keyboard-shortcuts-in-visual-studio?view=vs-2022)
