# Сочетания клавиш Visual Studio 2022

Список основан на стандартном профиле **General** в Visual Studio 2022 для Windows. Эти сочетания отличаются от Visual Studio для Mac и Visual Studio Code. Раскладка клавиатуры, выбранный профиль и настройки пользователя могут их менять.

Мы сверили прежний список с официальными настройками Microsoft и исправили неверные сочетания для закладок, сборки, поиска и замены.

## Справка

| Shortcut | Command |
|---|---|
| `F1` | Открыть справку |

## Сборка и отладка

| Shortcut | Command |
|---|---|
| `Ctrl+Shift+B` | Собрать решение |
| `F5` | Начать/продолжить отладку |
| `Ctrl+F5` | Запустить без отладки |
| `F9` | Переключить точку останова |
| `Ctrl+F9` | Включить точку останова |
| `Ctrl+Shift+F9` | Удалить все точки останова |
| `F10` | Шаг с обходом |
| `F11` | Шаг с заходом |
| `Shift+F11` | Выйти из функции |

## Навигация по коду

| Shortcut | Command |
|---|---|
| `F12` | Перейти к определению |

## Редактирование и навигация

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+C` | Закомментировать выделение |
| `Ctrl+K, then Ctrl+U` | Раскомментировать выделение |

## Поиск и замена

| Shortcut | Command |
|---|---|
| `Ctrl+F` | Найти |
| `Ctrl+H` | Заменить |
| `Ctrl+Shift+F` | Найти в файлах |
| `Ctrl+Shift+H` | Заменить в файлах |

## Переход к строке

| Shortcut | Command |
|---|---|
| `Ctrl+G` | Перейти к строке |

## Редактирование и навигация

| Shortcut | Command |
|---|---|
| `Ctrl+L` | Вырезать текущую строку |
| `Ctrl+D` | Дублировать |
| `Ctrl+Shift+V` | Перебирать элементы буфера обмена |

## Навигация по коду

| Shortcut | Command |
|---|---|
| `Ctrl+]` | Перейти к парной фигурной скобке |
| `Ctrl+Shift+]` | Расширить выделение до парной скобки |
| `Alt+Up/Down Arrow` | Переместить выделенные строки вверх/вниз |
| `Shift+Alt+Up/Down Arrow` | Расширить выделение столбца вверх/вниз |

## Окна инструментов и Git

| Shortcut | Command |
|---|---|
| `Ctrl+Tab` | Следующее окно документа |
| `Ctrl+Alt+L` | Открыть обозреватель решений |
| `Ctrl+Shift+E` | Открыть представление ресурсов |
| `Ctrl+0, then Ctrl+G` | Перейти к Git Changes |
| `Ctrl+0, then Ctrl+O` | Перейти к Git Commits |

## Закладки

| Shortcut | Command |
|---|---|
| `Ctrl+K, then Ctrl+K` | Переключить закладку |
| `Ctrl+K, then Ctrl+N` | Следующая закладка |
| `Ctrl+K, then Ctrl+P` | Предыдущая закладка |
| `Ctrl+K, then Ctrl+L` | Очистить все закладки |

## Просмотр и изменение сочетания клавиш

В Visual Studio откройте **Tools > Options > Environment > Keyboard** и найдите команду, чтобы увидеть ее сочетание в текущем профиле. В последовательных сочетаниях нажимайте клавиши по порядку, делая короткую паузу между группами. Раскладка клавиатуры и языковые параметры также влияют на обозначения клавиш.

- [Keyboard shortcuts in Visual Studio (Windows)](https://learn.microsoft.com/en-us/visualstudio/ide/default-keyboard-shortcuts-in-visual-studio?view=vs-2022)
