# Список сочетаний клавиш Visual Studio

Я составил список сочетаний клавиш Visual Studio, которые я часто использую.
Изучив сочетания клавиш для Visual Studio, вы сможете эффективно выполнять задачи разработки. Пожалуйста, используйте их.

※ Проверено в Visual Studio 2022.

| Сочетание клавиш                   | Описание                       |
|-----------------------------|--------------------------|
| `F1`                        | Показать справку для выбранного слова            |
| `F2`                        | Перейти к закладке              |
| `Ctrl` + `F2`               | Добавить закладку                |
| `Ctrl` + `Shift` + `F2`     | Удалить все закладки            |
| `F5`                        | Собрать и запустить (с отладкой)          |
| `Ctrl` + `F5`               | Собрать и запустить (без отладки)          |
| `F7`                        | Собрать                      |
| `F9`                        | Добавить точку останова на строку с курсором        |
| `Ctrl` + `F9`               | Отключить точку останова на строке с курсором     |
| `Shift` + `Ctrl` + `F9`     | Удалить все точки останова          |
| `F10`                       | Шаг с обходом                 |
| `F11`                       | Шаг с заходом                   |
| `F12`                       | Перейти к определению                  |
| `Ctrl` + `D`                | Дублировать строку с курсором                 |
| `Ctrl` + `X`                | Вырезать строку (если нет выделения)         |
| `Ctrl` + `Shift` + `]`      | Выделить до парной скобки   |
| `Alt` + `Стрелки вверх/вниз`            | Переместить строку с курсором вверх/вниз            |
| `Alt` + `Shift` + `Стрелки`    | Мультикурсор/блочное выделение             |
| `Ctrl` + `Tab`              | Переключить исходный код/окно       |
| `Ctrl` + `Shift` + `V`      | Показать историю буфера обмена             |
| `Ctrl` + `K` затем `Ctrl` + `C` | Закомментировать строку с курсором            |
| `Ctrl` + `K` затем `Ctrl` + `U` | Раскомментировать строку с курсором          |
| `Ctrl` + `G`                | Перейти к указанному номеру строки             |
| `Ctrl` + `F`                | Поиск                       |
| `Ctrl` + `Shift` + `F`      | Глобальный поиск                  |
| `Ctrl` + `H`                | Замена                       |
| `Ctrl` + `Shift` + `F`      | Глобальная замена                  |
| `Ctrl` + `Tab`              | Переключить исходный код/окно       |
| `Ctrl` + `Space`            | Автодополнение слов                     |
| `Ctrl` + `Alt` + `L`        | Открыть окно обозревателя решений |
| `Ctrl` + `Shift` + `E`      | Открыть окно представления ресурсов        |
| `Ctrl` + `0` затем `Ctrl` + `G` | Открыть окно коммитов Git         |
