# GIF動畫螢幕錄影工具
我製作了一個錄製螢幕並轉換為GIF動畫的工具。
使用此工具，您可以錄製螢幕上的操作，並在Microsoft Teams等通訊工具中分享。

## 使用方法
1. 啟動工具
2. 指定要錄製的範圍。如果未指定，將錄製整個螢幕。
2. 按下錄影按鈕
3. 按下停止錄影按鈕
4. GIF動畫將輸出在與執行檔相同的位置
