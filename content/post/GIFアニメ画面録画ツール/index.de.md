# Tool zur GIF-animierten Bildschirmaufnahme
Ich habe ein Tool erstellt, um den Bildschirm aufzuzeichnen und in eine GIF-Animation umzuwandeln.
Mit diesem Tool können Sie Bildschirmoperationen aufzeichnen und auf Kommunikationstools wie Microsoft Teams teilen.

## Wie man es benutzt
1. Starten Sie das Tool
2. Geben Sie den aufzunehmenden Bereich an. Wenn nichts angegeben wird, wird der gesamte Bildschirm aufgenommen.
2. Drücken Sie die Aufnahmetaste
3. Drücken Sie die Taste zum Beenden der Aufnahme
4. Die GIF-Animation wird am selben Ort wie die ausführbare Datei ausgegeben

## Herunterladen
[Herunterladen](https://github.com/kenjinote/GifScreenRecorder/releases)

Öffnen Sie den obigen Link und klicken Sie auf den Link `GIFScreenRecorder.exe`, um die ausführbare Datei herunterzuladen.
