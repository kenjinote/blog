# Tool zur GIF-animierten Bildschirmaufnahme
Ich habe ein Tool erstellt, um den Bildschirm aufzuzeichnen und in eine GIF-Animation umzuwandeln.
Mit diesem Tool können Sie Bildschirmoperationen aufzeichnen und auf Kommunikationstools wie Microsoft Teams teilen.

## Wie man es benutzt
1. Starten Sie das Tool
2. Geben Sie den aufzunehmenden Bereich an. Wenn nichts angegeben wird, wird der gesamte Bildschirm aufgenommen.
3. Drücken Sie die Aufnahmetaste
4. Drücken Sie die Taste zum Beenden der Aufnahme
5. Die GIF-Animation wird am selben Ort wie die ausführbare Datei ausgegeben

## Herunterladen
[Herunterladen](https://github.com/kenjinote/GifScreenRecorder/releases)

Öffnen Sie den obigen Link und klicken Sie auf den Link `GIFScreenRecorder.exe`, um die ausführbare Datei herunterzuladen.

## Kompatibilität und Datenschutz

Dieses Tool ist für Windows gedacht und speichert Bildschirmaufnahmen als animierte GIFs; Audio wird nicht aufgezeichnet. Prüfen Sie vor der Aufnahme, ob im ausgewählten Bereich private Informationen sichtbar sind, und kontrollieren Sie das GIF vor dem Teilen. Laden Sie die ausführbare Datei von den [GitHub-Releases des Projekts](https://github.com/kenjinote/GifScreenRecorder/releases) herunter.
