# Outil d'enregistrement d'écran en GIF animé
J'ai créé un outil pour enregistrer l'écran et le transformer en GIF animé.
Avec cet outil, vous pouvez enregistrer les opérations à l'écran et les partager sur des outils de communication tels que Microsoft Teams.

## Comment utiliser
1. Lancez l'outil
2. Spécifiez la zone à enregistrer. Si aucune zone n'est spécifiée, l'écran entier sera enregistré.
3. Appuyez sur le bouton d'enregistrement
4. Appuyez sur le bouton d'arrêt de l'enregistrement
5. Le GIF animé sera généré au même endroit que le fichier exécutable

## Télécharger
[Télécharger](https://github.com/kenjinote/GifScreenRecorder/releases)

Ouvrez le lien ci-dessus et cliquez sur le lien `GIFScreenRecorder.exe` pour télécharger le fichier exécutable.

## Code source
[GitHub](https://github.com/kenjinote/GifScreenRecorder)

## Compatibilité et confidentialité

Cet outil est destiné à Windows et enregistre l’écran sous forme de GIF animés ; il n’enregistre pas le son. Avant l’enregistrement, vérifiez que la zone choisie ne contient pas d’informations privées, puis relisez le GIF avant de le partager. Téléchargez l’exécutable depuis les [versions GitHub du projet](https://github.com/kenjinote/GifScreenRecorder/releases).
