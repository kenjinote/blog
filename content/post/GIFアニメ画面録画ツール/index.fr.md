# Outil d'enregistrement d'écran en GIF animé
J'ai créé un outil pour enregistrer l'écran et le transformer en GIF animé.
Avec cet outil, vous pouvez enregistrer les opérations à l'écran et les partager sur des outils de communication tels que Microsoft Teams.

## Comment utiliser
1. Lancez l'outil
2. Spécifiez la zone à enregistrer. Si aucune zone n'est spécifiée, l'écran entier sera enregistré.
2. Appuyez sur le bouton d'enregistrement
3. Appuyez sur le bouton d'arrêt de l'enregistrement
4. Le GIF animé sera généré au même endroit que le fichier exécutable

## Télécharger
[Télécharger](https://github.com/kenjinote/GifScreenRecorder/releases)

Ouvrez le lien ci-dessus et cliquez sur le lien `GIFScreenRecorder.exe` pour télécharger le fichier exécutable.
