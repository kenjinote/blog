# Herramienta de grabación de pantalla en GIF animado
He creado una herramienta para grabar la pantalla y convertirla en un GIF animado.
Con esta herramienta, puedes grabar operaciones en pantalla y compartirlas mediante herramientas de comunicación como Microsoft Teams.

## Cómo usar
1. Inicia la herramienta
2. Especifica el área a grabar. Si no se especifica, se grabará toda la pantalla.
2. Presiona el botón de grabar
3. Presiona el botón de detener grabación
4. El GIF animado se guardará en la misma ubicación que el archivo ejecutable.
