# Alat Perekam Layar Animasi GIF
Saya telah membuat alat untuk merekam layar dan menyimpannya sebagai animasi GIF.
Dengan menggunakan alat ini, Anda dapat merekam operasi di layar dan membagikannya melalui alat komunikasi seperti Microsoft Teams.

## Cara Penggunaan
1. Jalankan alat
2. Tentukan area yang akan direkam. Jika tidak ditentukan, seluruh layar akan direkam.
3. Tekan tombol rekam
4. Tekan tombol berhenti merekam
5. Animasi GIF akan disimpan di lokasi yang sama dengan file eksekusi
