# GIF एनिमेटेड स्क्रीन रिकॉर्डिंग टूल
मैंने स्क्रीन रिकॉर्ड करने और इसे GIF एनीमेशन बनाने के लिए एक टूल बनाया है।
इस टूल का उपयोग करके, आप स्क्रीन पर होने वाले कार्यों को रिकॉर्ड कर सकते हैं और उन्हें Microsoft Teams जैसे संचार टूल पर साझा कर सकते हैं।

## उपयोग कैसे करें
1. टूल लॉन्च करें
2. रिकॉर्ड करने के लिए क्षेत्र निर्दिष्ट करें। यदि निर्दिष्ट नहीं है, तो पूरी स्क्रीन रिकॉर्ड की जाएगी।
2. रिकॉर्ड बटन दबाएं
3. रिकॉर्डिंग रोकें बटन दबाएं
4. GIF एनीमेशन निष्पादन योग्य फ़ाइल के समान स्थान पर आउटपुट होगा

## डाउनलोड
[डाउनलोड](https://github.com/kenjinote/GifScreenRecorder/releases)

ऊपर दिया गया लिंक खोलें, और निष्पादन योग्य फ़ाइल डाउनलोड करने के लिए `GIFScreenRecorder.exe` लिंक पर क्लिक करें।
