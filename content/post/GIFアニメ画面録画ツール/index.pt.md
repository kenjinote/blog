# Ferramenta de gravação de tela em GIF animado
Fiz uma ferramenta para gravar a tela e transformar em um GIF animado.
Com esta ferramenta, você pode gravar operações na tela e compartilhá-las em ferramentas de comunicação como o Microsoft Teams.

## Como usar
1. Inicie a ferramenta
2. Especifique a área a ser gravada. Se não for especificada, a tela inteira será gravada.
2. Pressione o botão de gravar
3. Pressione o botão de parar gravação
4. O GIF animado será gerado no mesmo local do arquivo executável
