# Инструмент для записи экрана в формате GIF
Я создал инструмент для записи экрана в виде GIF-анимации.
Используя этот инструмент, вы можете записывать действия на экране и делиться ими с помощью таких средств связи, как Microsoft Teams.

## Как использовать
1. Запустите инструмент
2. Укажите область для записи. Если область не указана, будет записан весь экран.
3. Нажмите кнопку записи
4. Нажмите кнопку остановки записи
5. GIF-анимация будет сохранена в той же папке, что и исполняемый файл
