# GIF Animation Screen Recording Tool
I created a tool to record the screen and convert it into a GIF animation.
With this tool, you can record screen operations and share them via communication tools like Microsoft Teams.

## How to Use
1. Launch the tool.
2. Specify the recording area. If not specified, the entire screen will be recorded.
3. Press the record button.
4. Press the stop recording button.
5. The GIF animation will be output to the same location as the executable file.
