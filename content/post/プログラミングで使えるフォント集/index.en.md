## JetBrains Mono

An open-source programming font provided by JetBrains.

Download: [https://www.jetbrains.com/ja-jp/lp/mono/](https://www.jetbrains.com/ja-jp/lp/mono/)    

## HackGen

HackGen is a programming font that combines the English programming font Hack with Genjyuu Gothic, a derivative of Source Han Sans.

Download: [https://github.com/yuru7/HackGen/releases](https://github.com/yuru7/HackGen/releases)

## Ricty Diminished

`Ricty Diminished` is a sister font to `Ricty`. Instead of `Inconsolata` and `Migu 1M`, it is synthesized using `Inconsolata` and `Circle M+ 1m` with the `Ricty` generation script. Since it does not include IPA Gothic glyphs, the number of available kanji glyphs is limited, but in exchange, it can be distributed under the `SIL Open Font License`.

Download: [https://rictyfonts.github.io/diminished](https://rictyfonts.github.io/diminished)

## Cica

It uses `Hack` + `DejaVu Sans Mono` for alphanumeric characters and symbols.
For other characters, it uses `Rounded Mgen+`. It is a programming font designed for coding.

Download: [https://github.com/miiton/Cica/releases](https://github.com/miiton/Cica/releases)

References:
- [Hack](https://sourcefoundry.org/hack/)
- [DejaVu Sans Mono](https://dejavu-fonts.github.io/)
- [Rounded Mgen+](http://jikasei.me/font/rounded-mgenplus/)

## Migu

A synthesized font of M+ and IPA.

Download: [https://itouhiro.github.io/mixfont-mplus-ipa/migu/](https://itouhiro.github.io/mixfont-mplus-ipa/migu/)

## Osaka

A font that allows you to use `Osaka`, a standard Mac OS font, on Windows.

Download: [http://ifs.nog.cc/osakattf.hp.infoseek.co.jp/](http://ifs.nog.cc/osakattf.hp.infoseek.co.jp/)

## PlemolJP

A programming font that combines IBM's open-source Japanese font `IBM Plex Sans JP` with `IBM Plex Mono`, also from IBM's Plex series.

Download: [https://github.com/yuru7/PlemolJP/releases](https://github.com/yuru7/PlemolJP/releases)
