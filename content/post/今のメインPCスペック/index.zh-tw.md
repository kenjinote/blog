我會寫下我目前主要個人電腦的規格。

| 項目名稱 | 值 |
|---------|-----------------------------------------------|
| 處理器 | Intel Core i7-8700K CPU @ 3.70GHz 3.70 GHz |
| 記憶體 | 32.0 GB |
| 系統類型 | 64 位元作業系統，x64 型處理器 |
| 作業系統 | Windows 11 Enterprise（版本 21H2，組建 22000.856） |
