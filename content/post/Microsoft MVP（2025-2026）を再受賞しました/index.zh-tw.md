# 再次榮獲 Microsoft MVP (2025-2026)！

大家好，我是 kenji。

向大家報告一個好消息。今年我再次榮獲了 **Microsoft MVP (Most Valuable Professional)** 獎項。這是我 **第 9 次** 獲獎。

非常感謝大家一直以來的支持。

---

## 什麼是 Microsoft MVP？

一聽到「MVP」，許多人可能會想到體育界的最有價值球員，但這裡的 MVP 是指 **授予那些對 Microsoft 技術社群做出貢獻的人的稱號** 。

具體來說，包括：

* 在技術部落格和社群媒體上發布資訊
* 在 GitHub 上公開範例程式碼
* 在讀書會和研討會上發表演講
* 在問答網站上回答問題
* 與海外開發者進行技術交流和合作
* 參與工程師互相交流的社群並發表文章

等「為了他人分享自己的知識和經驗」的活動會受到評估的制度。

獲獎者遍布全球，但每年選出的人數有限，再次獲獎也絕非易事。正因為如此，能夠獲得這份認定，我感到無比榮幸。

---

## 過去一年我致力於的事情

今年，我致力於以 **技術的「易懂性」與「易達性」** 為核心來傳播資訊。

* 在 GitHub 上公開實用的範例程式碼
* 在讀書會與研討會上發表演講（不分國內外）
* 透過技術部落格和社群媒體定期發布資訊
* 在問答網站上持續回答問題
* 在工程師社群網站上分享知識
* 與海外工程師交流及共同測試

其中，在 GitHub 上公開程式碼讓我印象特別深刻，因為有時會收到「我也在煩惱同樣的問題，這幫了我大忙！」這樣的回饋，讓我切實感受到自己的努力正在幫助其他人的開發工作。

此外，在活動演講時，我也會收到「即使是初學者也很容易理解」的回饋，這成為我思考「什麼是能傳達給別人的技術解說？」的好契機。

---

## 展望明年

技術的發展真的非常快，光是追趕就很辛苦。儘管如此，我認為傳遞 **作為「第一手資訊」的真實見解** （例如自己嘗試後獲得的親身體驗和遇到的挫折點）具有巨大的價值。

明年，我想挑戰發布 **結合影片和圖解的「視覺上易懂的技術內容」** 。我希望增加我的產出，哪怕只能稍微解決別人的「卡關！」感也好。

---

## 結語

MVP 這個頭銜終究只是個里程碑。

今後，我也不會勉強，會以自己的步調前進。
但同時也會確實地幫助到他人。

「查資料時幫了大忙」
「這個範例能動！」
「這段內容很容易懂」

我希望繼續成為能讓人說出這些話的工程師。

今後也請大家多多指教。
