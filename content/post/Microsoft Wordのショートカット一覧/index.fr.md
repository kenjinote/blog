## Liste des raccourcis

| Raccourci clavier | Description |
|------------------|-----|
| `Ctrl` + `B`     | Mettre en gras |
| `Ctrl` + `I`     | Mettre en italique |
| `Ctrl` + `U`     | Souligner |
| `Ctrl` + `E`     | Centrer |
| `Ctrl` + `L`     | Aligner à gauche |
| `Ctrl` + `R`     | Aligner à droite |
| `Ctrl` + `]`     | Augmenter la taille de la police |
| `Ctrl` + `[`     | Diminuer la taille de la police |
| `Ctrl` + `C`     | Copier |
| `Ctrl` + `V`     | Coller |
| `Ctrl` + `X`     | Couper |
| `Ctrl` + `Z`     | Annuler |
| `Ctrl` + `Y`     | Rétablir |
| `Ctrl` + `A`     | Tout sélectionner |
| `Shift` + `Flèches` | Sélectionner une plage |
| `Ctrl` + `F`     | Rechercher du texte |
| `Ctrl` + `H`     | Remplacer du texte |
| `Ctrl` + `P`     | Aperçu avant impression |
| `Ctrl` + `S`     | Enregistrer le document |
| `F12`            | Enregistrer sous |
| `Ctrl` + `Home`  | Aller au début du document |
| `Ctrl` + `End`   | Aller à la fin du document |
