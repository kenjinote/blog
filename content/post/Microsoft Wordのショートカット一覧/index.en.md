## Shortcuts List

| Shortcut Key        | Description |
|------------------|-----|
| `Ctrl` + `B`     | Make bold |
| `Ctrl` + `I`     | Make italic |
| `Ctrl` + `U`     | Underline |
| `Ctrl` + `E`     | Center align |
| `Ctrl` + `L`     | Left align |
| `Ctrl` + `R`     | Right align |
| `Ctrl` + `]`     | Increase font size |
| `Ctrl` + `[`     | Decrease font size |
| `Ctrl` + `C`     | Copy |
| `Ctrl` + `V`     | Paste |
| `Ctrl` + `X`     | Cut |
| `Ctrl` + `Z`     | Undo |
| `Ctrl` + `Y`     | Redo |
| `Ctrl` + `A`     | Select all |
| `Shift` + `Arrow keys` | Select text |
| `Ctrl` + `F`     | Find text |
| `Ctrl` + `H`     | Replace text |
| `Ctrl` + `P`     | Print preview |
| `Ctrl` + `S`     | Save document |
| `F12`            | Save as |
| `Ctrl` + `Home`  | Move to start of document |
| `Ctrl` + `End`   | Move to end of document |
