## Lista de atajos de teclado

| Atajo de teclado        | Descripción |
|------------------|-----|
| `Ctrl` + `B`     | Negrita |
| `Ctrl` + `I`     | Cursiva |
| `Ctrl` + `U`     | Subrayado |
| `Ctrl` + `E`     | Centrar |
| `Ctrl` + `L`     | Alinear a la izquierda |
| `Ctrl` + `R`     | Alinear a la derecha |
| `Ctrl` + `]`     | Aumentar tamaño de fuente |
| `Ctrl` + `[`     | Disminuir tamaño de fuente |
| `Ctrl` + `C`     | Copiar |
| `Ctrl` + `V`     | Pegar |
| `Ctrl` + `X`     | Cortar |
| `Ctrl` + `Z`     | Deshacer |
| `Ctrl` + `Y`     | Rehacer |
| `Ctrl` + `A`     | Seleccionar todo |
| `Shift` + `Teclas de dirección` | Seleccionar rango |
| `Ctrl` + `F`     | Buscar texto |
| `Ctrl` + `H`     | Reemplazar texto |
| `Ctrl` + `P`     | Vista previa de impresión |
| `Ctrl` + `S`     | Guardar documento |
| `F12`            | Guardar como |
| `Ctrl` + `Home`  | Ir al principio del documento |
| `Ctrl` + `End`   | Ir al final del documento |
