## Список сочетаний клавиш

| Сочетание клавиш | Описание |
|------------------|-----|
| `Ctrl` + `B`     | Жирный |
| `Ctrl` + `I`     | Курсив |
| `Ctrl` + `U`     | Подчеркнутый |
| `Ctrl` + `E`     | Выровнять по центру |
| `Ctrl` + `L`     | Выровнять по левому краю |
| `Ctrl` + `R`     | Выровнять по правому краю |
| `Ctrl` + `]`     | Увеличить размер шрифта |
| `Ctrl` + `[`     | Уменьшить размер шрифта |
| `Ctrl` + `C`     | Копировать |
| `Ctrl` + `V`     | Вставить |
| `Ctrl` + `X`     | Вырезать |
| `Ctrl` + `Z`     | Отменить |
| `Ctrl` + `Y`     | Повторить отмененное действие |
| `Ctrl` + `A`     | Выделить все |
| `Shift` + `клавиши со стрелками` | Выделить диапазон |
| `Ctrl` + `F`     | Найти текст |
| `Ctrl` + `H`     | Заменить текст |
| `Ctrl` + `P`     | Предварительный просмотр печати |
| `Ctrl` + `S`     | Сохранить документ |
| `F12`            | Сохранить как |
| `Ctrl` + `Home`  | Перейти в начало документа |
| `Ctrl` + `End`   | Перейти в конец документа |
