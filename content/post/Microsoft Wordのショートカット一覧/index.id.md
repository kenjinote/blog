## Daftar Pintasan

| Tombol Pintasan  | Deskripsi |
|------------------|-----|
| `Ctrl` + `B`     | Tebal |
| `Ctrl` + `I`     | Miring |
| `Ctrl` + `U`     | Garis bawah |
| `Ctrl` + `E`     | Rata tengah |
| `Ctrl` + `L`     | Rata kiri |
| `Ctrl` + `R`     | Rata kanan |
| `Ctrl` + `]`     | Perbesar ukuran font |
| `Ctrl` + `[`     | Perkecil ukuran font |
| `Ctrl` + `C`     | Salin |
| `Ctrl` + `V`     | Tempel |
| `Ctrl` + `X`     | Potong |
| `Ctrl` + `Z`     | Urungkan |
| `Ctrl` + `Y`     | Ulangi |
| `Ctrl` + `A`     | Pilih semua |
| `Shift` + `tombol panah` | Pilih rentang |
| `Ctrl` + `F`     | Cari teks |
| `Ctrl` + `H`     | Ganti teks |
| `Ctrl` + `P`     | Pratinjau cetak |
| `Ctrl` + `S`     | Simpan dokumen |
| `F12`            | Simpan sebagai |
| `Ctrl` + `Home`  | Pindah ke awal dokumen |
| `Ctrl` + `End`   | Pindah ke akhir dokumen |
