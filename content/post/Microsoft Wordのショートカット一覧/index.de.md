## Tastenkombinationen

| Tastenkombination | Beschreibung |
|------------------|-----|
| `Ctrl` + `B`     | Fett formatieren |
| `Ctrl` + `I`     | Kursiv formatieren |
| `Ctrl` + `U`     | Unterstreichen |
| `Ctrl` + `E`     | Zentrieren |
| `Ctrl` + `L`     | Linksbündig ausrichten |
| `Ctrl` + `R`     | Rechtsbündig ausrichten |
| `Ctrl` + `]`     | Schriftgrad vergrößern |
| `Ctrl` + `[`     | Schriftgrad verkleinern |
| `Ctrl` + `C`     | Kopieren |
| `Ctrl` + `V`     | Einfügen |
| `Ctrl` + `X`     | Ausschneiden |
| `Ctrl` + `Z`     | Rückgängig machen |
| `Ctrl` + `Y`     | Wiederherstellen |
| `Ctrl` + `A`     | Alles auswählen |
| `Shift` + `Pfeiltasten` | Bereich auswählen |
| `Ctrl` + `F`     | Text suchen |
| `Ctrl` + `H`     | Text ersetzen |
| `Ctrl` + `P`     | Seitenansicht anzeigen |
| `Ctrl` + `S`     | Dokument speichern |
| `F12`            | Speichern unter |
| `Ctrl` + `Home`  | Zum Anfang des Dokuments springen |
| `Ctrl` + `End`   | Zum Ende des Dokuments springen |
