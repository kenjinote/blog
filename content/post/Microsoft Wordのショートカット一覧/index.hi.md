## शॉर्टकट सूची

| शॉर्टकट कुंजी          | विवरण |
|------------------|-----|
| `Ctrl` + `B`     | बोल्ड करें |
| `Ctrl` + `I`     | इटैलिक करें |
| `Ctrl` + `U`     | अंडरलाइन करें |
| `Ctrl` + `E`     | केंद्र में संरेखित करें |
| `Ctrl` + `L`     | बाएं संरेखित करें |
| `Ctrl` + `R`     | दाएं संरेखित करें |
| `Ctrl` + `]`     | फ़ॉन्ट आकार बढ़ाएं |
| `Ctrl` + `[`     | फ़ॉन्ट आकार घटाएं |
| `Ctrl` + `C`     | कॉपी करें |
| `Ctrl` + `V`     | पेस्ट करें |
| `Ctrl` + `X`     | कट करें |
| `Ctrl` + `Z`     | पूर्ववत करें |
| `Ctrl` + `Y`     | फिर से करें |
| `Ctrl` + `A`     | सभी चुनें |
| `Shift` + `तीर कुंजियां` | सीमा का चयन करें |
| `Ctrl` + `F`     | टेक्स्ट खोजें |
| `Ctrl` + `H`     | टेक्स्ट बदलें |
| `Ctrl` + `P`     | प्रिंट पूर्वावलोकन |
| `Ctrl` + `S`     | दस्तावेज़ सहेजें |
| `F12`            | इस रूप में सहेजें |
| `Ctrl` + `Home`  | दस्तावेज़ की शुरुआत में जाएं |
| `Ctrl` + `End`   | दस्तावेज़ के अंत में जाएं |
