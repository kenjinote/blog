## Lista de Atalhos

| Tecla de Atalho         | Descrição |
|------------------|-----|
| `Ctrl` + `B`     | Negrito |
| `Ctrl` + `I`     | Itálico |
| `Ctrl` + `U`     | Sublinhado |
| `Ctrl` + `E`     | Alinhar ao centro |
| `Ctrl` + `L`     | Alinhar à esquerda |
| `Ctrl` + `R`     | Alinhar à direita |
| `Ctrl` + `]`     | Aumentar o tamanho da fonte |
| `Ctrl` + `[`     | Diminuir o tamanho da fonte |
| `Ctrl` + `C`     | Copiar |
| `Ctrl` + `V`     | Colar |
| `Ctrl` + `X`     | Recortar |
| `Ctrl` + `Z`     | Desfazer |
| `Ctrl` + `Y`     | Refazer a ação desfeita |
| `Ctrl` + `A`     | Selecionar tudo |
| `Shift` + `Teclas de Seta` | Selecionar um intervalo |
| `Ctrl` + `F`     | Pesquisar texto |
| `Ctrl` + `H`     | Substituir texto |
| `Ctrl` + `P`     | Exibir visualização de impressão |
| `Ctrl` + `S`     | Salvar o documento |
| `F12`            | Salvar como |
| `Ctrl` + `Home`  | Mover para o início do documento |
| `Ctrl` + `End`   | Mover para o final do documento |
