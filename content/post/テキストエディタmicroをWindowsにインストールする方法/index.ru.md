## Скачивание micro
https://github.com/zyedidia/micro/releases

Откройте ссылку выше, нажмите `Show all XX assets` (где X - цифры) и скачайте `micro-X.X.XX-win64.zip` (где X - цифры).
Распакуйте zip-файл и поместите все файлы в любую папку.

## Настройка переменных среды
Чтобы использовать `micro.exe` из командной строки, необходимо настроить переменные среды.

1. Нажмите клавиши `Win` + `R`, введите `sysdm.cpl` и нажмите `Enter`.
2. В окне `Свойства системы` нажмите `Свойства системы`.
3. Нажмите `Переменные среды`.
4. Выберите `Path` в `Системные переменные` и нажмите `Изменить`.
5. Нажмите `Создать` и добавьте путь к папке, содержащей `micro.exe`.
6. Нажмите `ОК`, чтобы закрыть все диалоговые окна.
7. Перезапустите командную строку, введите `nano` и проверьте, запускается ли он.

## Как использовать micro

При вводе `micro` в командной строке и выполнении появится следующий экран.
![img_3.png](img_3.png)

Основные операции и сочетания клавиш следующие:

| Сочетания клавиш | Операция | 
|--------|-----| 
| Ctrl+Q | Закрыть файл | 
| Ctrl+S | Сохранить файл | 
| Ctrl+O | Открыть файл | 
| Ctrl+A | Выбрать всё | 
| Ctrl+X | Вырезать выделенное | 
| Ctrl+C | Скопировать выделенное | 
| Ctrl+V | Вставить | 
| Ctrl+Z | Отменить | 
| Ctrl+Y | Повторить | 
| Ctrl+E | Выполнить команду редактора |
