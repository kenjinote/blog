## Скачивание micro
https://github.com/micro-editor/micro/releases/latest
В Assets последнего релиза скачайте архив для Windows x64 (например, `micro-<version>-win64.zip`) и распакуйте его в выбранную папку.

Для Windows на ARM выберите соответствующий архив ARM64.

## Настройка переменных среды
Чтобы использовать `micro.exe` из командной строки, необходимо настроить переменные среды.

1. Нажмите `Win` + `R`, введите `sysdm.cpl` и нажмите `Enter`.
2. Откройте вкладку «Дополнительно» и нажмите «Переменные среды».
3. В разделе пользовательских переменных своей учетной записи выберите `Path` и нажмите «Изменить». Если `Path` нет, создайте его.
4. Нажмите «Создать» и добавьте путь к папке с `micro.exe`.
5. Нажмите «ОК», чтобы закрыть диалоговые окна.
6. Откройте командную строку заново и запустите `micro`, чтобы проверить его запуск.

## Как использовать micro

При вводе `micro` в командной строке и выполнении появится следующий экран.
![img_3.png](img_3.webp)

Основные операции и сочетания клавиш следующие:

| Сочетания клавиш | Операция | 
|--------|-----| 
| Ctrl+Q | Закрыть текущий файл (micro завершится, если это последний файл) |
| Ctrl+S | Сохранить файл | 
| Ctrl+O | Открыть файл | 
| Ctrl+A | Выбрать всё | 
| Ctrl+X | Вырезать выделенное | 
| Ctrl+C | Скопировать выделенное | 
| Ctrl+V | Вставить | 
| Ctrl+Z | Отменить | 
| Ctrl+Y | Повторить | 
| Ctrl+E | Выполнить команду редактора |
