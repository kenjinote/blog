## Генерация QR-кода с помощью curl

Внимание: Представленный метод возвращает QR-код, сгенерированный на стороне сервера, поэтому журналы могут сохраняться. Будьте осторожны при преобразовании конфиденциальной информации, такой как личные данные, в QR-код.

### Метод 1

Это способ генерации QR-кода в командной строке.
`qrenco.de` возвращает текстовый ответ.

```
curl qrenco.de/kenji.blog
```

### Метод 2

`api.qrserver.com` возвращает изображение.

```
curl -o qr.png "https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=HelloWorld"
```

- Результат вывода
![](qr.png)
