# Удаление локального тега

1. Проверьте существующие локальные теги с помощью `git tag`.
2. Удалите тег с помощью `git tag -d v0.1.0`. (Замените `v0.1.0` на тег, который вы хотите удалить)

# Удаление удаленного тега

1. Проверьте существующие удаленные теги с помощью `git ls-remote --tags`.
2. Удалите удаленный тег с помощью `git push origin --delete v0.1.0`. (Замените `v0.1.0` на тег, который вы хотите удалить)
