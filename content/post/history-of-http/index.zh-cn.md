# HTTP技术解析

Hypertext Transfer Protocol (HTTP) 是Web基础的通信协议。

## 无状态设计

HTTP是无状态（stateless）协议。每个请求都会被独立处理。

```mermaid
graph LR;
    C["Client (Web Browser)"] -- "GET /index.html (HTTP/1.1)" --> S["Server (Web Server)"];
    S -- "200 OK (HTML Content)" --> C;
```

## 性能考察

在HTTP/2和HTTP/3中，通过多路复用减轻了往返时间（RTT）的影响。页面加载时间可以建立如下模型：

$$ T_{load} = T_{DNS} + T_{TCP} + T_{TLS} + \sum_{i=1}^{N} \left( \frac{S_i}{B} + RTT \right) $$

通过多路复用，后半部分的 $\sum$ 部分被并行化，从而显著缩短了时间。
