# Техническое объяснение HTTP

Hypertext Transfer Protocol (HTTP) — это базовый протокол связи для Web.

## Дизайн без сохранения состояния

HTTP — это протокол без сохранения состояния (stateless). Каждый запрос обрабатывается независимо.

```mermaid
graph LR;
    C["Client (Web Browser)"] -- "GET /index.html (HTTP/1.1)" --> S["Server (Web Server)"];
    S -- "200 OK (HTML Content)" --> C;
```

## Рассмотрение производительности

В HTTP/2 и HTTP/3 влияние времени приема-передачи (RTT) уменьшается за счет мультиплексирования. Время загрузки страницы можно смоделировать следующим образом.

$$ T_{load} = T_{DNS} + T_{TCP} + T_{TLS} + \sum_{i=1}^{N} \left( \frac{S_i}{B} + RTT \right) $$

Благодаря мультиплексированию, вторая часть $\sum$ распараллеливается, что значительно сокращает время.
