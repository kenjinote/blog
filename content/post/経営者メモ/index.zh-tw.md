# 尋找正在流行起來的事業
- 向Hot Pepper內部人員或稅務師詢問正在流行起來的事業
- 不要進入已經飽和且強者雲集的事業
- 只進入確信能夠吸引顧客的事業（不要進入有現有業者使用特殊吸引顧客方法（無法模仿的方法）的事業）

# 徹底模仿
- 在進入之前研究其商業邏輯
- 徹底抄襲
- 在此基礎上進行改良

# 系統化
- 將一切手冊化，讓任何人都能不費力地完成
- 思考提高銷售額（增加客數、客單價）和減少經費（人事費、廣告費）的點子，並將其系統化

# 經營者的理念
- 經營者的理念就是「企業利潤最大化」，僅此而已
- 將社會貢獻或討好員工做為經營者理念是NG的（認為這些東西之後自然會隨之而來）
