# تثبيت PowerToys من موجه الأوامر

إليك كيفية تثبيت PowerToys من موجه الأوامر.

```
winget install Microsoft.PowerToys --source winget
```

# إلغاء تثبيت PowerToys من موجه الأوامر

```
winget uninstall --name PowerToys 
```
