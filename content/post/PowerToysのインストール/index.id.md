# Menginstal PowerToys dari Command Prompt

Berikut adalah cara menginstal PowerToys dari Command Prompt.

```
winget install Microsoft.PowerToys --source winget
```

# Menghapus Instalasi PowerToys dari Command Prompt

```
winget uninstall --name PowerToys 
```
