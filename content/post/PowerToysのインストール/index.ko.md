# 명령 프롬프트에서 PowerToys 설치하기

명령 프롬프트를 사용하여 PowerToys를 설치하는 방법을 소개합니다.

```
winget install Microsoft.PowerToys --source winget
```

# 명령 프롬프트에서 PowerToys 제거하기

```
winget uninstall --name PowerToys 
```
