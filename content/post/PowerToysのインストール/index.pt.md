# Instalar PowerToys no Prompt de Comando

Abaixo está como instalar o PowerToys usando o Prompt de Comando.

```
winget install Microsoft.PowerToys --source winget
```

# Desinstalar PowerToys no Prompt de Comando

```
winget uninstall --name PowerToys 
```
