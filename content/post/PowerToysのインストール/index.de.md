# PowerToys in der Eingabeaufforderung installieren

Hier wird beschrieben, wie Sie PowerToys über die Eingabeaufforderung installieren.

```
winget install Microsoft.PowerToys --source winget
```

# PowerToys in der Eingabeaufforderung deinstallieren

```
winget uninstall --name PowerToys 
```
