# Installer PowerToys via l'Invite de commandes

Voici comment installer PowerToys à l'aide de l'Invite de commandes.

```
winget install Microsoft.PowerToys --source winget
```

# Désinstaller PowerToys via l'Invite de commandes

```
winget uninstall --name PowerToys 
```
