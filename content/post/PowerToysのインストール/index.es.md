# Instalar PowerToys con el símbolo del sistema

Aquí se muestra cómo instalar PowerToys usando el símbolo del sistema.

```
winget install Microsoft.PowerToys --source winget
```

# Desinstalar PowerToys con el símbolo del sistema

```
winget uninstall --name PowerToys 
```
