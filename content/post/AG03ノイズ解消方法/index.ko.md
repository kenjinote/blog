# YAMAHA AG03 노이즈 해결 방법

AG03 모니터로 PC 소리를 듣다 보면 정기적으로 (1분에서 3분 정도에 1번) 지직거리는 노이즈가 발생해서,
알아보니 AG03 노이즈 대책으로 다음과 같은 방법이 있는 것 같습니다.

https://jp.yamaha.com/support/updates/yamaha_steinberg_usb_driver_for_win.html

위 사이트에서 Yamaha Steinberg USB Driver를 다운로드하여 설치하니 노이즈가 해결되었습니다.
