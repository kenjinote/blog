# FONTPLUS

FONTPLUS delivers web fonts. Its Smart License applies fonts by adding the service script and CSS to a site.

The official page lists Smart License from JPY 1,100 per month: a 100,000-PV one-month ticket costs JPY 1,100 including tax; 1.2 million PV for one year costs JPY 13,200. The trial includes selected fonts, up to 5,000 PV, for six months.

There is no stated limit on domains or font count, but PV tickets are capped. Normally one page view consumes one PV even with several fonts; reloads count too. Multiple service script tags on one page may count separately.

Prices and terms can change. Confirm current rates, PV counting, covered sites, and terms on the official page before subscribing. Large sites may request a custom quote.
