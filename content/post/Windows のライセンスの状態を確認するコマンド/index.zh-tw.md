# 【Windows】如何檢查授權狀態（1個命令即可）

您是否曾想過您的 Windows 授權是否已正確認證？

在這種時候，非常方便的是 **一鍵檢查授權資訊的方法** 。只需執行以下步驟，您就可以輕鬆檢查目前的授權狀態。

## 檢查授權狀態的命令

您可以使用 Windows 內建的指令碼工具來顯示授權資訊。使用的命令如下：

```
slmgr /dli
```

執行此命令後，部分授權資訊將顯示在一個視窗中。

## 執行方法

1. **從「開始功能表」輸入「cmd」，右鍵點擊命令提示字元 →「以系統管理員身分執行」** 。

2. 在命令提示字元中輸入以下內容並按 Enter 鍵：

   ```
   slmgr /dli
   ```

3. 等待幾秒鐘後，將顯示如下的授權資訊。

   ![Windows授權檢查畫面](img.png)

## 顯示的主要資訊

* 產品金鑰的一部分
* 授權類型（零售、OEM 等）
* 授權狀態（有效、過期、未認證等）

## 如果您想了解更詳細的資訊？

還有以下命令：

* `slmgr /dlv` ：顯示更詳細的授權資訊
* `slmgr /xpr` ：顯示授權的到期日期（如是否永久）

## 總結

只需一個命令，即可輕鬆檢查 Windows 的授權狀態。

* **簡易檢查** ：`slmgr /dli`
* **詳細檢查** ：`slmgr /dlv`
* **檢查到期日期** ：`slmgr /xpr`

如果授權出現問題，更新和某些功能可能會受到限制，因此定期檢查會讓人更安心。
