# 【Windows】Как проверить статус лицензии (всего одной командой)

Вы когда-нибудь задумывались о том, правильно ли активирована ваша лицензия Windows?

В таких случаях существует удобный способ **проверить информацию о лицензии с помощью одной команды**. Просто выполните следующие шаги, чтобы легко проверить текущий статус лицензии.

## Команда для проверки статуса лицензии

Вы можете использовать встроенный скриптовый инструмент Windows для отображения информации о лицензии. Вот команда, которую нужно использовать:

```
slmgr /dli
```

При запуске этой команды часть информации о лицензии отобразится в окне.

## Как выполнить

1. **В меню «Пуск» введите «cmd», щелкните правой кнопкой мыши «Командная строка» → «Запуск от имени администратора»**.

2. Введите следующее в командной строке и нажмите Enter:

   ```
   slmgr /dli
   ```

3. Подождав несколько секунд, вы увидите следующую информацию о лицензии.

   ![Экран подтверждения лицензии Windows](img.png)

## Основная отображаемая информация

* Часть ключа продукта
* Тип лицензии (Retail, OEM и т. д.)
* Статус лицензии (действительна, просрочена, не активирована и т. д.)

## Что если вы хотите узнать более подробную информацию?

Существуют также следующие команды:

* `slmgr /dlv`: Отображает более подробную информацию о лицензии
* `slmgr /xpr`: Отображает срок действия лицензии (является ли она постоянной и т. д.)

## Резюме

Статус лицензии Windows можно легко проверить одной командой.

* **Простая проверка**: `slmgr /dli`
* **Подробная проверка**: `slmgr /dlv`
* **Проверка срока действия**: `slmgr /xpr`

Если с лицензией возникнут проблемы, могут быть ограничения на обновления и некоторые функции, поэтому полезно регулярно проверять её.
