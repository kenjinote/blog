# 【Для начинающих】Как установить Gemini CLI на Windows

"[Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI" позволяет использовать генеративный ИИ Google "[Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/)" из командной строки.
В этой статье мы максимально просто объясним шаги по установке [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI в среде Windows.

---

## 1. Предварительная подготовка: Установка Node.js и npm

Во-первых, поскольку [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI работает в среде под названием "Node.js", вам необходимо предварительно установить следующее:

* **Node.js**
* **npm (инструмент управления пакетами, поставляемый с Node.js)**
* **npx (инструмент выполнения команд, включенный в npm)**

Пожалуйста, скачайте версию Node.js для Windows с официального сайта ниже (рекомендуется версия LTS):

👉 [Официальный сайт Node.js](https://nodejs.org/)

После завершения установки давайте проверим, правильно ли она выполнена, с помощью следующих команд.

```powershell
node -v
npm -v
```

---

## 2. Запуск PowerShell

Для использования [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI в Windows обычно используется PowerShell.
Введите "PowerShell" в меню "Пуск" и запустите его.

---

## 3. Установка Gemini CLI

Скопируйте и вставьте следующую команду в PowerShell и выполните её:

```bash
npx @google/gemini-cli
```

Эта команда предназначена для временного выполнения пакета [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI, выпущенного Google.
При необходимости может потребоваться выполнить первоначальную настройку или войти в систему.

※ При первом запуске это может занять несколько минут. Если возникнет ошибка, пожалуйста, еще раз проверьте Node.js и ваше сетевое окружение.

---

## 4. Установка завершена! Что дальше

Теперь [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI установлен на Windows.
В дальнейшем, используя [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) из командной строки, вы сможете выполнять различные операции, такие как генерация текста и дополнение кода.

Если вы хотите ознакомиться с официальной документацией или справкой, вы также можете использовать такую команду:

```bash
npx @google/gemini-cli --help
```

## Заключение

Давайте повторим шаги по установке [Gemini](/ru/p/google-one-gemini%E3%81%8C%E8%A7%A3%E7%B4%84%E3%81%A7%E3%81%8D%E3%81%AA%E3%81%84%E6%99%82%E3%81%AE%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1-%D1%80%D0%B5%D1%88%D0%B5%D0%BD%D0%B8%D1%8F/) CLI на Windows.

2. Запустите PowerShell
3. Выполните `npx @google/gemini-cli`

Вот и всё!
