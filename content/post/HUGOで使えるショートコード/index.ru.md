# Встроенные шорткоды Hugo: вставки, версии и конфиденциальность

Шорткоды вызывают функции шаблонов из содержимого Markdown. В Hugo есть встроенные шорткоды; другие могут предоставлять темы и модули, а проект может определить собственные. Имена и аргументы различаются между версиями Hugo, поэтому сверяйтесь с официальной документацией для используемой версии.

## Встроенные шорткоды Hugo

Flickr не входит во встроенные шорткоды ядра Hugo. Если вызов `flickr` работает в проекте, его предоставляет тема, модуль или пользовательский шаблон, например `layouts/_shortcodes/flickr.html`. Не считайте его встроенным только из-за названия.

В актуальный официальный список входят, помимо прочих, `details`, `figure`, `highlight`, `instagram`, `param`, `qr`, `ref`, `relref`, `vimeo`, `x` и `youtube`. Полный список и аргументы приведены на официальной странице.

## Примеры для медиа

### YouTube

Укажите идентификатор из параметра `v` в URL видео.

`{{</* youtube 0RKpf3rK57I */>}}`

### X (Hugo 0.141.0 и новее)

Укажите имя пользователя и идентификатор публикации из её URL.

`{{</* x user="SanDiegoZoo" id="1453110110599868418" */>}}`

### Старый Twitter (Hugo 0.139.0)

В Hugo 0.139.0 используются следующие именованные аргументы.

`{{</* twitter user="SanDiegoZoo" id="1453110110599868418" */>}}`

### Instagram

Последняя часть URL публикации Instagram — её идентификатор.

`{{</* instagram CxOWiQNP2MO */>}}`

### Vimeo

Используйте числовой идентификатор в конце URL видео Vimeo.

`{{</* vimeo 19899678 */>}}`

## Учитывайте версию

Сборка этого блога закреплена на Hugo 0.139.0. В этой версии встроенный шорткод для X (ранее Twitter) называется `twitter` и требует именованные аргументы `user` и `id`. Шорткод `x` появился в Hugo 0.141.0, а в более поздней версии `twitter` был объявлен устаревшим. Перед копированием примеров из актуальной документации проверьте версию Hugo в проекте.

## Настройки конфиденциальности

Вставки YouTube, X, Instagram и Vimeo могут подключать браузер посетителя к этим сервисам. Настройки `privacy` в Hugo позволяют отключить вставки или включить упрощённый режим, если он доступен. `privacyEnhanced` для YouTube ограничивает сохранение данных, пока посетитель не запустит видео.

Режим повышенной конфиденциальности YouTube:

```yaml
privacy:
  youTube:
    privacyEnhanced: true
```

Упрощённый режим X:

```yaml
privacy:
  x:
    simple: true
    enableDNT: true
```

Старый Twitter (Hugo 0.139.0):

```yaml
privacy:
  twitter:
    simple: true
    enableDNT: true
```

Проверьте названия параметров в официальной документации для используемой версии Hugo.

Упрощённый режим Instagram всё равно загружает изображение с серверов Instagram. Упрощённый режим Vimeo получает миниатюру и открывает Vimeo в новой вкладке после нажатия. Такие режимы не устраняют все запросы к сторонним сервисам.

Перед публикацией вставки проверьте запросы к поставщику, поведение файлов cookie и требования к конфиденциальности, применимые к вашей аудитории.

## Показ синтаксиса как текста

Чтобы показать запись шорткода как обычный текст, экранируйте разделители, добавив `/*` и `*/`, как в примере.

`{{</*/* youtube 0RKpf3rK57I */*/>}}`
