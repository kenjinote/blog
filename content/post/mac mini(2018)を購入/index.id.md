# Membeli mac mini(2018)

Saya membeli mac mini(2018) bekas model lama di Mercari. Spesifikasinya sebagai berikut.

- CPU: 3.2GHz 6-core Intel Core i7
- Memori: 32GB
- Penyimpanan: 1TB SSD

Harganya adalah 77.000 yen.

# Alasan pembelian

- Saya menggunakan mac mini dengan spesifikasi yang hampir sama di tempat kerja untuk mengembangkan aplikasi smartphone, dan saya juga ingin menyiapkan lingkungan pengembangan (terutama lingkungan eksekusi xcode) di rumah.
- Saya memiliki macbook pro, tetapi saya membelinya 9 tahun yang lalu dan kinerjanya cukup lambat, jadi saya jarang menggunakannya.
- Secara pribadi saya ingin mengembangkan aplikasi iOS.
