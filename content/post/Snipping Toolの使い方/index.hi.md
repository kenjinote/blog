## Snipping Tool के बारे में

Snipping Tool Windows में शामिल स्क्रीन कैप्चर ऐप है। समर्थित Windows और ऐप संस्करणों में यह चित्र कैप्चर और वीडियो रिकॉर्ड कर सकता है। अपडेट के साथ स्क्रीन और नाम बदल सकते हैं।

## ऐप खोलें

Start मेनू में Snipping Tool खोजकर खोलें। स्क्रीनशॉट ओवरले के लिए `Win + Shift + S` और वीडियो रिकॉर्डिंग ओवरले के लिए `Win + Shift + R` दबाएँ।


## स्क्रीनशॉट लें

`Win + Shift + S` दबाकर आयताकार, freeform, window या full-screen snip चुनें। क्षेत्र चुनने पर चित्र Snipping Tool में खुलेगा, जहाँ उसे संपादित और सहेजा जा सकता है।

![Snipping Tool interface](img_1.webp)

## स्क्रीन रिकॉर्ड करें

रिकॉर्डिंग समर्थित Windows संस्करण में Snipping Tool में Record > New चुनें या `Win + Shift + R` दबाएँ। क्षेत्र चुनें, Start दबाएँ, फिर Stop करके रिकॉर्डिंग सहेजें।

## संस्करण नोट

स्क्रीनशॉट में जापानी UI है। स्क्रीन और सहेजने की जगह Windows/app संस्करण और सेटिंग के अनुसार बदल सकती है।
