## 什么是 Snipping Tool
Snipping Tool 是 Windows 自带的屏幕截图工具。您可以截取屏幕的一部分并保存，或者捕获整个屏幕，还可以进行录屏。

## Snipping Tool 启动方法

主要可以通过以下 3 种方法启动。

- 按 `Win键`，输入 `Snipping Tool` 并按 `Enter键`。
- 按 `Win键` + `Shift` + `S键`。
- 按 `Win键` + `R键`，输入 `snippingtool` 并按 `Enter键`。

## Snipping Tool 使用方法
![img_1.png](img_1.png)

### 保存截图的方法如下：

1. 选择 `相机` 图标。
2. 点击 `新建` 按钮。
3. 选择要截取的范围。
4. 点击 `另存为` 按钮。
5. 输入保存路径和文件名并保存。

### 录制屏幕视频的方法如下：

1. 选择 `视频` 图标。
2. 点击 `新建` 按钮。
3. 选择要录制的范围。
4. 点击 `开始` 按钮。
5. 录制屏幕。
6. 点击 `停止` 按钮。
7. 点击 `另存为` 按钮。
8. 输入保存路径和文件名并保存。
