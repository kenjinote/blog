## حول Snipping Tool

أداة Snipping Tool هي تطبيق التقاط الشاشة المضمّن في Windows. تتيح الإصدارات المدعومة من Windows والتطبيق التقاط الصور وتسجيل الفيديو. قد تتغير الواجهة والتسميات مع التحديثات.

## فتح التطبيق

ابحث عن Snipping Tool في قائمة ابدأ وافتحه. يفتح `Win + Shift + S` واجهة التقاط الصور، ويفتح `Win + Shift + R` واجهة تسجيل الفيديو.


## التقاط صورة للشاشة

اضغط `Win + Shift + S` واختر قصاً مستطيلاً أو حراً أو لنافذة أو للشاشة كاملة. حدد المنطقة؛ ستظهر الصورة في Snipping Tool لتحريرها وحفظها.

![Snipping Tool interface](img_1.webp)

## تسجيل الشاشة

في إصدارات Windows التي تدعم التسجيل، اختر Record > New داخل Snipping Tool أو اضغط `Win + Shift + R`. حدد المنطقة، وابدأ التسجيل، ثم أوقفه واحفظه.

## ملاحظات الإصدار

تُظهر الصورة الواجهة اليابانية. قد يختلف الشكل ومكان الحفظ حسب إصدار Windows والتطبيق والإعدادات.
