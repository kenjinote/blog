# Sejarah Pengembangan Low-Code / No-Code (1980-an hingga Sekarang)

Pengembangan Low-code / No-code adalah metode pengembangan yang memungkinkan Anda membuat aplikasi, situs web, dan basis data tanpa memerlukan keahlian khusus dalam pemrograman. Konsep ini dimulai pada 1980-an dan telah berkembang sebagai berbagai platform seiring dengan penyebaran PC, evolusi internet, dan perluasan teknologi cloud. Dalam artikel ini, kami akan menyoroti alat dan layanan representatif per dekade, serta memperkenalkan fitur dan harganya.

---

## 1980-an: Masa Awal

* **HyperCard (Apple, 1987)**
  Alat pembuatan aplikasi untuk Macintosh. Menyusun layar dalam bentuk kartu dan membuat GUI melalui drag-and-drop. Kontrol operasi sederhana juga dimungkinkan menggunakan bahasa skrip aslinya "HyperTalk". Alat ini populer untuk tujuan pembuatan prototipe. Harga rilis adalah $49,95, dan kemudian diberikan secara gratis untuk pembeli Mac baru. Versi terakhir dirilis pada tahun 1998, dan tidak ada dukungan untuk Mac OS X dan yang lebih baru.

* **FileMaker (Claris/Apple, 1985)**
  Perangkat lunak basis data grafis. Alat basis data relasional yang dilengkapi tampilan data tabular, serta pengeditan tata letak bebas dan fungsi skrip. Saat ini ditawarkan sebagai "Claris FileMaker Pro", dan versi lisensi penuh seharga $594 (per 2024).

---

## 1990-an: Munculnya Aplikasi GUI dan Pengembangan Sistem Bisnis

* **Visual Basic (Microsoft, 1991)**
  IDE (Integrated Development Environment) yang dikhususkan untuk pengembangan aplikasi Windows. Aplikasi berbasis peristiwa dapat dibangun dengan mudah dengan melakukan drag-and-drop komponen GUI seperti tombol dan label. Dengan rilisnya VB6.0 pada tahun 1998, ia bertransisi ke era .NET.

* **Microsoft Access (1992)**
  Alat pengembangan basis data untuk Windows. Memungkinkan desain basis data relasional dan pembuatan formulir melalui GUI, dan secara luas digunakan untuk pengembangan aplikasi bisnis umum. Saat ini ditawarkan sebagai bagian dari Microsoft 365.

* **PowerBuilder (PowerSoft/Sybase, 1991)**
  Alat pengembangan 4GL untuk aplikasi bisnis. Mendukung arsitektur klien/server dan memiliki keunggulan dalam integrasi basis data. Saat ini terus ditawarkan di bawah naungan SAP.

* **Dreamweaver (Macromedia, 1997)**
  Alat WYSIWYG yang memungkinkan pembuatan halaman web secara visual. Memungkinkan peralihan antara pengeditan HTML dan tampilan desain, serta mendukung ASP dan PHP. Saat ini ditawarkan oleh Adobe dan tersedia melalui langganan (sekitar $34,49 per bulan).

* **Flash (Macromedia, 1996)**
  Awalnya adalah alat pembuatan animasi vektor yang dikembangkan sebagai FutureSplash Animator. Kemudian dimanfaatkan untuk pembuatan konten interaktif web, namun dukungannya dihentikan pada tahun 2020 karena masalah keamanan.

* **GameMaker (1999)**
  Alat pembuatan game 2D untuk pemula. Penempatan objek dan kontrol peristiwa dimungkinkan melalui drag-and-drop. Kemudian juga mendukung skrip (GML), dan saat ini berbagai paket ditawarkan untuk komersial.

---

## 2000-an: Perluasan Berbasis Web dan Open Source

* **WordPress (2003)**
  CMS open source yang menggunakan PHP dan MySQL. Memungkinkan Anda membangun blog atau situs web perusahaan menggunakan tema dan plugin tanpa pengetahuan pemrograman. Didistribusikan secara gratis dan merupakan salah satu CMS yang paling banyak digunakan di dunia.

* **Wix (2006)**
  Layanan no-code yang memungkinkan Anda membangun situs web di browser. Anda dapat memilih template dan mengeditnya dengan drag-and-drop. Selain paket gratis, paket berbayar memungkinkan penggunaan domain kustom dan fitur e-commerce.

* **OutSystems (2001)**
  Platform low-code untuk perusahaan (enterprise). Karena sistem bisnis dapat dikembangkan dengan cepat, adopsinya semakin maju di perusahaan besar dan lembaga pemerintah. Mendukung cloud maupun on-premise.

* **Scratch (MIT, 2007)**
  Alat pembelajaran pemrograman yang dikembangkan untuk anak-anak. Permainan dan animasi dapat dibuat dengan menggabungkan balok berwarna, dan secara luas digunakan dalam lingkungan pendidikan. Disediakan secara gratis.

* **Airtable (2013)**
  Layanan berbasis cloud yang menggabungkan spreadsheet dan basis data. Terlihat mirip dengan Excel tetapi memungkinkan relasi, tampilan kanban, integrasi API, dll. Secara luas digunakan mulai dari individu hingga perusahaan.

---

## 2010-an ~ 2020-an: Era Cloud dan Otomatisasi

Dalam beberapa tahun terakhir, alat low-code / no-code berbasis cloud telah berkembang pesat.

* **Power Platform (Microsoft)**
  Platform pengembangan dan otomatisasi aplikasi bisnis terintegrasi yang mencakup "Power Apps", "Power Automate", dll. Memungkinkan Anda membangun proses bisnis perusahaan secara visual melalui drag-and-drop.

* **Salesforce Lightning Platform**
  Platform pengembangan aplikasi yang disediakan oleh Salesforce, sebuah CRM. Memungkinkan pembuatan aplikasi bisnis melalui GUI, dan integrasi dengan layanan Salesforce lainnya juga mudah.

* **Zapier / IFTTT**
  Alat otomatisasi yang memungkinkan Anda membangun integrasi antar beberapa layanan cloud tanpa pengkodean (coding). Misalnya, alur kerja seperti "Beri tahu Slack saat ada input masuk di Google Forms" dapat diwujudkan dengan mudah.

* **Notion (2010-an)**
  Ruang kerja all-in-one yang mengintegrasikan manajemen dokumen, manajemen tugas, Wiki, dll. Juga dilengkapi dengan fitur basis data kustom, yang berguna untuk peningkatan proses bisnis tanpa kode.

* **Construct 3 / GameSalad**
  Alat yang memungkinkan Anda membuat game dengan drag-and-drop. Construct 3 mendukung HTML5 dan dapat berjalan di browser, sehingga populer di dunia pendidikan dan di kalangan pengembang indie.
