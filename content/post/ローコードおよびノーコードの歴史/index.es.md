# Historia del desarrollo low-code / no-code (Desde la década de 1980 hasta el presente)

El desarrollo low-code / no-code es un método de desarrollo que permite crear aplicaciones, sitios web y bases de datos sin necesidad de tener conocimientos especializados en programación. Esta idea comenzó en la década de 1980 y ha evolucionado como diversas plataformas junto con la popularización de las PC, la evolución de Internet y la expansión de las tecnologías en la nube. En este artículo, presentaremos herramientas y servicios representativos por década, destacando sus características y precios.

---

## Década de 1980: Los primeros años

* **HyperCard (Apple, 1987)**
  Herramienta de creación de aplicaciones para Macintosh. Configura pantallas en formato de tarjetas y permite crear interfaces gráficas (GUI) mediante arrastrar y soltar (drag & drop). También permite un control básico de acciones mediante su propio lenguaje de scripting, "HyperTalk". Fue popular para el prototipado. Su precio de lanzamiento fue de 49.95 dólares, y posteriormente se ofreció de forma gratuita a los nuevos compradores de Mac. Su versión final fue en 1998 y no fue compatible con Mac OS X y versiones posteriores.

* **FileMaker (Claris/Apple, 1985)**
  Software de base de datos gráfica. Es una herramienta de base de datos relacional que, además de mostrar datos en formato de tabla, cuenta con edición de diseño libre y funciones de scripting. Actualmente se ofrece como "Claris FileMaker Pro", y la versión con licencia completa cuesta 594 dólares (a partir de 2024).

---

## Década de 1990: El auge de las aplicaciones GUI y el desarrollo empresarial

* **Visual Basic (Microsoft, 1991)**
  IDE especializado en el desarrollo de aplicaciones para Windows. Permitía construir fácilmente aplicaciones basadas en eventos al colocar componentes de la GUI (como botones y etiquetas) mediante arrastrar y soltar. Tras VB6.0 en 1998, se transicionó a la era .NET.

* **Microsoft Access (1992)**
  Herramienta de desarrollo de bases de datos para Windows. Permite el diseño de bases de datos relacionales y la creación de formularios mediante GUI, siendo ampliamente utilizada para el desarrollo de aplicaciones empresariales para el público general. Actualmente se ofrece como parte de Microsoft 365.

* **PowerBuilder (PowerSoft/Sybase, 1991)**
  Herramienta de desarrollo 4GL para aplicaciones empresariales. Compatible con la arquitectura cliente-servidor y con fuertes capacidades de integración de bases de datos. Actualmente sigue siendo ofrecido bajo el paraguas de SAP.

* **Dreamweaver (Macromedia, 1997)**
  Herramienta WYSIWYG que permite la creación visual de páginas web. Permite alternar entre la edición de HTML y la vista de diseño, y también contaba con soporte para ASP y PHP. Actualmente es ofrecida por Adobe y está disponible mediante suscripción (aproximadamente 34.49 dólares al mes).

* **Flash (Macromedia, 1996)**
  Originalmente desarrollada como FutureSplash Animator, es una herramienta de creación de animaciones vectoriales. Posteriormente se utilizó para la creación de contenido interactivo para la web, pero su soporte finalizó en 2020 debido a problemas de seguridad.

* **GameMaker (1999)**
  Herramienta de creación de juegos 2D para principiantes. La colocación de objetos y el control de eventos son posibles mediante arrastrar y soltar. Posteriormente también añadió soporte para scripting (GML) y actualmente ofrece múltiples planes para uso comercial.

---

## Década de 2000: La expansión de la web y el código abierto

* **WordPress (2003)**
  CMS de código abierto que utiliza PHP y MySQL. Permite construir blogs y sitios web corporativos utilizando temas y plugins sin necesidad de conocimientos de programación. Se distribuye gratuitamente y es uno de los CMS más utilizados en todo el mundo.

* **Wix (2006)**
  Servicio no-code que permite construir sitios web en el navegador. Permite elegir plantillas y editarlas mediante arrastrar y soltar. Además del plan gratuito, los planes pagos permiten el uso de dominios personalizados y funciones de comercio electrónico (e-commerce).

* **OutSystems (2001)**
  Plataforma low-code para empresas. Debido a que permite desarrollar sistemas empresariales rápidamente, su adopción avanza en grandes empresas y agencias gubernamentales. Compatible tanto con la nube como con infraestructuras locales (on-premises).

* **Scratch (MIT, 2007)**
  Herramienta de aprendizaje de programación desarrollada para niños. Permite crear juegos y animaciones combinando bloques de colores, y se utiliza ampliamente en entornos educativos. Se ofrece de forma gratuita.

* **Airtable (2013)**
  Servicio basado en la nube que combina hojas de cálculo y bases de datos. Su apariencia es similar a Excel, pero permite relaciones, vistas Kanban, integración de API, entre otros. Es ampliamente utilizado tanto por individuos como por corporaciones.

---

## Década de 2010 - 2020: La era de la nube y la automatización

En los últimos años, las herramientas low-code / no-code basadas en la nube han evolucionado rápidamente.

* **Power Platform (Microsoft)**
  Plataforma integrada para el desarrollo y automatización de aplicaciones empresariales, que incluye "Power Apps" y "Power Automate". Permite construir visualmente procesos empresariales corporativos mediante arrastrar y soltar.

* **Salesforce Lightning Platform**
  Base de desarrollo de aplicaciones ofrecida por el CRM Salesforce. Permite crear aplicaciones empresariales con GUI y su integración con otros servicios de Salesforce es sencilla.

* **Zapier / IFTTT**
  Herramientas de automatización que permiten construir conexiones entre múltiples servicios en la nube sin necesidad de programar. Por ejemplo, se pueden implementar fácilmente flujos de trabajo como "Notificar a Slack cuando se ingrese información en Google Forms".

* **Notion (Década de 2010)**
  Espacio de trabajo todo en uno que integra la gestión de documentos, gestión de tareas, Wiki, etc. También cuenta con funciones de base de datos personalizada y es útil para la mejora de procesos empresariales sin necesidad de código.

* **Construct 3 / GameSalad**
  Herramientas que permiten crear juegos mediante arrastrar y soltar. Construct 3 es compatible con HTML5 y funciona en el navegador, siendo popular en entornos educativos y entre desarrolladores independientes.

## Fuentes de información y notas adicionales

Este artículo se ha elaborado basándose en los sitios web oficiales de cada producto, Wikipedia y materiales/artículos de alta fiabilidad (Apple, Microsoft, Adobe, etc.). Muchas de las herramientas de la década del 2000 en adelante son de suscripción, y las tarifas varían según el plan.
