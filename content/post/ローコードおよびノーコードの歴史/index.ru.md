# История разработки Low-Code / No-Code (с 1980-х годов до наших дней)

Разработка Low-code / No-code — это метод разработки, который позволяет создавать приложения, веб-сайты и базы данных без специализированных знаний в программировании. Эта концепция зародилась в 1980-х годах и развивалась в виде различных платформ вместе с распространением ПК, эволюцией Интернета и расширением облачных технологий. В этой статье мы рассмотрим типичные инструменты и сервисы по десятилетиям, а также расскажем об их особенностях и ценах.

---

## 1980-е годы: Ранний этап

* **HyperCard (Apple, 1987)**
  Инструмент для создания приложений для Macintosh. Экраны строились в виде карточек, а графический интерфейс (GUI) создавался с помощью перетаскивания (drag-and-drop). Также было возможно простое управление действиями с помощью собственного скриптового языка "HyperTalk". Пользовался популярностью для прототипирования. Цена на момент выпуска составляла 49,95 долларов, а позже он предоставлялся бесплатно новым покупателям Mac. Последняя версия вышла в 1998 году, и поддержки Mac OS X и выше нет.

* **FileMaker (Claris/Apple, 1985)**
  Графическое программное обеспечение для баз данных. Инструмент реляционных баз данных, предлагающий табличное отображение данных наряду со свободным редактированием макетов и функциями скриптов. В настоящее время предлагается как "Claris FileMaker Pro", а полная версия лицензии стоит 594 доллара (на 2024 год).

## 1990-е годы: Появление приложений с GUI и корпоративной разработки

* **Visual Basic (Microsoft, 1991)**
  Интегрированная среда разработки (IDE), специализирующаяся на разработке приложений для Windows. Можно было легко создавать приложения, управляемые событиями, перетаскивая компоненты GUI, такие как кнопки и метки. После выпуска VB6.0 в 1998 году произошел переход к эпохе .NET.

* **Microsoft Access (1992)**
  Инструмент разработки баз данных для Windows. Позволял проектировать реляционные базы данных и создавать формы через GUI, широко использовался для разработки корпоративных приложений общего назначения. В настоящее время предлагается как часть Microsoft 365.

* **PowerBuilder (PowerSoft/Sybase, 1991)**
  Инструмент разработки 4GL для бизнес-приложений. Поддерживал архитектуру клиент/сервер и имел сильные стороны в интеграции баз данных. В настоящее время продолжает предлагаться под эгидой SAP.

* **Dreamweaver (Macromedia, 1997)**
  Инструмент WYSIWYG, позволяющий визуально создавать веб-страницы. Позволял переключаться между редактированием HTML и просмотром дизайна, а также поддерживал ASP и PHP. В настоящее время предлагается Adobe по подписке (около 34,49 долларов в месяц).

* **Flash (Macromedia, 1996)**
  Первоначально инструмент для создания векторной анимации, разработанный как FutureSplash Animator. Позже использовался для создания интерактивного веб-контента, но поддержка была прекращена в 2020 году из-за проблем с безопасностью.

* **GameMaker (1999)**
  Инструмент для создания 2D-игр для начинающих. Размещение объектов и управление событиями возможно с помощью перетаскивания. Позже добавлена поддержка скриптов (GML), и в настоящее время предлагаются различные планы для коммерческого использования.

## 2000-е годы: Распространение веб-технологий и открытого исходного кода

* **WordPress (2003)**
  CMS с открытым исходным кодом на базе PHP и MySQL. Позволяет создавать блоги и корпоративные сайты с использованием тем и плагинов без знаний программирования. Распространяется бесплатно и является одной из самых используемых CMS в мире.

* **Wix (2006)**
  Сервис no-code, позволяющий создавать веб-сайты прямо в браузере. Вы можете выбрать шаблон и редактировать его с помощью drag-and-drop. Помимо бесплатного плана, платные планы позволяют использовать собственные домены и функции электронной коммерции.

* **OutSystems (2001)**
  Платформа low-code для предприятий. Позволяет быстро разрабатывать бизнес-системы, поэтому её внедрение активно продвигается в крупных компаниях и государственных учреждениях. Поддерживает как облачные, так и локальные решения.

* **Scratch (MIT, 2007)**
  Инструмент для обучения программированию, разработанный для детей. Позволяет создавать игры и анимации путем объединения цветных блоков, широко используется в образовательной среде. Предоставляется бесплатно.

* **Airtable (2013)**
  Облачный сервис, объединяющий электронные таблицы и базы данных. Внешне похож на Excel, но позволяет устанавливать связи, использовать канбан-доски, интегрироваться с API и многое другое. Широко используется как частными лицами, так и корпорациями.

## 2010-е — 2020-е годы: Эпоха облаков и автоматизации

В последние годы облачные инструменты low-code / no-code стремительно развиваются.

* **Power Platform (Microsoft)**
  Интегрированная платформа для разработки бизнес-приложений и автоматизации, включающая "Power Apps" и "Power Automate". Позволяет визуально выстраивать бизнес-процессы компании с помощью drag-and-drop.

* **Salesforce Lightning Platform**
  Платформа разработки приложений, предоставляемая CRM-системой Salesforce. Позволяет создавать бизнес-приложения с помощью GUI и легко интегрироваться с другими сервисами Salesforce.

* **Zapier / IFTTT**
  Инструменты автоматизации, позволяющие настраивать интеграцию между несколькими облачными сервисами без написания кода. Например, легко реализуются рабочие процессы вроде «отправить уведомление в Slack при заполнении формы Google».

* **Notion (2010-е годы)**
  Универсальное рабочее пространство, объединяющее управление документами, задачами, Wiki и многое другое. Также включает функцию пользовательских баз данных, что помогает улучшать рабочие процессы без написания кода.

* **Construct 3 / GameSalad**
  Инструменты, позволяющие создавать игры с помощью drag-and-drop. Construct 3 поддерживает HTML5 и работает в браузере, пользуясь популярностью в сфере образования и среди инди-разработчиков.

## Источники информации и примечания

Эта статья составлена на основе официальных сайтов каждого продукта, Википедии, а также надежных материалов и статей (Apple, Microsoft, Adobe и др.). Информация о ценах по возможности отражает официальные данные на тот момент или на сегодняшний день (в основном указаны в долларах США). Большинство инструментов, появившихся после 2000-х годов, работают по модели подписки, и цены варьируются в зависимости от плана.
