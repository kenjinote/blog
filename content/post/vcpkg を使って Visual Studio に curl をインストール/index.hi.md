## अगर आप Visual Studio में libcurl (OpenSSL समर्थित) का उपयोग करना चाहते हैं, तो vcpkg स्थापित करना आसान है और अनुशंसित है

C++ में HTTP संचार को संभालते समय अक्सर libcurl का उपयोग किया जाता है। लेकिन, निर्माण और निर्भरता को समायोजित करना आश्चर्यजनक रूप से परेशानी भरा हो सकता है।

ऐसे समय में Microsoft का C++ लाइब्रेरी प्रबंधन उपकरण ** "vcpkg" ** बहुत काम आता है।
इस बार, हम cpkg का उपयोग करके libcurl (OpenSSL समर्थित) स्थापित करने और इसे Visual Studio में सुचारू रूप से उपयोग करने योग्य बनाने की प्रक्रिया का परिचय देंगे।

---

### vcpkg की स्थापना (केवल उनके लिए जिन्होंने इसे स्थापित नहीं किया है)

सबसे पहले cpkg स्थापित करते हैं। कृपया PowerShell में निम्न चरणों का पालन करें।

`powershell
git clone https://github.com/microsoft/vcpkg
cd vcpkg
.ootstrap-vcpkg.bat
`

※यदि आपने अभी तक Git स्थापित नहीं किया है, तो कृपया इसे [Git की आधिकारिक वेबसाइट](https://git-scm.com/) से स्थापित करें।

---

### libcurl (OpenSSL समर्थित) की स्थापना

इसके बाद, vcpkg का उपयोग करके libcurl स्थापित करें। OpenSSL का समर्थन करने वाले 64-बिट संस्करण को निर्दिष्ट करने के लिए, निम्न कमांड चलाएँ।

`powershell
vcpkg install curl[ssl] --triplet x64-windows
`

इस कमांड को चलाने पर, आवश्यक निर्भरताएँ (जैसे OpenSSL) भी स्वचालित रूप से सेट हो जाती हैं।

---

### Visual Studio के साथ एकीकरण सेटिंग

vcpkg द्वारा स्थापित लाइब्रेरीज़ को अपने Visual Studio प्रोजेक्ट से आसानी से उपयोग करने के लिए, निम्नलिखित कमांड के साथ एकीकरण सेटिंग्स कॉन्फ़िगर करें।

`powershell
vcpkg integrate install
`

एक बार यह सेट हो जाने पर, #include <curl/curl.h> स्वचालित रूप से Visual Studio प्रोजेक्ट्स में उपलब्ध हो जाएगा, और आपको मैन्युअल रूप से लाइब्रेरी पथ या लिंकर सेटिंग्स को कॉन्फ़िगर करने की आवश्यकता नहीं होगी।

---

## निष्कर्ष

इसके साथ, Visual Studio में libcurl (OpenSSL समर्थित) स्थापित करने की तैयारी पूरी हो गई है।

* vcpkg का उपयोग करके, आप एक साथ परेशानी वाली निर्भरताओं को प्रबंधित कर सकते हैं
* cpkg install curl[ssl] --triplet x64-windows के साथ आसानी से libcurl स्थापित करें
* cpkg integrate install के साथ Visual Studio के साथ स्वचालित एकीकरण संभव है

अब, बस अपने प्रोजेक्ट में हेडर को शामिल करें और विकास शुरू करने के लिए libcurl के API का उपयोग करें।
कृपया सुविधाजनक vcpkg का लाभ उठाएं और अपने विकास की दक्षता को बढ़ाएं।
