## Если вы хотите использовать libcurl (с поддержкой OpenSSL) в Visual Studio, то установка vcpkg — это простой и рекомендуемый способ

`libcurl` часто используется, когда вы хотите работать с HTTP-соединениями в C++. Но настройка сборки и зависимостей может оказаться неожиданно сложной задачей.

В таких случаях на помощь приходит инструмент управления библиотеками C++ от Microsoft — ** «vcpkg» ** .
В этот раз я расскажу о шагах по использованию `vcpkg` для установки `libcurl` (с поддержкой OpenSSL) и его бесперебойного использования в Visual Studio.

---

### Установка vcpkg (только для тех, кто еще не установил)

Сначала давайте установим `vcpkg`. Пожалуйста, выполните следующие шаги в PowerShell.

```powershell
git clone https://github.com/microsoft/vcpkg
cd vcpkg
.\bootstrap-vcpkg.bat
```

※ Если у вас еще не установлен Git, установите его с [официального сайта Git](https://git-scm.com/).

---

### Установка libcurl (с поддержкой OpenSSL)

Затем мы используем vcpkg для установки `libcurl`. Чтобы указать 64-битную версию, совместимую с OpenSSL, выполните следующую команду.

```powershell
vcpkg install curl[ssl] --triplet x64-windows
```

При выполнении этой команды необходимые зависимости (такие как OpenSSL) также будут настроены автоматически.

---

### Настройка интеграции с Visual Studio

Чтобы упростить использование библиотек, установленных с помощью vcpkg, из ваших проектов Visual Studio, настройте интеграцию с помощью следующей команды.

```powershell
vcpkg integrate install
```

После этой настройки вы сможете автоматически использовать `#include <curl/curl.h>` в проектах Visual Studio, и вам больше не нужно будет вручную настраивать пути к библиотекам или параметры компоновщика.

---

## В заключение

Теперь вы готовы использовать `libcurl` (с поддержкой OpenSSL) в Visual Studio.

* С помощью vcpkg вы можете управлять всеми сложными зависимостями сразу
* Легко установить libcurl с помощью `vcpkg install curl[ssl] --triplet x64-windows`
* Автоматическая интеграция с Visual Studio с помощью `vcpkg integrate install`

После этого просто включите заголовочный файл в свой проект и начните разработку с использованием API libcurl.
Воспользуйтесь удобным vcpkg, чтобы значительно повысить эффективность разработки.
