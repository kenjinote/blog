## 1. 终极的“不完全信息游戏”

国际象棋、将棋和黑白棋等，盘面的信息对双方完全公开，被称为“完全信息游戏”。相对地，像扑克或麻将这样无法看到对手手牌的，则被归类为 **不完全信息游戏** 。

因为无法看到对手的手牌，所以存在运气的成分。但是，在扑克中决定长期胜负的并不是运气。而是 **数学（概率与赔率）、心理（诈唬），以及风险管理（资金管理）** 。
目前世界上最主流的扑克规则 **德州扑克** ，作为一项受到投资者和程序员狂热喜爱的高级智力运动（脑力竞技）而广为人知。

## 2. 德州扑克的基本规则

日本传统的扑克（换牌扑克）是发5张牌并进行更换，但德州扑克的规则完全不同。

- **手牌（底牌）**: 每个玩家只发 **2张** 牌（只有自己能看）。
- **公共牌**: 在牌桌中央，最多会面朝上翻开 **5张** 所有人都可以使用的公共牌。
- **凑牌型的方法**: 从自己的2张手牌和5张公共牌 **合计7张牌中，挑出最强的5张组合（牌型）** ，凑出最强牌型的人获胜。

### 押注（下注）的回合

每次翻开牌时，都会发生4次下注（或弃牌）的行动。

1. **翻牌前**: 只发了自己2张手牌状态下的下注。
2. **翻牌圈**: 翻开了“3张”公共牌状态下的下注。
3. **转牌圈**: 翻开了“第4张”公共牌状态下的下注。
4. **河牌圈**: 翻开了最后“第5张”公共牌状态下的下注。
5. **摊牌**: 所有人亮出底牌，胜者赢走所有筹码。

在途中的任何时候，只要觉得“不想再出筹码了”，随时都可以 **弃牌（Fold）** 退出该局游戏。反过来说，如果对手全部弃牌，那么无论你的手牌多弱，作为“剩下的最后一人”，你都可以赢走所有筹码。这就是 **诈唬（Bluff）** 能够成立的机制。

## 3. 为什么“位置”决定一切？

在德州扑克中，和手牌强度同样（甚至更加）重要的是 **位置（座位顺序）** 。
从被称为庄家按钮 (Dealer Button) 的标志左边开始，顺时针进行行动（下注）， **越靠后行动的人拥有压倒性的优势** 。

```mermaid

    SB["SB (先行动)"] --> BB["BB"]
    BB --> UTG["UTG (前段)"]
    UTG --> MP["MP (中段)"]
    MP --> CO["CO (后段)"]
    CO --> BTN["BTN (最后行动/最强)"]
```

这是因为越靠后行动的玩家（尤其是BTN：按钮位）， **越能看清“前面的人是下注了（牌很强），还是弃牌了（牌很弱）”等所有信息后再决定自己的行动** 。
因此，新手必须遵守“处在前面的位置时，除非是非常强的手牌（如AA或KK），否则不要参与”这种严格的理论（起手牌范围）。

## 4. 期望值（EV）与底池赔率的数学

扑克的本质不是赌博，而是 **永远重复期望值 (Expected Value: EV) 为正的投资操作** 。

例如，假设桌上的筹码（底池）有“$100”。
对手下注了“$50”。为了继续游戏（跟注），你需要支付“$50”。
此时，底池总额是 $150，而你需要支付 $50。也就是说，赔率是“150 : 50 = 3 : 1”。
这推导出了一个数学结论： **只要胜率达到25%以上（1 / 4），这场对决就值得花钱去接（期望值为正）** 。

职业扑克玩家不仅看手牌强度和对手的习惯，还会时刻心算这种“底池赔率”和“自己想要的牌出现的概率（出牌数：Outs）”，并排除感情因素，只做出数学上正确的选择。

## 5. 诈唬不是“谎言”，而是“数学故事”

诈唬（用弱牌下大注逼迫对手弃牌）并不像电影里那样，看着对手的眼睛“识破谎言”的心理战。现代扑克的诈唬极具逻辑性。

强大的玩家在经历翻牌前、翻牌圈、转牌圈和河牌圈的过程中，会 **进行连贯且具有故事性的下注** ，就好像自己真的拿到了很强的牌（例如同花）一样。
在对手看来，“他从初期就开始一直下注这个金额。那么，从概率上来说，认为他持有那种强牌是符合逻辑的。所以弃牌吧”，作为做出数学上正确判断的结果，诈唬就成功了。

## 6. 总结

人们常说德州扑克“学会规则只需10分钟，但精通却需要一生”。
在短期的1手牌或1天的时间里，有时“运气好拿到强牌的新手”也能战胜职业选手。但是，当尝试次数累积到1万手、10万手时，那些基于期望值不断做出正确决断的玩家，他们的利润将呈现出完美的直线上升趋势。
这个运气与实力、概率与心理错综复杂交织在一起的扑克世界，可以说是商业和投资的最佳训练场。
