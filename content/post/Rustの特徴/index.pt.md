# Características do Rust

- Uma linguagem de programação de código aberto relativamente nova desenvolvida pela Mozilla
- Linguagem rápida, sem coleta de lixo (garbage collection), especializada em programação de sistemas
- Garante a segurança de memória com mecanismos únicos de propriedade (ownership) e empréstimo (borrowing) como especificações da linguagem
- Funciona em multiplataformas
- Possui o excelente gerenciador de pacotes Cargo como padrão
