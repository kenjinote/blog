# Особенности Rust

- Относительно новый язык программирования с открытым исходным кодом, разрабатываемый Mozilla
- Быстрый язык без сборщика мусора, специально предназначенный для системного программирования
- Имеет уникальный механизм владения и заимствования в качестве спецификации языка, что обеспечивает безопасность памяти
- Работает на различных кросс-платформах
- Стандартно поставляется с отличным менеджером пакетов Cargo
