# Rust(러스트)의 특징

- Mozilla가 개발하고 있는 비교적 새로운 오픈 소스 프로그래밍 언어
- 가비지 컬렉션이 없으며, 빠르고 시스템 프로그래밍에 특화된 언어
- 소유권과 차용이라는 독특한 메커니즘을 언어 사양으로 가지며, 메모리 안전성을 보장한다
- 크로스 플랫폼에서 동작한다
- Cargo라는 우수한 패키지 매니저를 표준으로 갖추고 있다
