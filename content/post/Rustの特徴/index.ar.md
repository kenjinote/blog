# ميزات Rust

- لغة برمجة مفتوحة المصدر حديثة نسبياً يتم تطويرها بواسطة Mozilla
- لغة سريعة بدون جمع القمامة، متخصصة في برمجة النظم
- تمتلك آلية فريدة للملكية والاستعارة كمواصفات لغة لضمان أمان الذاكرة
- تعمل عبر منصات متعددة
- تمتلك مدير حزم ممتاز يسمى Cargo بشكل قياسي
