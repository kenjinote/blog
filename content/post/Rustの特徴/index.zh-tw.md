# Rust 的特徵

- 由 Mozilla 開發的相對較新的開源程式語言
- 沒有垃圾回收機制（garbage collection），是一種專為系統編程設計的高速語言
- 將所有權（ownership）和借用（borrowing）的獨特機制做為語言規範，保證記憶體安全
- 支援跨平台運行
- 標配了優秀的套件管理器 Cargo
