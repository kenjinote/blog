# 買了一台筆記型電腦 ThinkPad（二手）

在筆記型電腦上的工作幾乎都是透過遠端桌面連線進入其他終端機來進行，所以我不需要高規格的電腦。原本 ChromeBook 也可以，但因為沒有好看的設計或高解析度，所以我買了 ThinkPad。

規格如下，使用了各種點數後，價格大約是 5 萬 5 千日圓。

## ThinkPad T470s

- CPU: Intel Core i7-7600U
- RAM: 24GB
- SSD: 512GB
- OS: Windows 10 Pro 64bit
- 螢幕: 14.0 吋寬螢幕（防眩光面板）
- 解析度: WQHD 液晶 2560×1440
- 重量: 約 1.32kg
- 備註: 英文鍵盤

因為是二手的，我原本還在想會不會有使用痕跡或刮傷，但完全沒有問題，真是太好了。
目前電池用起來也沒什麼問題。

## 目前想到的不滿意之處
- 這款鍵盤沒有獨立的 `Pause` 鍵和 `App` 鍵。我以前在自己的快速鍵設定中將 `Pause` 指定為開啟「設定」（這不是 Windows 的預設功能）。`App` 鍵通常用來開啟操作功能表；沒有該鍵時，也可以按 `Shift + F10`。
- `PageUp` 鍵和 `PageDown` 鍵就在鍵盤方向鍵的旁邊，所以我經常按錯。這可能是需要習慣的問題。

## 目前的支援狀態（截至2026年11月）

本文記錄的是2023年1月購買時的情況，並非目前的購機建議。Windows 10一般支援已於2025年10月14日結束。未加入ESU的電腦不再接收一般安全性更新。符合資格的Windows 10電腦可透過ESU繼續接收更新；請確認註冊條件及適用期限（Microsoft目前列出的消費者ESU計畫至2027年10月12日）。本機搭載的Core i7-7600U未列入Microsoft目前支援的Windows 11處理器清單。購買前請確認作業系統支援狀態及升級資格。
