# Saya Membeli Laptop ThinkPad (Bekas)

Karena pekerjaan saya di laptop sebagian besar dilakukan melalui koneksi desktop jarak jauh ke perangkat lain, saya tidak memerlukan PC berspesifikasi tinggi. ChromeBook sebenarnya bisa saja, tetapi karena tidak ada desain yang bagus atau resolusi tinggi, saya membeli ThinkPad.

Spesifikasinya seperti di bawah ini, dan harganya sekitar 55.000 yen menggunakan berbagai poin.

## ThinkPad T470s

- CPU: Intel Core i7 7600U
- RAM: 24GB
- SSD: 512GB
- OS: Windows 10 Pro 64bit
- Layar: 14,0 inci lebar (panel non-glare)
- Resolusi: LCD WQHD 2560×1440
- Berat: sekitar 1,32kg
- Catatan: Keyboard bahasa Inggris

Karena bekas, saya pikir mungkin ada tanda-tanda penggunaan atau goresan, tetapi ternyata sama sekali tidak ada masalah dan bagus.
Baterai juga berfungsi tanpa masalah sejauh ini.

## Keluhan yang bisa saya pikirkan saat ini
- Tidak ada tombol `Pause` dan tombol `App`. Saya menggunakan tombol `Pause` sebagai pintasan untuk membuka pengaturan sistem. Selain itu, saya menggunakan tombol `App` untuk membuka menu pop-up, jadi tidak nyaman tanpa tombol tersebut.
- Tombol `PageUp` dan `PageDown` berada tepat di sebelah tombol panah pada keyboard, jadi saya sering salah menekannya. Mungkin ini hanya masalah kebiasaan.
