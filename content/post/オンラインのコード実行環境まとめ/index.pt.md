## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

Google Colaboratory é um ambiente de execução de código Python online.

- O uso de GPU também é possível.
- Usando os notebooks do Colab, você pode escrever código executável e rich text (incluindo imagens, HTML, LaTeX, etc.) em um único documento.

É baseado no Jupyter Notebook.

## Outros

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

Um ambiente de desenvolvimento integrado (IDE) online fornecido pela Amazon AWS. Ferramentas para mais de 40 linguagens de programação como Node.js, JavaScript, Python, PHP, Ruby, Go, C++, etc. já vêm empacotadas.

- [Visual Studio Code for the Web](https://vscode.dev/)

Um ambiente de desenvolvimento online fornecido pela Microsoft. No entanto, linguagens que requerem compilação não podem ser executadas ou depuradas.

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

Um ambiente de execução online que suporta 24 linguagens principais como C, C++, Java, Ruby, Python, PHP, Perl, etc.

- [CodePen](https://codepen.io/)

Um ambiente de execução online para HTML, CSS e JavaScript.

- [codeanywhere](https://codeanywhere.com/)

Um IDE online. Permite compartilhamento de código e chat.
