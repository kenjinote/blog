## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

Google Colaboratory एक ऑनलाइन Python निष्पादन वातावरण है।

- GPU का उपयोग भी संभव है।
- Colab नोटबुक का उपयोग करके, आप एक ही दस्तावेज़ में निष्पादन योग्य कोड और रिच टेक्स्ट (चित्र, HTML, LaTeX, आदि सहित) लिख सकते हैं।

यह Jupyter Notebook पर आधारित है।

## अन्य

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

Amazon AWS द्वारा प्रदान किया गया एक ऑनलाइन एकीकृत विकास वातावरण। इसमें Node.js, JavaScript, Python, PHP, Ruby, Go, C++ जैसी 40 से अधिक प्रोग्रामिंग भाषाओं के लिए टूल पहले से पैक होते हैं।

- [Visual Studio Code for the Web](https://vscode.dev/)

Microsoft द्वारा प्रदान किया गया एक ऑनलाइन विकास वातावरण। हालाँकि, संकलन (compilation) की आवश्यकता वाली भाषाओं को निष्पादित या डीबग नहीं किया जा सकता है।

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

एक ऑनलाइन निष्पादन वातावरण जो C, C++, Java, Ruby, Python, PHP, Perl आदि जैसी 24 प्रमुख भाषाओं का समर्थन करता है।

- [CodePen](https://codepen.io/)

HTML, CSS और JavaScript के लिए एक ऑनलाइन निष्पादन वातावरण।

- [codeanywhere](https://codeanywhere.com/)

एक ऑनलाइन IDE। आपको कोड साझा करने और चैट करने की अनुमति देता है।
