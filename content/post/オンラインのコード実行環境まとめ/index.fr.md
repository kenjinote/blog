## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

Google Colaboratory est un environnement d'exécution Python disponible en ligne.

- L'utilisation de GPU est également possible.
- Avec les notebooks Colab, vous pouvez écrire du code exécutable et du texte enrichi (images, HTML, LaTeX, etc.) dans un seul document.

Il est basé sur Jupyter Notebook.

## Autres

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

Un environnement de développement intégré en ligne fourni par Amazon AWS. Des outils pour plus de 40 langages de programmation tels que Node.js, JavaScript, Python, PHP, Ruby, [Go](https://kenji.blog/fr/p/programming-languages-history-paradigm-evolution/), C++, etc. sont pré-emballés.

- [Visual Studio Code for the Web](https://vscode.dev/)

Un environnement de développement en ligne fourni par Microsoft. Cependant, les langages nécessitant une compilation ne peuvent pas être exécutés ou débogués.

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

Un environnement d'exécution en ligne prenant en charge 24 langages principaux tels que C, C++, [Java](https://kenji.blog/fr/p/programming-languages-history-paradigm-evolution/), Ruby, Python, PHP, Perl, etc.

- [CodePen](https://codepen.io/)

Un environnement d'exécution en ligne pour HTML, CSS et JavaScript.

- [codeanywhere](https://codeanywhere.com/)

Un IDE en ligne. Permet le partage de code et le chat.
