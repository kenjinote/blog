## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

Google Colaboratory es un entorno de ejecución de Python en línea.

- Permite el uso de GPU.
- Los cuadernos de Colab permiten combinar código ejecutable y texto enriquecido (incluyendo imágenes, HTML, LaTeX, etc.) en un solo documento.

Está basado en Jupyter Notebook.

## Otros

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

Entorno de desarrollo integrado en línea proporcionado por Amazon AWS. Viene preempaquetado con herramientas para más de 40 lenguajes de programación, como Node.js, JavaScript, Python, PHP, Ruby, Go y C++.

- [Visual Studio Code for the Web](https://vscode.dev/)

Entorno de desarrollo en línea proporcionado por Microsoft. Sin embargo, no se puede ejecutar ni depurar código en lenguajes que requieren compilación.

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

Entorno de ejecución en línea compatible con 24 lenguajes principales, como C, C++, Java, Ruby, Python, PHP y Perl.

- [CodePen](https://codepen.io/)

Entorno de ejecución en línea para HTML, CSS y JavaScript.

- [codeanywhere](https://codeanywhere.com/)

IDE en línea. Permite compartir código y chatear.
