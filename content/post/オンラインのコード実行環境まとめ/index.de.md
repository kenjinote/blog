## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

Google Colaboratory ist eine online verfügbare Python-Ausführungsumgebung.

- Die Nutzung von GPUs ist ebenfalls möglich.
- Mit Colab-Notebooks können Sie ausführbaren Code und Rich-Text (Bilder, HTML, LaTeX usw.) in einem einzigen Dokument schreiben.

Es basiert auf Jupyter Notebook.

## Sonstiges

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

Eine von Amazon AWS bereitgestellte integrierte Online-Entwicklungsumgebung. Werkzeuge für über 40 Programmiersprachen wie Node.js, JavaScript, Python, PHP, Ruby, Go, C++ usw. sind vorpaketiert.

- [Visual Studio Code for the Web](https://vscode.dev/)

Eine von Microsoft bereitgestellte Online-Entwicklungsumgebung. Sprachen, die kompiliert werden müssen, können jedoch weder ausgeführt noch debuggt werden.

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

Eine Online-Ausführungsumgebung, die 24 Hauptsprachen wie C, C++, Java, Ruby, Python, PHP, Perl usw. unterstützt.

- [CodePen](https://codepen.io/)

Eine Online-Ausführungsumgebung für HTML, CSS und JavaScript.

- [codeanywhere](https://codeanywhere.com/)

Eine Online-IDE. Ermöglicht Codefreigabe und Chat.
