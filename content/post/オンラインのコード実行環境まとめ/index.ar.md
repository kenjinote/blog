## Python

- [Google Colaboratory](https://colab.research.google.com/#create=true)

بيئة Google Colaboratory هي بيئة لتنفيذ Python يمكن تشغيلها عبر الإنترنت.

- يمكن أيضاً استخدام GPU.
- باستخدام دفاتر Colab، يمكنك كتابة كود قابل للتنفيذ ونص غني (مثل الصور و HTML و LaTeX وما إلى ذلك) في مستند واحد.

وهي مبنية على Jupyter Notebook.

## أخرى

- [AWS Cloud9](https://aws.amazon.com/jp/cloud9/)

بيئة تطوير متكاملة عبر الإنترنت تقدمها Amazon AWS. تأتي مع أدوات مجمعة مسبقاً لأكثر من 40 لغة برمجة مثل Node.js و JavaScript و Python و PHP و Ruby و Go و C++ وغيرها.

- [Visual Studio Code for the Web](https://vscode.dev/)

بيئة تطوير عبر الإنترنت تقدمها Microsoft. ومع ذلك، لا يمكن تنفيذ أو تصحيح اللغات التي تتطلب تجميعاً (compile).

- [paiza.IO](https://paiza.io/projects/CGAcQLfW-IOXYy8Dq2OHBw?locale=ja-jp)

بيئة تنفيذ عبر الإنترنت تدعم 24 لغة رئيسية مثل C و C++ و Java و Ruby و Python و PHP و Perl وغيرها.

- [CodePen](https://codepen.io/)

بيئة تنفيذ عبر الإنترنت لـ HTML و CSS و JavaScript.

- [codeanywhere](https://codeanywhere.com/)

بيئة تطوير متكاملة (IDE) عبر الإنترنت. يمكنك مشاركة الكود والدردشة.
