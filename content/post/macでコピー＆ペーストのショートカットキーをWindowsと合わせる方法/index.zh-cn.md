同时使用 Windows 和 Mac 时，复制、粘贴等快捷键使用的修饰键不同。在 macOS Ventura 及更新版本中，可以交换 Control 键与 Command 键的功能。

此更改会影响所选键盘上所有使用 Control 或 Command 的快捷键，不仅限于复制和粘贴。

## 设置步骤

1. 从 Apple 菜单打开“系统设置”。
2. 依次打开“键盘”>“键盘快捷键”>“修饰键”。
3. 如果出现键盘菜单，请选择要配置的键盘。
4. 将“Control (^) 键”设为“Command (⌘)”。
5. 将“Command (⌘) 键”设为“Control (^)”，然后点按“完成”。

要恢复原设置，请在同一页面点按“恢复默认”。详见 Apple 的[修饰键设置指南](https://support.apple.com/en-ie/guide/mac-help/mchlp1011/27/mac/27)。
