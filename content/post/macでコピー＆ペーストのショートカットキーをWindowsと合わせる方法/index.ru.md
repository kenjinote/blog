При переключении между Windows и Mac различаются модификаторы для сочетаний клавиш, например копирования и вставки. В macOS Ventura и новее можно поменять действия клавиш Control и Command местами.

Изменение затрагивает все сочетания с Control или Command на выбранной клавиатуре, а не только копирование и вставку.

## Порядок действий

1. Откройте **Системные настройки** в меню Apple.
2. Перейдите в раздел **Клавиатура** > **Сочетания клавиш** > **Модификаторы**.
3. Если появится меню выбора клавиатуры, выберите нужную.
4. Назначьте **Control (^)** действие **Command (⌘)**.
5. Назначьте **Command (⌘)** действие **Control (^)** и нажмите **Готово**.

Чтобы отменить изменение, нажмите **Восстановить значения по умолчанию** на том же экране. См. [руководство Apple по клавишам-модификаторам](https://support.apple.com/en-ie/guide/mac-help/mchlp1011/27/mac/27).
