# 소개

Windows와 Mac을 번갈아 사용할 경우, 키보드 단축키로 자주 사용하는 복사, 붙여넣기, 실행 취소 등의 키가 다르기 때문에,
이를 맞추는 방법을 소개합니다.

# 설정 방법 (macOS Ventura)

1. 시스템 설정을 엽니다.
2. 키보드를 선택합니다.
3. 키보드 단축키를 선택합니다.
4. 보조 키를 선택합니다.
5. Control(^) 키를 「⌘ Command」에 할당합니다.
6. Command(⌘) 키를 「^ Control」에 할당합니다.
7. 완료를 클릭합니다.
