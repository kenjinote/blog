# 簡介

當在 Windows 和 mac 之間切換使用時，常用的複製、貼上和復原等快捷鍵有所不同，因此我將介紹如何將它們保持一致。

# 設定方法（macOS Ventura）

1. 開啟「系統設定」
2. 選擇「鍵盤」
3. 選擇「鍵盤快速鍵」
4. 選擇「變更鍵」
5. 將 Control(^) 鍵指派為「⌘ Command」
6. 將 Command(⌘) 鍵指派為「^ Control」
7. 點擊「完成」
