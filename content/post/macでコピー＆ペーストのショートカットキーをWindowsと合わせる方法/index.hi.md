# परिचय

जब आप विंडोज़ और मैक के बीच स्विच करते हैं, तो अक्सर उपयोग किए जाने वाले कीबोर्ड शॉर्टकट जैसे कॉपी, पेस्ट और अनडू अलग-अलग होते हैं, इसलिए मैं उन्हें समान करने का तरीका बताऊंगा।

# सेटअप विधि (macOS Ventura)

1. सिस्टम सेटिंग्स खोलें
2. कीबोर्ड चुनें
3. कीबोर्ड शॉर्टकट चुनें
4. मॉडिफायर कीज़ चुनें
5. Control(^) की को "⌘ Command" पर सेट करें
6. Command(⌘) की को "^ Control" पर सेट करें
7. डन पर क्लिक करें
