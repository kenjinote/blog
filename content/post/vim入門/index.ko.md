# Vim 입문

## 다운로드와 설치

[https://www.vim.org/download.php](https://www.vim.org/download.php)

위의 사이트에서, 설치하고 싶은 OS에 맞춰 모듈을 다운로드 및 설치합니다.

Windows의 경우 `gvim_X.X.X_x64_signed.exe`를 선택하면 좋을 것입니다.

##  시작 방법

Windows의 경우 환경 변수에 `vim.exe`가 있는 폴더를 Path에 등록해 둘 필요가 있습니다.

시작 방법

```
vim
```

파일명을 지정해서 시작할 경우

```
vim filename.txt
```

## 종료 방법

종료할 경우 `:`(콜론)을 입력 후, `q`를 입력하고, Enter를 입력
```
:q
```

파일을 업데이트했을 경우 `마지막 변경이 저장되지 않았습니다 (!를 추가하여 변경 사항 폐기)`라고 표시됩니다.
내용을 폐기하고 강제적으로 종료할 수 있습니다.
```
:q!
```

파일을 쓰고 종료할 경우
```
:wq
```

다음과 같이 입력해도 같은 의미입니다.
```
:x
```

또한, `Shift`를 누른 채 `z`를 2번 누르는 것으로도 종료할 수 있습니다. (`:wq`와 같음)

## 모드

Vim에는 `명령 모드`와 `입력 모드`가 있습니다. Vim을 시작한 시점에는 `명령 모드`가 되며, `i` 키를 누르면 `입력 모드`로 전환됩니다.

`입력 모드`에서는 문자 그대로 입력이 가능해집니다. `입력 모드`에서 `명령 모드`로 전환하려면 `ESC` 키를 누릅니다.

이 입력 모드의 전환이 있는 것이 Vim의 특징입니다.

## 커서 이동과 스크롤

`명령 모드`일 때의 커서 이동과 스크롤에 대해 정리합니다.

| 키                                 | 설명                      |
|------------------------------------|-------------------------|
| `h` (또는 `Ctrl`+`H`, `BackSpace`, `←`) | 왼쪽으로 이동                    |
| `j` (또는 `Ctrl`+`J`・`N`, `↓`)         | 아래로 이동                    |
| `k` (또는 `Ctrl`+`P`, `↑`)             | 위로 이동                    |
| `l` (또는 `Space`, `→`)               | 오른쪽으로 이동                    |
| `+` (또는 `Enter`)                   | 다음 줄의 첫 문자로 이동               |
| `-`                                | 이전 줄의 첫 문자로 이동               |
| `Ctrl`+`B` (또는 `PageUp`)            | 위쪽 방향으로 스크롤               |
| `Ctrl`+`F` (또는 `PageDown`)          | 아래쪽 방향으로 스크롤               |
| `Ctrl`+`U`                         | 위쪽 방향으로 반 스크롤              |
| `Ctrl`+`D`                         | 아래쪽 방향으로 반 스크롤              |
| `Ctrl`+`Y`                         | 위쪽 방향으로 1줄 스크롤             |
| `Ctrl`+`E`                         | 아래쪽 방향으로 1줄 스크롤             |
| `z` `Enter`                        | 커서가 있는 줄을 화면 상단으로 스크롤        |
| `z` `.`                            | 커서가 있는 줄을 화면 중앙으로 스크롤        |
| `z` `-`                            | 커서가 있는 줄을 화면 하단으로 스크롤        |
| `0` (또는 `\|`)                       | 커서를 줄의 맨 앞으로 이동              |
| `$`                                | 커서를 줄의 맨 뒤로 이동              |
| `^` (또는 `_`)                        | 커서를 줄의 맨 앞으로 (공백, Tab 제외) 이동 |
| `G` (또는 `:$`)                       | 커서를 마지막 줄로 이동             |
| `:줄 번호` `Enter`                     | 지정한 줄로 이동                  |

`숫자` 뒤에 위의 이동하는 키를 입력하면, 숫자만큼 여러 번 이동할 수 있습니다.
(예를 들어, `3j`를 입력하면 현재 커서 위치에서 아래로 3줄 이동합니다.)

## 기타 명령

| 키         | 설명                   |
|------------|----------------------|
| `Ctrl`+`L` | 화면을 다시 그림               |
| `Ctrl`+`G` | 파일 전체의 줄 수, 커서 위치 등을 표시 |
