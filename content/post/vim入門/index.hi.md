# vim परिचय

## डाउनलोड और इंस्टालेशन

[https://www.vim.org/download.php](https://www.vim.org/download.php)

उपरोक्त वेबसाइट से, अपने ऑपरेटिंग सिस्टम के अनुसार उपयुक्त मॉड्यूल डाउनलोड और इंस्टॉल करें।

Windows के लिए, `gvim_X.X.X_x64_signed.exe` चुनना एक अच्छा विकल्प होगा।

## शुरू करने का तरीका

Windows के मामले में, आपको Path पर्यावरण चर (Environment Variable) में उस फ़ोल्डर को पंजीकृत करना होगा जहाँ `vim.exe` स्थित है।

शुरू करने का तरीका:

```
vim
```

फ़ाइल का नाम निर्दिष्ट करके शुरू करना:

```
vim filename.txt
```

## बाहर निकलने (Exit) का तरीका

बाहर निकलने के लिए, `:` (कोलन) टाइप करें, फिर `q` टाइप करें, और Enter दबाएं।
```
:q
```

यदि आपने फ़ाइल में बदलाव किए हैं, तो यह `अंतिम परिवर्तन के बाद से सहेजा नहीं गया (बदलावों को छोड़ने के लिए ! जोड़ें)` प्रदर्शित करेगा।
आप परिवर्तनों को छोड़कर बलपूर्वक बाहर निकल सकते हैं।
```
:q!
```

फ़ाइल को सहेजने और बाहर निकलने के लिए:
```
:wq
```

नीचे दिए गए कमांड का अर्थ भी समान है:
```
:x
```

इसके अलावा, आप `Shift` को दबाए रखते हुए दो बार `z` दबाकर भी बाहर निकल सकते हैं। (यह :wq के समान है)

## मोड्स

vim में एक `कमांड मोड` (Command Mode) और एक `इन्सर्ट मोड` (Insert Mode) होता है। जब आप vim शुरू करते हैं, तो यह `कमांड मोड` में होता है, और `i` कुंजी दबाने पर यह `इन्सर्ट मोड` में चला जाता है।

`इन्सर्ट मोड` में, आप टेक्स्ट टाइप कर सकते हैं। `इन्सर्ट मोड` से वापस `कमांड मोड` में जाने के लिए, `ESC` कुंजी दबाएं।

यह मोड बदलना vim की एक प्रमुख विशेषता है।

## कर्सर मूवमेंट और स्क्रॉलिंग

यहाँ `कमांड मोड` के दौरान कर्सर मूवमेंट और स्क्रॉलिंग का सारांश दिया गया है।

| कुंजी                               | विवरण                      |
|------------------------------------|-------------------------|
| `h` (या `Ctrl`+`H`, `BackSpace`, `←`) | बाईं ओर जाएँ                    |
| `j` (या `Ctrl`+`J` / `N`, `↓`)         | नीचे जाएँ                    |
| `k` (या `Ctrl`+`P`, `↑`)             | ऊपर जाएँ                    |
| `l` (या `Space`, `→`)               | दाईं ओर जाएँ                    |
| `+` (या `Enter`)                   | अगली लाइन की शुरुआत में जाएँ               |
| `-`                                | पिछली लाइन की शुरुआत में जाएँ               |
| `Ctrl`+`B` (या `PageUp`)            | ऊपर की ओर स्क्रॉल करें (पेज)               |
| `Ctrl`+`F` (या `PageDown`)          | नीचे की ओर स्क्रॉल करें (पेज)               |
| `Ctrl`+`U`                         | ऊपर की ओर आधा स्क्रॉल करें              |
| `Ctrl`+`D`                         | नीचे की ओर आधा स्क्रॉल करें              |
| `Ctrl`+`Y`                         | ऊपर की ओर 1 लाइन स्क्रॉल करें             |
| `Ctrl`+`E`                         | नीचे की ओर 1 लाइन स्क्रॉल करें             |
| `z` `Enter`                        | कर्सर वाली लाइन को स्क्रीन के ऊपर स्क्रॉल करें        |
| `z` `.`                            | कर्सर वाली लाइन को स्क्रीन के मध्य में स्क्रॉल करें        |
| `z` `-`                            | कर्सर वाली लाइन को स्क्रीन के नीचे स्क्रॉल करें        |
| `0` (या `\|`)                       | कर्सर को लाइन की शुरुआत में ले जाएँ              |
| `$`                                | कर्सर को लाइन के अंत में ले जाएँ              |
| `^` (या `_`)                        | कर्सर को लाइन की शुरुआत में ले जाएँ (स्पेस, Tab को छोड़कर) |
| `G` (या `:$`)                       | कर्सर को अंतिम लाइन पर ले जाएँ             |
| `:लाइन_नंबर` `Enter`                     | निर्दिष्ट लाइन पर जाएँ                  |

उपर्युक्त मूवमेंट कुंजियों से पहले एक `नंबर` टाइप करके, आप उस संख्या के बराबर कई बार आगे बढ़ सकते हैं।
(उदाहरण के लिए, `3j` टाइप करने से आप वर्तमान कर्सर स्थान से 3 लाइनें नीचे चले जाएंगे।)

## अन्य कमांड

| कुंजी         | विवरण                   |
|------------|----------------------|
| `Ctrl`+`L` | स्क्रीन को फिर से ड्रा करें               |
