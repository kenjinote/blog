# Введение в Vim

## Загрузка и установка

[https://www.vim.org/download.php](https://www.vim.org/download.php)

Загрузите и установите модуль для вашей ОС с указанного выше сайта.

Для Windows, вероятно, лучше всего выбрать `gvim_X.X.X_x64_signed.exe`.

## Как запустить

В Windows необходимо зарегистрировать папку, содержащую `vim.exe`, в переменной среды Path.

Способ запуска

```
vim
```

Если вы хотите запустить, указав имя файла

```
vim filename.txt
```

## Как выйти

Чтобы выйти, введите `:` (двоеточие), затем введите `q` и нажмите Enter
```
:q
```

Если файл был обновлен, отобразится `Нет записи с момента последнего изменения (добавьте ! для игнорирования)`.
Вы можете отменить изменения и принудительно завершить работу.
```
:q!
```

Чтобы сохранить файл и выйти
```
:wq
```

Следующее означает то же самое.
```
:x
```

Вы также можете выйти, дважды нажав `z`, удерживая `Shift`. (То же, что и :wq)

## Режимы

Vim имеет `командный режим` и `режим ввода`. Когда вы запускаете vim, он переходит в `командный режим`, а при нажатии клавиши `i` вы переходите в `режим ввода`.

В `режиме ввода` вы можете печатать текст, как обычно. Чтобы перейти из `режима ввода` в `командный режим`, нажмите клавишу `ESC`.

Особенностью vim является наличие такого переключения режимов.

## Перемещение курсора и прокрутка

Ниже приведен список команд перемещения курсора и прокрутки в `командном режиме`.

| Клавиша                            | Описание                  |
|------------------------------------|-------------------------|
| `h` (или `Ctrl`+`H`, `BackSpace`, `←`) | Перемещение влево       |
| `j` (или `Ctrl`+`J`, `N`, `↓`)         | Перемещение вниз        |
| `k` (или `Ctrl`+`P`, `↑`)             | Перемещение вверх       |
| `l` (или `Space`, `→`)               | Перемещение вправо      |
| `+` (или `Enter`)                   | Перемещение в начало следующей строки |
| `-`                                | Перемещение в начало предыдущей строки |
| `Ctrl`+`B` (или `PageUp`)            | Прокрутка вверх         |
| `Ctrl`+`F` (или `PageDown`)          | Прокрутка вниз          |
| `Ctrl`+`U`                         | Прокрутка вверх на пол-экрана |
| `Ctrl`+`D`                         | Прокрутка вниз на пол-экрана |
| `Ctrl`+`Y`                         | Прокрутка вверх на 1 строку  |
| `Ctrl`+`E`                         | Прокрутка вниз на 1 строку   |
| `z` `Enter`                        | Прокрутка строки с курсором к верхнему краю экрана |
| `z` `.`                            | Прокрутка строки с курсором к центру экрана |
| `z` `-`                            | Прокрутка строки с курсором к нижнему краю экрана |
| `0` (или `\|`)                       | Перемещение курсора в начало строки |
| `$`                                | Перемещение курсора в конец строки |
| `^` (или `_`)                        | Перемещение курсора в начало строки (без учета пробелов, Tab) |
| `G` (или `:$`)                       | Перемещение курсора на последнюю строку |
| `:номер строки` `Enter`            | Переход на указанную строку |

Если после `числа` вы введете вышеуказанные клавиши перемещения, вы сможете переместиться столько раз, сколько указано в числе.
(Например, ввод `3j` переместит вас на 3 строки вниз от текущего положения курсора.)

## Другие команды

| Клавиша      | Описание                 |
|------------|----------------------|
| `Ctrl`+`L` | Перерисовать экран       |
| `Ctrl`+`G` | Отобразить количество строк всего файла, позицию курсора и т. д. |
