I would like to introduce "Tab Auto Refresh", an Edge browser extension that automatically refreshes web pages.

## Before you install

The interface and permissions may change. These screenshots date from 2024, so check the current listing and confirmation prompt for the publisher and requested permissions. Limit site access to the sites you need or “On click.” Avoid auto-refresh on pages where repeated loads could have unwanted effects, such as while submitting a form.

## Installing Tab Auto Refresh

[Tab Auto Refresh](https://microsoftedge.microsoft.com/addons/detail/%E3%82%BF%E3%83%96%E3%81%AE%E8%87%AA%E5%8B%95%E6%9B%B4%E6%96%B0/bicjibdndeejemialpbohjpiimehbapb)

On the listing, click `Get`. Review the requested permissions in the prompt before clicking `Add extension`.

![img_2.png](img_2.webp)

Click `Add extension`.

![img_3.png](img_3.webp)

## How to Use

Once the installation is complete, an icon will be added to the top right of Edge.

![img_4.png](img_4.webp)

Open the web page you want to auto-refresh and click the icon to start auto-refreshing.

![img_1.png](img_1.webp)

The part in the green frame is the auto-refresh interval. Please select the timing to auto-refresh.

To stop auto-refreshing, click the icon and then click `Stop reloading this tab`.

![img_5.png](img_5.webp)
