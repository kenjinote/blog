## 설치 전 확인 사항

화면과 권한은 변경될 수 있습니다. 스크린샷은 2024년 기준이므로 현재 스토어 설명과 확인 창에서 게시자 및 요청 권한을 확인하세요. 사이트 접근을 필요한 사이트 또는 “클릭할 때”로 제한하세요. 양식 제출 중처럼 반복 로드가 문제를 일으킬 수 있는 페이지에서는 자동 새로 고침을 사용하지 마세요.

## 탭 자동 새로고침 설치

[탭 자동 새로고침](https://microsoftedge.microsoft.com/addons/detail/%E3%82%BF%E3%83%96%E3%81%AE%E8%87%AA%E5%8B%95%E6%9B%B4%E6%96%B0/bicjibdndeejemialpbohjpiimehbapb)

스토어 페이지에서 `Get`(또는 해당 언어의 버튼)을 클릭합니다. 확인 창에서 요청 권한을 확인한 뒤 `Add extension`을 선택하세요.

![img_2.png](img_2.webp)

`확장 기능 추가`를 클릭합니다.

![img_3.png](img_3.webp)

## 사용법

설치가 완료되면 Edge의 우측 상단에 아이콘이 추가됩니다.

![img_4.png](img_4.webp)

자동으로 새로고침할 웹 페이지를 열고 아이콘을 클릭하면 자동 새로고침이 시작됩니다.

![img_1.png](img_1.webp)

녹색 테두리 부분이 자동 새로고침되는 간격입니다. 자동 새로고침할 타이밍을 선택해 주세요.

자동 새로고침을 중지하려면 아이콘을 클릭하고 `Stop reloading this tab`을 클릭합니다.

![img_5.png](img_5.webp)
