Saya akan memperkenalkan ekstensi browser Edge "Pembaruan Tab Otomatis" yang memperbarui halaman web secara otomatis.

## Instalasi Pembaruan Tab Otomatis

[Pembaruan Tab Otomatis](https://microsoftedge.microsoft.com/addons/detail/%E3%82%BF%E3%83%96%E3%81%AE%E8%87%AA%E5%8B%95%E6%9B%B4%E6%96%B0/bicjibdndeejemialpbohjpiimehbapb)

Akses situs di atas dan klik `Instal`.

![img_2.png](img_2.png)

Klik `Tambahkan ekstensi`.

![img_3.png](img_3.png)

## Cara Menggunakan

Setelah instalasi selesai, sebuah ikon akan ditambahkan ke kanan atas Edge.

![img_4.png](img_4.png)

Buka halaman web yang ingin Anda perbarui secara otomatis dan klik ikon untuk memulai pembaruan otomatis.

![img_1.png](img_1.png)

Bagian yang dibingkai hijau adalah interval pembaruan otomatis. Silakan pilih waktu untuk memperbarui secara otomatis.

Untuk menghentikan pembaruan otomatis, klik ikon lalu klik `Stop reloading this tab`.

![img_5.png](img_5.png)
