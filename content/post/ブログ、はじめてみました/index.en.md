Hello everyone.
Just on a whim, I decided to start a blog.

I don't really have a grand purpose like "I want to broadcast this!",
but I thought it would be nice to have a place where I can just write down things about technology, daily life, or whatever comes to mind.

I'm not going to try too hard, and I plan to use it like a notepad.

---

## Made with Hugo

This blog is made with a static site generator called "Hugo".
I found a nice theme, so I decided to use it on a whim.
(It's a secret that it took me about 2 hours to choose a theme)

I'll casually write down things about code or tools I'm interested in as memos.
