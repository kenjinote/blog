## Saya mulai menulis blog

![](https://user-images.githubusercontent.com/2605401/187252583-63ef83f4-99c1-4eaf-a5b8-3b5ac1439860.gif)
Sesuatu seperti kembang api, kodenya ada [di sini](https://github.com/kenjinote/Fireworks "Pergi ke kode")

Halo semuanya.
Saya memutuskan untuk mulai menulis blog tanpa alasan khusus.

Saya tidak punya tujuan besar seperti "Saya ingin mempublikasikan ini!",
hanya berpikir akan menyenangkan memiliki tempat di mana saya bisa menulis apa pun yang terlintas di pikiran, baik itu tentang teknologi maupun kehidupan sehari-hari.

Saya tidak akan terlalu serius dan akan menggunakannya seperti buku catatan.

---

## Dibuat menggunakan sesuatu yang disebut Hugo

Blog ini dibuat menggunakan generator situs statis yang disebut "Hugo".
Saya menemukan tema yang bagus, jadi saya memutuskan untuk mencobanya.
(Butuh sekitar 2 jam untuk memilih tema, tapi itu rahasia)

Saya juga berencana untuk membuat catatan tentang kode dan alat yang menarik bagi saya.

## Cerita Komeda di pagi hari

Ngomong-ngomong, pagi ini saya bangun agak pagi dan pergi ke kedai kopi Komeda.
Saya berangkat jam 8:30, berjalan sambil menghirup udara pagi.

Saya memesan paket sarapan A dengan mini shironoir dan cafe au lait.
Kalau tidak salah harganya sekitar 800 yen? (Saya tidak ingat)

Kafe di pagi hari sangat menyenangkan.
Jika saya punya waktu untuk bersantai sebelum bekerja, rasanya hari itu akan berjalan lancar.

---

Jadi, mulai sekarang saya akan menulis dengan santai.
Saya berencana mencampur topik teknis dan kehidupan sehari-hari.

Mohon dukungannya!
