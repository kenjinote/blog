Arduino Community Edition 是由社群維護的舊版 Arduino 擴充功能分支，並非 Microsoft 官方產品。

SQLTools 是可連線多種資料庫的社群擴充功能。請依資料庫選擇驅動程式，並確認發行者與存取權限。

GitHub Copilot for Azure 為 Copilot 加入 Azure 技能，並非通用的 Azure 管理擴充功能。

## 安裝前請確認

VS Code 擴充功能具有與 VS Code 相同的權限，可以讀寫檔案、發出網路要求並啟動外部程序。安裝前請查看發行者、擴充套件安裝的相依擴充功能、更新記錄、支援資訊及隱私條款。具有 AI 功能的擴充功能可能會將程式碼或提示傳送至外部服務。處理敏感工作時，請先查看服務的資料使用條款與組織政策。

## 總結

安裝更多擴充功能不一定能提高效率。請先確認用途、發行者、權限及維護情況，只安裝實際使用的項目。
