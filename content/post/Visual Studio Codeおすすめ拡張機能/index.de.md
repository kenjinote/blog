# VS-Code-Erweiterungen nach Aufgabe auswählen

Marketplace-Namen und Funktionen ändern sich; veraltete Namen, doppelte Funktionen und missverständliche Beschreibungen aus der Version von 2024 wurden aktualisiert. Jeder Eintrag führt zur Marketplace-Seite.

VS Code enthält bereits Funktionen wie grundlegende Git-Integration und JavaScript-/TypeScript-Debugging. Probiere zuerst die integrierten Funktionen aus und ergänze nur, was dir fehlt.

## Vor der Installation prüfen

VS-Code-Erweiterungen haben dieselben Berechtigungen wie VS Code. Sie können Dateien lesen und schreiben, Netzwerkanfragen senden und externe Prozesse starten. Prüfe vor der Installation den Herausgeber, Abhängigkeiten eines Erweiterungspakets, den Update-Verlauf, Support-Informationen und Datenschutzbedingungen. Erweiterungen mit KI-Funktionen können Code oder Prompts an externe Dienste senden. Prüfe bei sensiblen Projekten die Datennutzungsbedingungen des Dienstes und die Richtlinien deiner Organisation.

## Zusammenfassung

Mehr Erweiterungen bedeuten nicht automatisch mehr Produktivität. Prüfe Zweck, Herausgeber, Berechtigungen und Pflegezustand und installiere nur, was du verwendest.
