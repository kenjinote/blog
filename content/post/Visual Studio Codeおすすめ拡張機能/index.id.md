## Sebelum memasang

Ekstensi VS Code memiliki izin yang sama dengan VS Code. Ekstensi dapat membaca dan menulis file, membuat permintaan jaringan, serta menjalankan proses eksternal. Sebelum memasang, periksa penerbit, dependensi tambahan dari paket ekstensi, riwayat pembaruan, dukungan, dan ketentuan privasi. Ekstensi dengan fitur AI dapat mengirim kode atau prompt ke layanan eksternal. Untuk pekerjaan sensitif, periksa ketentuan penggunaan data layanan dan kebijakan organisasi Anda.

## Ringkasan

Memasang lebih banyak ekstensi tidak otomatis meningkatkan produktivitas. Periksa tujuan, penerbit, izin, dan pemeliharaan, lalu pasang hanya yang Anda gunakan.
