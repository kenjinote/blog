# Choose VS Code extensions by task

Install only the extensions you need. This guide groups representative options by task. Marketplace names and capabilities change over time; we have updated obsolete names, overlapping entries, and misleading descriptions from the 2024 version and linked each item to its Marketplace page.

VS Code already includes features such as basic Git integration and JavaScript/TypeScript debugging. Try built-in features first, then add extensions for capabilities you need.

Arduino Community Edition is a community-maintained fork of the former Arduino extension, not an official Microsoft product.

SQLTools is a community extension that connects to several database systems. Choose a driver for your database and review its publisher and access requirements.

GitHub Copilot for Azure adds Azure skills for Copilot; it is not a general Azure management extension.

## Before you install

VS Code extensions run with the same permissions as VS Code. They can read and write files, make network requests, and launch external processes. Before installing, review the publisher, dependencies added by an extension pack, update history, support information, and privacy terms. Extensions with AI features may send code or prompts to an external service. For sensitive work, check the service’s data-use terms and your organization’s policy.

## Summary

Adding more extensions does not automatically improve productivity. Check the purpose, publisher, required access, and maintenance status, and install only what you use.
