# 關於獲得 Microsoft MVP 獎項 (2023-2024)

很高興與大家分享，我榮獲了 Microsoft MVP (2023-2024) 獎項。
這是自 2017 年以來連續第 7 年獲得此殊榮。

獲獎的類別是 **Developer Technologies** 。

回顧過去的活動，我主要參與了以下事項：

- 在 [GitHub](https://github.com/kenjinote) 上公開程式碼
- 在部落格及 [社群媒體 (如 Twitter 等)](https://twitter.com/kenjinote) 上分享技術資訊
- 在 [MSDN 論壇](https://social.msdn.microsoft.com/Forums/ja-JP/home) 上發文解答
- 提供對微軟產品的反饋

未來，我希望能繼續撰寫更好的文章，並持續分享有用的資訊。

感謝大家一直以來的支持。
