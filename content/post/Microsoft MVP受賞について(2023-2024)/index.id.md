# Tentang Penghargaan Microsoft MVP (2023-2024)

Artikel ini diterbitkan pada Juli 2023 dan mencatat penghargaan 2023-2024 serta kegiatan saya pada saat itu.

Baru-baru ini, saya telah menerima penghargaan Microsoft MVP (2023-2024).
Ini adalah tahun ke-7 berturut-turut sejak 2017 saya menerima penghargaan ini.

Kategori penghargaan yang saya terima adalah **Developer Technologies** .

Melihat kembali kegiatan saya sejauh ini, saya telah melakukan kegiatan berikut:

- Mempublikasikan kode di [GitHub](https://github.com/kenjinote)
- Berbagi informasi teknis di blog dan [SNS (seperti X (sebelumnya Twitter))](https://x.com/kenjinote)
- Memposting di [Forum MSDN (kini hanya-baca)](https://learn.microsoft.com/en-us/teamblog/msdn-technet-migration)
- Memberikan umpan balik untuk produk Microsoft

Ke depannya, saya ingin terus menulis artikel yang lebih baik dan berbagi informasi.

Terima kasih banyak atas dukungan Anda.

Lihat [ringkasan resmi Microsoft](https://mvp.microsoft.com/mvpintro/) untuk informasi program MVP saat ini.
