# Introducción

Aquí se explica cómo cambiar de aplicación en Mac al estilo de Windows (Alt+Tab).

Como es difícil lograrlo cambiando la configuración estándar, este método consiste en instalar una aplicación.

# Imagen de funcionamiento
![animation.gif](animation.gif)

# Método de configuración (macOS Ventura)

1. Abrir [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app)
2. Hacer clic en `Download the latest release`
3. Abrir la aplicación descargada
4. Seguir los pasos para instalarla

Con esto, el cambio de aplicaciones se podrá hacer con Alt+Tab igual que en Windows.
