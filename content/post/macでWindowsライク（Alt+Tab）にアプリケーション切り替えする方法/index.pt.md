# Introdução

Aqui mostrarei como alternar aplicativos no Mac de forma semelhante ao Windows (Alt+Tab).

Como é difícil conseguir isso alterando as configurações padrão, este método envolve a instalação de um aplicativo.

# Imagem de demonstração
![animation.gif](animation.gif)

# Método de configuração (macOS Ventura)

1. Abra [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app)
2. Clique em `Download the latest release`
3. Abra o aplicativo baixado
4. Siga as instruções para instalá-lo

Agora, você poderá alternar entre aplicativos usando Alt+Tab, assim como no Windows.
