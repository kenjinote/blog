# परिचय

यहाँ मैं बताऊंगा कि Mac पर Windows की तरह (Alt+Tab) एप्लिकेशन कैसे स्विच करें।

चूँकि डिफ़ॉल्ट सेटिंग्स को बदलकर इसे प्राप्त करना मुश्किल है, इस विधि में एक एप्लिकेशन इंस्टॉल करना शामिल है।

# डेमो छवि
![animation.gif](animation.gif)

# सेटअप विधि (macOS Ventura)

1. [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app) खोलें
2. `Download the latest release` पर क्लिक करें
3. डाउनलोड किया गया एप्लिकेशन खोलें
4. इसे इंस्टॉल करने के लिए निर्देशों का पालन करें

अब, आप Windows की तरह ही Alt+Tab का उपयोग करके एप्लिकेशन स्विच कर पाएंगे।
