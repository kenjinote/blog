# 簡介

這裡將介紹如何在 Mac 上像 Windows 一樣（Alt+Tab）切換應用程式。

因為透過更改預設設定很難實現，所以這個方法需要安裝應用程式。

![animation.gif](animation.gif)

# 設定方法 (macOS Ventura)

1. 打開 [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app)
2. 點擊 `Download the latest release`
3. 打開下載的應用程式
4. 按照步驟進行安裝

這樣，你就可以像在 Windows 上一樣使用 Alt+Tab 切換應用程式了。
