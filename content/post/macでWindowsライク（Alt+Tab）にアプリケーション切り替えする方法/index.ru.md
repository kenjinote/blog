## Встроенное переключение и AltTab

В macOS уже есть `Command-Tab` для переключения приложений и `Command-` (гравис) для окон текущего приложения. Чтобы выбирать отдельные окна, как в Windows, скачайте AltTab с [официального сайта](https://alt-tab.app/). По умолчанию используется `Option-Tab`; назначение `Command-Tab` заменит встроенное сочетание macOS для приложений.

Для переключения окон AltTab нужен доступ к Универсальному доступу. Разрешение на запись экрана включает миниатюры; без него приложение работает без предпросмотра. Основная функция бесплатна, Pro-функции оплачиваются отдельно. До выдачи разрешений прочитайте [FAQ](https://alt-tab.app/faq) и [политику конфиденциальности](https://alt-tab.app/privacy).
