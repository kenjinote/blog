# Введение

Я покажу вам, как переключать приложения на Mac подобно Windows (Alt+Tab).

Поскольку этого сложно достичь изменением стандартных настроек, этот метод включает установку приложения.

# Как настроить (macOS Ventura)

1. Откройте [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app)
2. Нажмите `Download the latest release`
3. Откройте загруженное приложение
4. Следуйте инструкциям по установке

Теперь вы сможете переключать приложения с помощью Alt+Tab, как в Windows.
