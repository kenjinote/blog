# Pengantar

Saya akan menunjukkan cara beralih aplikasi di Mac seperti Windows (Alt+Tab).

Karena sulit untuk mencapai ini dengan mengubah pengaturan standar, metode ini melibatkan pemasangan aplikasi.

# Demonstrasi
![animation.gif](animation.gif)

# Cara mengatur (macOS Ventura)

1. Buka [https://alt-tab-macos.netlify.app](https://alt-tab-macos.netlify.app)
2. Klik `Download the latest release`
3. Buka aplikasi yang diunduh
4. Ikuti instruksi untuk menginstal

Sekarang Anda akan dapat beralih aplikasi dengan Alt+Tab seperti di Windows.

Selesai
