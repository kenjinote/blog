## Perpindahan bawaan dan AltTab

macOS sudah memiliki `Command-Tab` untuk berpindah aplikasi dan `Command-` (grave accent) untuk berpindah jendela dalam aplikasi aktif. Untuk memilih tiap jendela seperti di Windows, unduh AltTab dari [situs resminya](https://alt-tab.app/). Pintasan bawaan adalah `Option-Tab`; mengubahnya ke `Command-Tab` akan menggantikan pintasan perpindahan aplikasi bawaan macOS.

AltTab memerlukan izin Aksesibilitas untuk berpindah jendela. Izin Perekaman Layar mengaktifkan thumbnail; tanpa izin itu aplikasi tetap berfungsi tanpa pratinjau. Fitur inti gratis dan fitur Pro berbayar terpisah. Baca [FAQ](https://alt-tab.app/faq) dan [kebijakan privasi](https://alt-tab.app/privacy) sebelum memberikan izin.
