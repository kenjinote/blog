# कंप्यूटर का बुनियादी ज्ञान

यह पृष्ठ समझाता है कि कंप्यूटर क्या है।

## कंप्यूटर की परिभाषा
कंप्यूटर एक मशीन है जिसमें निम्नलिखित 5 उपकरण होते हैं:

1. इनपुट डिवाइस
2. आउटपुट डिवाइस
3. स्टोरेज डिवाइस
4. कंट्रोल यूनिट
5. अरिथमेटिक लॉजिक यूनिट

संक्षेप में, कंप्यूटर एक ऐसी मशीन है जो दिए गए `इनपुट` के लिए विशिष्ट `प्रोसेसिंग` करती है और परिणाम को `आउटपुट` के रूप में देती है।
यह `इनपुट` किए गए डेटा को `स्टोर` कर सकता है, `ऑपरेशन` कर सकता है और `आउटपुट` दे सकता है। `कंट्रोल` का कार्य उपरोक्त 4 उपकरणों को नियंत्रित करना है।

## कंप्यूटर चलाने के लिए क्या चाहिए
कंप्यूटर चलाने के लिए उपकरणों (हार्डवेयर) के अलावा प्रोग्राम (सॉफ्टवेयर) की भी आवश्यकता होती है।

प्रोग्राम में, हम कंप्यूटर को निर्देश देते हैं कि उसे क्या प्रोसेसिंग करनी है। प्रोग्राम उस प्रारूप में लिखे जाते हैं जिसे कंप्यूटर समझ सके।

प्रोग्राम का एक उदाहरण नीचे दिया गया है:
1 से इनपुट किए गए पूर्णांक तक का योग निकालने का प्रोग्राम
```
#include <iostream>
using namespace std;

int main() {
    // आवश्यक मेमोरी स्पेस का आवंटन
    int n, sum = 0;
    
    // आउटपुट
    cout << "कृपया एक पूर्णांक दर्ज करें: ";
    
    // इनपुट 
    cin >> n;
    
    // ऑपरेशन
    for (int i = 1; i <= n; i++) { // ऑपरेशन
        sum += i;
    }
    
    // आउटपुट
    cout << "1 से " << n << " तक का योग " << sum << " है।" << endl;
    
    // समाप्त
    return 0;
}
```

प्रोग्राम को कंपाइलर द्वारा मशीन कोड में परिवर्तित किया जाता है, जिससे यह ऐसे प्रारूप में बदल जाता है जिसे कंप्यूटर निष्पादित कर सके।
