# 電腦的基礎知識

本頁將說明什麼是電腦。

## 電腦的定義
電腦是一台擁有以下五種單元的機器：

1. 輸入單元
2. 輸出單元
3. 記憶單元
4. 控制單元
5. 算術邏輯單元

簡而言之，對某個 `輸入` 進行特定的 `處理`，並將結果 `輸出` 的機器就是電腦。
它可以 `記憶` 所 `輸入` 的資料，進行 `運算`，並進行 `輸出`。 `控制` 負責控制上述四種單元。

## 運行電腦所需的事物
要運行電腦，除了設備（硬體）之外，還需要程式（軟體）。

在程式中，我們指示電腦要執行什麼樣的處理。程式是以電腦能夠理解的格式撰寫的。

程式的範例如下：
一個計算從 1 到輸入整數之總和的程式
```
#include <iostream>
using namespace std;

int main() {
    // 配置所需的記憶體空間
    int n, sum = 0;
    
    // 輸出
    cout << "請輸入一個整數： ";
    
    // 輸入 
    cin >> n;
    
    // 運算
    for (int i = 1; i <= n; i++) { // 運算
        sum += i;
    }
    
    // 輸出
    cout << "從 1 到 " << n << " 的總和是 " << sum << "。" << endl;
    
    // 結束
    return 0;
}
```

程式會透過編譯器轉換成機器碼，並轉換為電腦可以執行的格式。
