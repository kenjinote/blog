# 计算机基础知识

本页面介绍什么是计算机。

## 计算机的定义
计算机是拥有以下5种设备的机器。

1. 输入设备
2. 输出设备
3. 存储设备
4. 控制设备
5. 运算设备

简单来说，计算机就是对特定的`输入`进行特定的`处理`，并将结果`输出`的机器。
它可以将`输入`的数据进行`存储`、`运算`和`输出`。`控制`则起到控制上述4种设备的作用。

## 运行计算机所需的内容
要使计算机运行，除了设备（硬件）之外，还需要程序（软件）。

程序用于指示计算机执行什么样的处理。程序以计算机能够理解的格式编写。

程序的示例如下。
求从1到输入的整数之和的程序
```cpp
#include <iostream>
using namespace std;

int main() {
    // 确保所需的存储空间
    int n, sum = 0;
    
    // 输出
    cout << "请输入整数: ";
    
    // 输入 
    cin >> n;
    
    // 运算
    for (int i = 1; i <= n; i++) { // 运算
        sum += i;
    }
    
    // 输出
    cout << "1到" << n << "的合计是" << sum << "。" << endl;
    
    // 结束
    return 0;
}
```

程序会由编译器转换为机器语言，转换成计算机能够执行的格式。
