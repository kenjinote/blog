# Базовые знания о компьютерах

На этой странице объясняется, что такое компьютер.

## Определение компьютера
Компьютер - это машина, состоящая из следующих пяти устройств.

1. Устройство ввода
2. Устройство вывода
3. Устройство хранения
4. Устройство управления
5. Арифметическое устройство

Грубо говоря, компьютер - это машина, которая принимает определенный `ввод`, выполняет определенную `обработку` и `выводит` результат.
Он может `сохранять` введенные данные, `вычислять` и `выводить` их. Устройство `управления` играет роль в управлении четырьмя вышеупомянутыми устройствами.

## Что нужно для работы компьютера
Для работы компьютера, помимо оборудования (аппаратного обеспечения), необходимы программы (программное обеспечение).

Программы указывают компьютеру, какую обработку выполнять. Программы пишутся в формате, который может понять компьютер.

Пример программы:
Программа, которая вычисляет сумму целых чисел от 1 до введенного числа
```cpp
#include <iostream>
using namespace std;

int main() {
    // Выделение необходимой памяти
    int n, sum = 0;
    
    // Вывод
    cout << "Введите целое число: ";
    
    // Ввод
    cin >> n;
    
    // Вычисление
    for (int i = 1; i <= n; i++) { // Вычисление
        sum += i;
    }
    
    // Вывод
    cout << "Сумма от 1 до " << n << " равна " << sum << "." << endl;
    
    // Завершение
    return 0;
}
```

Программы преобразуются в машинный код компилятором, превращаясь в формат, который может выполнить компьютер.
