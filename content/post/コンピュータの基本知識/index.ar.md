# المعرفة الأساسية بالكمبيوتر

تشرح هذه الصفحة ما هو الكمبيوتر.

## تعريف الكمبيوتر
الكمبيوتر هو آلة تحتوي على الأجهزة الخمسة التالية.

1. جهاز الإدخال
2. جهاز الإخراج
3. جهاز التخزين
4. جهاز التحكم
5. وحدة الحساب

بشكل عام، الكمبيوتر هو آلة تأخذ `إدخالًا` معينًا، وتقوم بإجراء `معالجة` محددة، ثم `تخرج` النتيجة.
يمكنه `تخزين` البيانات المدخلة، وإجراء `العمليات الحسابية` عليها، ثم `إخراجها`. يلعب جهاز `التحكم` دورًا في التحكم في الأجهزة الأربعة المذكورة أعلاه.

## ما تحتاجه لتشغيل الكمبيوتر
لتشغيل الكمبيوتر، تحتاج إلى برامج بالإضافة إلى الأجهزة.

تخبر البرامج الكمبيوتر بالمعالجة التي يجب إجراؤها. تتم كتابة البرامج بتنسيق يمكن للكمبيوتر فهمه.

كمثال على برنامج، يوجد ما يلي:
برنامج يحسب مجموع الأعداد الصحيحة من 1 إلى الرقم المدخل
```cpp
#include <iostream>
using namespace std;

int main() {
    // تأمين مساحة التخزين اللازمة
    int n, sum = 0;
    
    // إخراج
    cout << "أدخل عددًا صحيحًا: ";
    
    // إدخال
    cin >> n;
    
    // عملية حسابية
    for (int i = 1; i <= n; i++) { // عملية حسابية
        sum += i;
    }
    
    // إخراج
    cout << "مجموع الأعداد من 1 إلى " << n << " هو " << sum << "." << endl;
    
    // إنهاء
    return 0;
}
```

يتم تحويل البرامج إلى لغة الآلة بواسطة مترجم، ثم تحويلها إلى تنسيق يمكن للكمبيوتر تنفيذه.
