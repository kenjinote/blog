# GitHub Sponsors로 개발 활동 후원하기

GitHub Sponsors를 통해 개인 개발자 kenjinote를 후원할 수 있습니다. 후원은 자발적입니다.

## 후원금 사용 계획

후원금은 도구의 개발과 유지 관리 및 프로젝트 관련 비용에 보탬이 될 예정입니다. 코드 서명 인증서 취득은 장래 목표이며, 특정 기능이나 제공 시기를 약속하는 것은 아닙니다.

## 후원 방법

현재 후원 금액과 표시된 혜택은 [GitHub Sponsors 프로필](https://github.com/sponsors/kenjinote)에서 확인할 수 있습니다. 결제, 청구 및 세금 처리는 계정·지역·GitHub의 현재 약관에 따라 달라집니다. 후원 전에 [공식 수수료 및 세금 안내](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes)를 확인하세요.

[GitHub Sponsors에서 kenjinote 후원하기](https://github.com/sponsors/kenjinote)

제 개발 활동을 후원해 주실지 검토해 주셔서 감사합니다.
