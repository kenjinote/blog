# 透過 GitHub Sponsors 支持開發

您可以透過 GitHub Sponsors 支持獨立開發者 kenjinote。贊助完全出於自願。

## 贊助款用途

贊助款預計用於支持工具開發、維護及相關專案支出。取得程式碼簽章憑證是未來目標，不代表承諾提供特定功能或交付日期。

## 贊助方式

目前可選金額與列出的回饋請參閱 [GitHub Sponsors 個人資料](https://github.com/sponsors/kenjinote)。付款、帳單與稅務處理會因帳戶、地區及 GitHub 現行條款而異；贊助前請閱讀[官方費用與稅務說明](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes)。
