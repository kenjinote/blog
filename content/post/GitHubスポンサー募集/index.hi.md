# GitHub Sponsors के माध्यम से विकास का समर्थन

आप GitHub Sponsors के ज़रिये स्वतंत्र डेवलपर kenjinote का समर्थन कर सकते हैं। यह समर्थन स्वैच्छिक है।

## समर्थन राशि का उपयोग

समर्थन राशि का उद्देश्य टूल के विकास और रखरखाव तथा परियोजना से जुड़े खर्चों में मदद करना है। कोड-साइनिंग प्रमाणपत्र प्राप्त करना भविष्य का लक्ष्य है, कोई वादा किया गया फ़ीचर या समय-सीमा नहीं।

## समर्थन कैसे करें

उपलब्ध राशियाँ और सूचीबद्ध लाभ [GitHub Sponsors प्रोफ़ाइल](https://github.com/sponsors/kenjinote) पर देखें। भुगतान, बिलिंग और कर संबंधी व्यवहार खाते, क्षेत्र और GitHub की मौजूदा शर्तों पर निर्भर करते हैं; समर्थन से पहले [आधिकारिक शुल्क और कर मार्गदर्शन](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes) पढ़ें।

[GitHub Sponsors पर kenjinote का समर्थन करें](https://github.com/sponsors/kenjinote)

मेरे काम का समर्थन करने पर विचार करने के लिए धन्यवाद।
