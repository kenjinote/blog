# 通过 GitHub Sponsors 支持开发

您可以通过 GitHub Sponsors 支持独立开发者 kenjinote。赞助完全自愿。

## 赞助款用途

赞助款计划用于支持工具的开发、维护及相关项目支出。获取代码签名证书是未来目标，不代表承诺提供某项功能或交付日期。

## 如何赞助

当前可选金额及列出的权益请查看 [GitHub Sponsors 个人资料](https://github.com/sponsors/kenjinote)。付款、账单和税务处理会因账号、地区及 GitHub 当前条款而异；赞助前请阅读[官方费用与税务说明](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes)。

[在 GitHub Sponsors 上赞助 kenjinote](https://github.com/sponsors/kenjinote)

感谢您考虑支持我的开发工作。
