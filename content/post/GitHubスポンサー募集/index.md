# GitHub Sponsorsで開発活動を支援する

GitHub Sponsorsを通じて、個人開発者kenjinoteの活動をご支援いただけます。支援は任意です。

## 支援の使い道

ご支援はツールの開発・保守や関連する活動費に活用する予定です。コード署名証明書の取得も将来の目標ですが、特定の機能や時期を約束するものではありません。

## 支援方法

支援プランや金額、特典の有無は[GitHub Sponsorsプロフィール](https://github.com/sponsors/kenjinote)で確認できます。決済、請求、税務上の扱いはアカウントや地域、GitHubの現行条件によって異なるため、支援前に[公式の料金・税務案内](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes)をご確認ください。
