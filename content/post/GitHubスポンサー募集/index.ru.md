# Поддержка разработки через GitHub Sponsors

Поддержать независимого разработчика kenjinote можно через GitHub Sponsors. Поддержка добровольная.

## Использование средств

Средства планируется направлять на разработку и сопровождение инструментов, а также связанные расходы проекта. Получение сертификатов подписи кода — будущая цель, а не обещанная функция или срок выпуска.

## Как поддержать

Доступные суммы и указанные преимущества перечислены в [профиле GitHub Sponsors](https://github.com/sponsors/kenjinote). Платёж, выставление счетов и налогообложение зависят от аккаунта, региона и текущих условий GitHub; перед поддержкой прочитайте [официальную информацию о сборах и налогах](https://docs.github.com/en/sponsors/sponsoring-open-source-contributors/about-sponsorships-fees-and-taxes).

[Поддержать kenjinote на GitHub Sponsors](https://github.com/sponsors/kenjinote)

Спасибо, что рассматриваете возможность поддержать мою работу.
