# Windowsエクスプローラーを再起動する方法

デスクトップやタスクバーの反応が止まったときは、Windowsのシェルであるエクスプローラー（explorer.exe）を再起動すると改善することがあります。Windows 10/11では、プロセスを強制終了するより、タスクマネージャーの「再起動」を使う方法が簡単です。画面の項目名はWindowsのバージョンや表示言語で異なることがあります。

## タスクマネージャーから再起動する

1. `Ctrl` + `Shift` + `Esc` キーを押してタスクマネージャーを開きます。開けない場合は `Ctrl` + `Alt` + `Delete` を押し、表示された画面からタスクマネージャーを選びます。

2. 「プロセス」タブまたは一覧で `Windows Explorer`（エクスプローラー）を探します。

3. 対象を右クリックし、「再起動」を選びます。デスクトップやタスクバーが一時的に消え、数秒後に戻ることがあります。

## 一覧にない場合は explorer.exe を起動する

1. タスクマネージャーで「新しいタスクを実行」を選びます。Windows 10など一部の画面では、メニューの「ファイル」から同じ項目を開きます。

2. `explorer.exe` と入力し、「OK」または `Enter` を押します。

通常は上の「再起動」を使ってください。エクスプローラーを終了すると、デスクトップやタスクバーが一時的に表示されなくなる場合があります。
