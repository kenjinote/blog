# 如何重启 Windows 资源管理器

如果桌面或任务栏停止响应，重启 Windows shell 的一部分——资源管理器（explorer.exe）可能会有所帮助。在 Windows 10/11 中，建议使用任务管理器的“重新启动”，而不是强制结束进程。界面名称可能因 Windows 版本和显示语言而异。

## 从任务管理器重新启动

1. 按 `Ctrl` + `Shift` + `Esc` 打开任务管理器。如果无法打开，按 `Ctrl` + `Alt` + `Delete`，然后在出现的界面中选择任务管理器。

2. 在“进程”选项卡或进程列表中找到 `Windows Explorer`（Windows 资源管理器）。

3. 右键单击它并选择“重新启动”。桌面和任务栏可能会短暂消失，然后重新出现。

## 列表中没有时启动 explorer.exe

1. 在任务管理器中选择“运行新任务”。某些 Windows 10 界面中，可以从“文件”菜单打开此项。

2. 输入 `explorer.exe`，然后按 `Enter` 或选择“确定”。

如果有“重新启动”选项，请优先使用。结束资源管理器进程后，桌面和任务栏可能会暂时消失。
