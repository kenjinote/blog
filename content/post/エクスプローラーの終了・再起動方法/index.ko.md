# Windows 탐색기 다시 시작하는 방법

바탕 화면이나 작업 표시줄이 응답하지 않으면 Windows 셸의 일부인 Windows 탐색기(explorer.exe)를 다시 시작하면 해결될 수 있습니다. Windows 10/11에서는 프로세스를 강제 종료하기보다 작업 관리자의 다시 시작 기능을 사용하세요. 화면의 항목 이름은 Windows 버전과 표시 언어에 따라 다를 수 있습니다.

## 작업 관리자에서 다시 시작하기

1. `Ctrl` + `Shift` + `Esc`를 눌러 작업 관리자를 엽니다. 열리지 않으면 `Ctrl` + `Alt` + `Delete`를 누른 뒤 표시되는 화면에서 작업 관리자를 선택합니다.

2. 프로세스 탭 또는 프로세스 목록에서 `Windows Explorer`(Windows 탐색기)를 찾습니다.

3. 마우스 오른쪽 버튼을 클릭하고 `다시 시작`을 선택합니다. 바탕 화면과 작업 표시줄이 잠시 사라졌다가 다시 나타날 수 있습니다.

## 목록에 없으면 explorer.exe 실행하기

1. 작업 관리자에서 `새 작업 실행`을 선택합니다. 일부 Windows 10 화면에서는 `파일` 메뉴에서 열 수 있습니다.

2. `explorer.exe`를 입력하고 `Enter` 키를 누르거나 `확인`을 선택합니다.

가능하면 `다시 시작`을 사용하세요. 탐색기 프로세스를 끝내면 바탕 화면과 작업 표시줄이 일시적으로 보이지 않을 수 있습니다.
