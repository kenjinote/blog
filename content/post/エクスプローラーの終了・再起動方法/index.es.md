# Cómo reiniciar el Explorador de Windows

Si el escritorio o la barra de tareas dejan de responder, reiniciar el Explorador de Windows (explorer.exe), que forma parte del shell de Windows, puede ayudar. En Windows 10 y 11, usa la opción Reiniciar del Administrador de tareas en lugar de forzar el cierre del proceso. Los nombres de la interfaz pueden variar según la versión y el idioma.

## Reiniciarlo desde el Administrador de tareas

1. Pulsa `Ctrl` + `Shift` + `Esc` para abrir el Administrador de tareas. Si no funciona, pulsa `Ctrl` + `Alt` + `Supr` y elige Administrador de tareas en la pantalla que aparece.

2. Busca `Windows Explorer` (Explorador de Windows) en la pestaña Procesos o en la lista de procesos.

3. Haz clic derecho y selecciona `Reiniciar`. Es posible que el escritorio y la barra de tareas desaparezcan brevemente y vuelvan a aparecer.

## Si no aparece, inicia explorer.exe

1. En el Administrador de tareas, selecciona `Ejecutar nueva tarea`. En algunas interfaces de Windows 10, se encuentra en el menú `Archivo`.

2. Escribe `explorer.exe` y pulsa `Enter` o selecciona `Aceptar`.

Cuando esté disponible, usa `Reiniciar`. Al finalizar el Explorador, el escritorio y la barra de tareas pueden ocultarse temporalmente.
