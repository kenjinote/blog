# 如何重新啟動 Windows 檔案總管

如果桌面或工作列停止回應，重新啟動 Windows shell 的一部分——檔案總管（explorer.exe）可能有所幫助。在 Windows 10/11 中，建議使用工作管理員的「重新啟動」，不要強制結束程序。介面名稱可能因 Windows 版本與顯示語言而異。

## 從工作管理員重新啟動

1. 按 `Ctrl` + `Shift` + `Esc` 開啟工作管理員。如果無法開啟，按 `Ctrl` + `Alt` + `Delete`，再從出現的畫面選取工作管理員。

2. 在「處理程序」索引標籤或程序清單中找到 `Windows Explorer`（Windows 檔案總管）。

3. 按一下滑鼠右鍵並選取「重新啟動」。桌面與工作列可能會短暫消失，稍後再出現。

## 清單中沒有時啟動 explorer.exe

1. 在工作管理員中選取「執行新工作」。部分 Windows 10 介面可從「檔案」功能表開啟。

2. 輸入 `explorer.exe`，按 `Enter` 或選取「確定」。

如果有「重新啟動」選項，請優先使用。結束檔案總管程序後，桌面與工作列可能會暫時消失。
