# Windows Explorer को पुनरारंभ कैसे करें

यदि डेस्कटॉप या टास्कबार जवाब देना बंद कर दे, तो Windows shell के हिस्से Windows Explorer (explorer.exe) को पुनरारंभ करने से मदद मिल सकती है। Windows 10/11 में प्रक्रिया को बलपूर्वक बंद करने के बजाय Task Manager का Restart विकल्प इस्तेमाल करें। इंटरफ़ेस के नाम Windows संस्करण और प्रदर्शन भाषा के अनुसार बदल सकते हैं।

## Task Manager से पुनरारंभ करें

1. Task Manager खोलने के लिए `Ctrl` + `Shift` + `Esc` दबाएँ। यदि यह काम न करे, तो `Ctrl` + `Alt` + `Delete` दबाकर दिखाई देने वाली स्क्रीन से Task Manager चुनें।

2. Processes टैब या प्रक्रिया सूची में `Windows Explorer` खोजें।

3. उस पर राइट-क्लिक करके `Restart` चुनें। डेस्कटॉप और टास्कबार कुछ क्षण के लिए गायब होकर वापस आ सकते हैं।

## सूची में न हो तो explorer.exe शुरू करें

1. Task Manager में `Run new task` चुनें। Windows 10 के कुछ इंटरफ़ेस में यह `File` मेनू में होता है।

2. `explorer.exe` लिखें और `Enter` दबाएँ या `OK` चुनें।

उपलब्ध होने पर `Restart` का उपयोग करें। Explorer को समाप्त करने पर डेस्कटॉप और टास्कबार अस्थायी रूप से छिप सकते हैं।
