# Hugo क्या है

Hugo एक स्टैटिक साइट जनरेटर है। आप Markdown फ़ाइलों को HTML में परिवर्तित करके एक वेबसाइट बना सकते हैं। Hugo Go भाषा में लिखा गया है और बहुत तेज़ी से काम करता है।

यह ब्लॉग भी Hugo से बनाया गया है।

# Hugo CLI स्थापित करना

Hugo CLI स्थापित करने के लिए, नीचे दिया गया कमांड चलाएँ।

※ यह macOS का एक उदाहरण है। अन्य ऑपरेटिंग सिस्टम के लिए, कृपया आधिकारिक दस्तावेज़ देखें।

```bash
brew install hugo
```

आप इसे Homebrew का उपयोग करके स्थापित कर सकते हैं।

# Hugo कमांड सूची

Hugo में विभिन्न कमांड उपलब्ध हैं। नीचे आमतौर पर उपयोग किए जाने वाले कमांड दिए गए हैं।

## एक नई साइट बनाना

```bash
hugo new site <साइट का नाम>
```

एक नई साइट बनाने का कमांड। `<साइट का नाम>` में, साइट का नाम निर्दिष्ट करें।

## एक नया लेख बनाना

```bash
hugo new <लेख का नाम>.md
```

एक नया लेख बनाने का कमांड। `<लेख का नाम>` में, लेख का नाम निर्दिष्ट करें।

## सर्वर शुरू करना

```bash
hugo server
```

स्थानीय सर्वर शुरू करने का कमांड। इसे `http://localhost:1313` पर एक्सेस किया जा सकता है।

## बिल्ड करना

```bash
hugo
```

साइट को बिल्ड करने का कमांड। HTML फ़ाइलें `public` निर्देशिका (डायरेक्टरी) में उत्पन्न होंगी।

## डिप्लॉय करना

```bash
hugo deploy
```

साइट को डिप्लॉय करने का कमांड। डिप्लॉयमेंट गंतव्य की सेटिंग `config.toml` फ़ाइल में की जाती है।

## लेखों की सूची प्रदर्शित करना

```bash
hugo list all
```

लेखों की सूची प्रदर्शित करने का कमांड।

## सेटिंग्स की जाँच करना

```bash
hugo config
```

सेटिंग्स की जाँच करने का कमांड।

## मदद प्रदर्शित करना

```bash
hugo help
```

मदद प्रदर्शित करने का कमांड।

## संस्करण प्रदर्शित करना

```bash
hugo version
```

संस्करण (वर्जन) प्रदर्शित करने का कमांड।

यह Hugo कमांड की सूची थी। कई अन्य कमांड उपलब्ध हैं, इसलिए कृपया आधिकारिक दस्तावेज़ देखें।
