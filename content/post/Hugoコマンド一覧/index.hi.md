# Hugo क्या है

Hugo एक स्टैटिक साइट जनरेटर है। आप Markdown फ़ाइलों को HTML में परिवर्तित करके एक वेबसाइट बना सकते हैं। Hugo [Go](https://kenji.blog/hi/p/programming-languages-history-paradigm-evolution/) भाषा में लिखा गया है और बहुत तेज़ी से काम करता है।

यह ब्लॉग भी Hugo से बनाया गया है।

# Hugo CLI स्थापित करना

Hugo CLI स्थापित करने के लिए, नीचे दिया गया कमांड चलाएँ।

※ यह macOS का एक उदाहरण है। अन्य ऑपरेटिंग सिस्टम के लिए, कृपया आधिकारिक दस्तावेज़ देखें।

```bash
brew install hugo
```

आप इसे Homebrew का उपयोग करके स्थापित कर सकते हैं।

# Hugo कमांड सूची

Hugo में विभिन्न कमांड उपलब्ध हैं। नीचे आमतौर पर उपयोग किए जाने वाले कमांड दिए गए हैं।

## एक नई साइट बनाना

```bash
hugo new project <site-name>
```

आपके दिए गए नाम से एक नई साइट बनाता है।

## एक नया लेख बनाना

```bash
hugo new content posts/<post-name>.md
```

निर्दिष्ट पथ पर नई सामग्री फ़ाइल बनाता है।

## सर्वर शुरू करना

```bash
hugo server
```

स्थानीय सर्वर शुरू करने का कमांड। इसे `http://localhost:1313` पर एक्सेस किया जा सकता है।

## बिल्ड करना

```bash
hugo
```

साइट को बिल्ड करने का कमांड। HTML फ़ाइलें `public` निर्देशिका (डायरेक्टरी) में उत्पन्न होंगी।

## डिप्लॉय करना

```bash
hugo deploy
```

यह कमांड समर्थित क्लाउड स्टोरेज सेवाओं पर साइट डिप्लॉय करता है। साइट कॉन्फ़िगरेशन के `deployment` सेक्शन में लक्ष्य सेट करें और प्रदाता की CLI से प्रमाणित करें। यह GitHub Pages जैसे किसी भी वेब होस्ट के लिए सामान्य डिप्लॉय कमांड नहीं है। Hugo v0.159.2 और बाद के संस्करणों के लिए Deploy edition आवश्यक है।

## लेखों की सूची प्रदर्शित करना

```bash
hugo list all
```

इसमें ड्राफ़्ट, भविष्य की तारीख वाली और समय-सीमा समाप्त सामग्री सहित सभी सामग्री दिखाई जाती है।

## सेटिंग्स की जाँच करना

```bash
hugo config
```

यह डिफ़ॉल्ट और साइट के लिए कॉन्फ़िगर की गई सेटिंग, दोनों दिखाता है।

## मदद प्रदर्शित करना

```bash
hugo help
```

मदद प्रदर्शित करने का कमांड।

## संस्करण प्रदर्शित करना

```bash
hugo version
```

यह Hugo का संस्करण और रनटाइम परिवेश की जानकारी दिखाता है।


यह Hugo कमांड की सूची थी। कई अन्य कमांड उपलब्ध हैं, इसलिए कृपया आधिकारिक दस्तावेज़ देखें।
