# ما هو Hugo

Hugo هو أحد مولدات المواقع الثابتة. يتيح لك إنشاء مواقع ويب عن طريق تحويل ملفات Markdown إلى HTML. تمت كتابة Hugo بلغة Go ويعمل بسرعة فائقة.

هذه المدونة أيضاً تم إنشاؤها باستخدام Hugo.

# تثبيت واجهة سطر الأوامر (CLI) لـ Hugo

لتثبيت واجهة سطر أوامر Hugo، قم بتشغيل الأمر التالي.

※ هذا مثال لنظام macOS. لأنظمة التشغيل الأخرى، يرجى الرجوع إلى الوثائق الرسمية.

```bash
brew install hugo
```

يمكنك تثبيته باستخدام Homebrew.

# قائمة أوامر Hugo

يوفر Hugo أوامر متنوعة. قمنا بتلخيص الأوامر الأكثر استخداماً أدناه.

## إنشاء موقع جديد

```bash
hugo new site <اسم الموقع>
```

هذا الأمر لإنشاء موقع جديد. في `<اسم الموقع>`، حدد اسم الموقع.

## إنشاء مقال جديد

```bash
hugo new <اسم المقال>.md
```

هذا الأمر لإنشاء مقال جديد. في `<اسم المقال>`، حدد اسم المقال.

## بدء تشغيل الخادم

```bash
hugo server
```

هذا الأمر لتشغيل الخادم المحلي. يمكن الوصول إليه عبر `http://localhost:1313`.

## بناء الموقع

```bash
hugo
```

هذا الأمر لبناء الموقع. سيتم إنشاء ملفات HTML في مجلد `public`.

## النشر

```bash
hugo deploy
```

هذا الأمر لنشر الموقع. يتم تكوين إعدادات النشر في ملف `config.toml`.

## عرض قائمة المقالات

```bash
hugo list all
```

هذا الأمر لعرض قائمة بجميع المقالات.

## التحقق من الإعدادات

```bash
hugo config
```

هذا الأمر للتحقق من الإعدادات.

## عرض المساعدة

```bash
hugo help
```

هذا الأمر لعرض المساعدة.

## عرض الإصدار

```bash
hugo version
```

هذا الأمر لعرض الإصدار.

هذه هي قائمة أوامر Hugo. تتوفر العديد من الأوامر الأخرى، لذا يرجى الرجوع إلى الوثائق الرسمية.
