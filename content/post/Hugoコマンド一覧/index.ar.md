# ما هو Hugo

Hugo هو أحد مولدات المواقع الثابتة. يتيح لك إنشاء مواقع ويب عن طريق تحويل ملفات Markdown إلى HTML. تمت كتابة Hugo بلغة [Go](https://kenji.blog/ar/p/programming-languages-history-paradigm-evolution/) ويعمل بسرعة فائقة.

هذه المدونة أيضاً تم إنشاؤها باستخدام Hugo.

# تثبيت واجهة سطر الأوامر (CLI) لـ Hugo

لتثبيت واجهة سطر أوامر Hugo، قم بتشغيل الأمر التالي.

※ هذا مثال لنظام macOS. لأنظمة التشغيل الأخرى، يرجى الرجوع إلى الوثائق الرسمية.

```bash
brew install hugo
```

يمكنك تثبيته باستخدام Homebrew.

# قائمة أوامر Hugo

يوفر Hugo أوامر متنوعة. قمنا بتلخيص الأوامر الأكثر استخداماً أدناه.

## إنشاء موقع جديد

```bash
hugo new project <site-name>
```

ينشئ موقعاً جديداً بالاسم الذي تحدده.

## إنشاء مقال جديد

```bash
hugo new content posts/<post-name>.md
```

ينشئ ملف محتوى جديداً في المسار المحدد.

## بدء تشغيل الخادم

```bash
hugo server
```

هذا الأمر لتشغيل الخادم المحلي. يمكن الوصول إليه عبر `http://localhost:1313`.

## بناء الموقع

```bash
hugo
```

هذا الأمر لبناء الموقع. سيتم إنشاء ملفات HTML في مجلد `public`.

## النشر

```bash
hugo deploy
```

ينشر هذا الأمر الموقع لدى موفري التخزين السحابي المدعومين. حدّد الوجهة في قسم `deployment` من إعدادات الموقع وسجّل الدخول باستخدام أداة سطر الأوامر الخاصة بالموفر. هذا ليس أمر نشر عامًا لمضيفي الويب مثل GitHub Pages. يتطلب Hugo v0.159.2 والإصدارات الأحدث إصدار Deploy.

## عرض قائمة المقالات

```bash
hugo list all
```

يعرض كل المحتوى، بما في ذلك المسودات والمحتوى المؤرخ للمستقبل والمحتوى منتهي الصلاحية.

## التحقق من الإعدادات

```bash
hugo config
```

يعرض الإعدادات الافتراضية والإعدادات المحددة للموقع.

## عرض المساعدة

```bash
hugo help
```

هذا الأمر لعرض المساعدة.

## عرض الإصدار

```bash
hugo version
```

يعرض إصدار Hugo ومعلومات بيئة التشغيل.


هذه هي قائمة أوامر Hugo. تتوفر العديد من الأوامر الأخرى، لذا يرجى الرجوع إلى الوثائق الرسمية.
