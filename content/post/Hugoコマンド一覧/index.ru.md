# Что такое Hugo

Hugo — это генератор статических сайтов. Он позволяет создавать веб-сайты, преобразуя файлы Markdown в HTML. Hugo написан на языке [Go](https://kenji.blog/ru/p/programming-languages-history-paradigm-evolution/) и работает очень быстро.

Этот блог также создан с помощью Hugo.

# Установка CLI Hugo

Чтобы установить CLI Hugo, выполните следующую команду.

※ Это пример для macOS. Для других ОС, пожалуйста, обратитесь к официальной документации.

```bash
brew install hugo
```

Вы можете установить его с помощью Homebrew.

# Список команд Hugo

Hugo предлагает различные команды. Ниже приведены наиболее часто используемые команды.

## Создать новый сайт

```bash
hugo new project <site-name>
```

Создает новый сайт с указанным именем.

## Создать новую статью

```bash
hugo new content posts/<post-name>.md
```

Создает новый файл контента по указанному пути.

## Запустить сервер

```bash
hugo server
```

Команда для запуска локального сервера. Вы можете получить к нему доступ по адресу `http://localhost:1313`.

## Сборка сайта

```bash
hugo
```

Команда для сборки сайта. HTML-файлы будут сгенерированы в директории `public`.

## Развертывание

```bash
hugo deploy
```

Эта команда размещает сайт в поддерживаемых облачных хранилищах. Укажите цель в разделе `deployment` конфигурации сайта и выполните вход через CLI провайдера. Это не универсальная команда для любого веб-хостинга, например GitHub Pages. В Hugo v0.159.2 и более поздних версиях требуется редакция Deploy.

## Показать список статей

```bash
hugo list all
```

Выводит весь контент, включая черновики, материалы с будущей датой публикации и просроченные материалы.

## Проверка конфигурации

```bash
hugo config
```

Показывает настройки по умолчанию и параметры, заданные для сайта.

## Показать справку

```bash
hugo help
```

Команда для отображения справки.

## Показать версию

```bash
hugo version
```

Показывает версию Hugo и сведения о среде выполнения.


На этом список команд Hugo завершен. Существует множество других команд, поэтому, пожалуйста, обратитесь к официальной документации.
