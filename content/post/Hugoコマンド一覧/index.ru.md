# Что такое Hugo

Hugo — это генератор статических сайтов. Он позволяет создавать веб-сайты, преобразуя файлы Markdown в HTML. Hugo написан на языке Go и работает очень быстро.

Этот блог также создан с помощью Hugo.

# Установка CLI Hugo

Чтобы установить CLI Hugo, выполните следующую команду.

※ Это пример для macOS. Для других ОС, пожалуйста, обратитесь к официальной документации.

```bash
brew install hugo
```

Вы можете установить его с помощью Homebrew.

# Список команд Hugo

Hugo предлагает различные команды. Ниже приведены наиболее часто используемые команды.

## Создать новый сайт

```bash
hugo new site <Имя сайта>
```

Команда для создания нового сайта. Вместо `<Имя сайта>` укажите название вашего сайта.

## Создать новую статью

```bash
hugo new <Имя статьи>.md
```

Команда для создания новой статьи. Вместо `<Имя статьи>` укажите название вашей статьи.

## Запустить сервер

```bash
hugo server
```

Команда для запуска локального сервера. Вы можете получить к нему доступ по адресу `http://localhost:1313`.

## Сборка сайта

```bash
hugo
```

Команда для сборки сайта. HTML-файлы будут сгенерированы в директории `public`.

## Развертывание

```bash
hugo deploy
```

Команда для развертывания сайта. Настройки развертывания выполняются в файле `config.toml`.

## Показать список статей

```bash
hugo list all
```

Команда для отображения списка статей.

## Проверка конфигурации

```bash
hugo config
```

Команда для проверки конфигурации.

## Показать справку

```bash
hugo help
```

Команда для отображения справки.

## Показать версию

```bash
hugo version
```

Команда для отображения версии.

На этом список команд Hugo завершен. Существует множество других команд, поэтому, пожалуйста, обратитесь к официальной документации.
