# 前言

我使用的是美式鍵盤，在 Windows 上我使用 `` Alt + ` `` 來切換日文輸入。
我想在 Mac 上也使用相同的按鍵進行切換，經過一番查詢，我發現可以在設定中進行更改。

# 設定方法 (macOS Ventura)

1. 打開系統設定
2. 選擇「鍵盤」
3. 選擇「鍵盤快速鍵」
4. 選擇「輸入方式」
5. 雙擊「選擇輸入選單中的下一個來源」右側的快速鍵顯示
6. 輸入 `` Alt + ` ``
7. 點擊完成

現在，您可以使用 `` Alt + ` `` 在英文與日文之間進行切換。
不過，預設情況下，片假名會包含在切換選項中，因此我按照以下步驟從輸入來源中移除了片假名。

1. 打開系統設定
2. 選擇「鍵盤」
3. 點擊輸入方式中 `日文 - 羅馬字輸入` 右側的編輯
4. 點擊 `日文 - 羅馬字輸入`
5. 取消勾選輸入模式中的片假名
6. 點擊完成
