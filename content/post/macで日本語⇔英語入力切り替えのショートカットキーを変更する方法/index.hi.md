# परिचय

मैं US कीबोर्ड का उपयोग करता हूं, और Windows पर मैं `` Alt + ` `` के साथ जापानी इनपुट स्विच करता हूं।
मैं Mac पर भी उसी कुंजी के साथ स्विच करना चाहता था, और शोध करने पर मुझे पता चला कि इसे सेटिंग्स में बदला जा सकता है।

# सेटिंग विधि (macOS Ventura)

1. सिस्टम सेटिंग्स खोलें
2. कीबोर्ड चुनें
3. कीबोर्ड शॉर्टकट चुनें
4. इनपुट स्रोत चुनें
5. इनपुट मेनू में अगले स्रोत का चयन करें के दाईं ओर शॉर्टकट डिस्प्ले पर डबल-क्लिक करें
6. `` Alt + ` `` टाइप करें
7. संपन्न पर क्लिक करें

अब, आप अंग्रेजी ⇔ जापानी को `` Alt + ` `` के साथ स्विच कर सकते हैं।
हालाँकि, डिफ़ॉल्ट रूप से, कटकाना स्विचिंग में शामिल हो जाता है, इसलिए मैंने नीचे दिए गए चरणों का पालन करके इनपुट स्रोत से कटकाना को हटा दिया।

1. सिस्टम सेटिंग्स खोलें
2. कीबोर्ड चुनें
3. इनपुट स्रोतों में `जापानी - रोमाजी इनपुट` के दाईं ओर स्थित संपादित करें पर क्लिक करें
4. `जापानी - रोमाजी इनपुट` पर क्लिक करें
5. इनपुट मोड में कटकाना को अनचेक करें
6. संपन्न पर क्लिक करें
