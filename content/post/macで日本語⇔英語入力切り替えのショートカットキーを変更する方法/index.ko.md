# 시작하며

저는 US 키보드를 사용하고 있어서, Windows에서는 `` Alt + ` ``로 일본어 입력을 전환하는데
mac에서도 같은 키로 전환하고 싶어서 찾아보니 설정에서 변경할 수 있다는 것을 알았습니다.

# 설정 방법 (macOS Ventura)

1. 시스템 설정을 엽니다.
2. 키보드를 선택합니다.
3. 키보드 단축키를 선택합니다.
4. 입력 소스를 선택합니다.
5. '입력 메뉴에서 다음 소스 선택' 오른쪽의 단축키 표기를 더블 클릭합니다.
6. `` Alt + ` ``를 입력합니다.
7. 완료를 클릭합니다.

이제 영어 ⇔ 일본어를 `` Alt + ` ``로 전환할 수 있게 됩니다.
다만, 기본 설정으로는 전환 중에 가타카나가 포함되어 버리므로, 아래 절차에 따라 입력 소스에서 가타카나를 삭제했습니다.

1. 시스템 설정을 엽니다.
2. 키보드를 선택합니다.
3. 입력 소스 중 '일본어 - 로마자 입력' 오른쪽의 편집을 클릭합니다.
4. '일본어 - 로마자 입력'을 클릭합니다.
5. 입력 모드 중 가타카나의 체크를 해제합니다.
6. 완료를 클릭합니다.
