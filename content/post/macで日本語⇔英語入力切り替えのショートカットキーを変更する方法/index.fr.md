# Introduction

J'utilise un clavier américain (US) et sur Windows, je bascule la saisie japonaise avec `` Alt + ` ``.
Je voulais basculer avec la même touche sur Mac, et après quelques recherches, j'ai découvert qu'il était possible de le changer dans les paramètres.

# Méthode de configuration (macOS Ventura)

1. Ouvrez les Réglages Système
2. Sélectionnez Clavier
3. Sélectionnez Raccourcis clavier
4. Sélectionnez Sources de saisie
5. Double-cliquez sur l'affichage du raccourci à droite de "Sélectionner la source suivante dans le menu de saisie"
6. Appuyez sur `` Alt + ` ``
7. Cliquez sur Terminé

Désormais, vous pouvez basculer entre l'anglais ⇔ et le japonais avec `` Alt + ` ``.
Cependant, par défaut, le Katakana est inclus dans le basculement, j'ai donc supprimé le Katakana de la source de saisie en suivant les étapes ci-dessous.

1. Ouvrez les Réglages Système
2. Sélectionnez Clavier
3. Cliquez sur Modifier à droite de `Japonais - Romaji` dans les sources de saisie
4. Cliquez sur `Japonais - Romaji`
5. Décochez la case Katakana dans le Mode de saisie
6. Cliquez sur Terminé

C'est tout
