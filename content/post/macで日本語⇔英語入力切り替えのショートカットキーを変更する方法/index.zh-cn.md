# 前言

我使用的是美式（US）键盘，在Windows上我使用 `` Alt + ` `` 来切换日语输入，
我想在Mac上也使用同样的键进行切换，经过一番查找后，发现可以通过设置来更改。

# 设置方法(macOS Ventura)

1. 打开“系统设置”
2. 选择“键盘”
3. 选择“键盘快捷键”
4. 选择“输入法”
5. 双击“选择输入菜单中的下一个输入法”右侧的快捷键
6. 输入 `` Alt + ` ``
7. 点击“完成”

这样，就可以使用 `` Alt + ` `` 来切换英语 ⇔ 日语了。
不过，默认情况下切换选项中会包含片假名，因此我通过以下步骤从输入法中移除了片假名。

1. 打开“系统设置”
2. 选择“键盘”
3. 点击输入法中`日语 - 罗马音输入`右侧的“编辑”
4. 点击`日语 - 罗马音输入`
5. 取消勾选输入模式中的“片假名”
6. 点击“完成”
