# Macで日本語・英語の入力切替ショートカットを変更する方法

MacのUSキーボードで日本語と英語を切り替えるショートカットは、システム設定から変更できます。macOS Ventura以降は「システム設定」、それ以前は「システム環境設定」と表示されます。MacのキーボードではWindowsのAltキーに相当するキーはOption（⌥）です。外付けキーボードでは刻印や割り当てが異なることがあります。

## 入力ソース切替のキーを変更する

1. Appleメニューから「システム設定」を開き、「キーボード」を選びます。

2. 「キーボードショートカット」を開き、「入力ソース」を選びます。

3. 「入力メニューの次のソースを選択」のショートカット欄をダブルクリックし、設定したいキーの組み合わせを押します。例としてOption + `を試せますが、キーボード配列や他のショートカットとの競合によって使えない場合があります。

4. 「完了」をクリックします。

## 日本語と英語だけを切り替える

1. 入力ソースの切替は、入力メニューに登録したソース間を移動します。Appleの標準設定ではControl + Spaceで直前の入力ソース、Control + Option + Spaceで次の入力ソースを選べます。割り当ては設定で確認してください。

2. 切替時に複数の日本語ソースが表示される場合は、「キーボード」>「テキスト入力」>「編集」を開き、使わない入力ソース（例：日本語 - かな）だけを削除します。日本語 - ローマ字入力は残します。

入力ソース（英語、日本語 - ローマ字入力など）と、日本語入力ソース内の入力モード（ひらがな、カタカナなど）は別の設定です。カタカナを入力モードから外すと、カタカナへの変換方法が制限されます。切替一覧から日本語の種類を減らしたい場合は、入力モードではなく不要な入力ソースを削除してください。
