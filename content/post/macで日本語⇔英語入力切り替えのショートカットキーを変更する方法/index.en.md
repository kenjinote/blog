# Change the Japanese–English Input Shortcut on Mac

You can change the shortcut for switching between Japanese and English input sources in Settings. macOS Ventura and later call this app System Settings; earlier versions call it System Preferences. On an Apple keyboard, the key corresponding to the Windows Alt key is Option (⌥). External keyboards may use different labels or mappings.

## Change the input-source shortcut

1. Open the Apple menu, choose `System Settings`, then select `Keyboard`.

2. Open `Keyboard Shortcuts` and select `Input Sources`.

3. Double-click the shortcut next to `Select the next source in the Input menu`, then press the key combination you want. You can try Option + `, but the combination may be unavailable because of your keyboard layout or a shortcut conflict.

4. Click `Done`.

## Switch only between Japanese and English

1. The input-source shortcut moves among the sources in your Input menu. Apple’s defaults are Control + Space for the last-used source and Control + Option + Space for the next source. Check the current assignments in Settings.

2. If several Japanese sources appear while switching, open `Keyboard` > `Text Input` > `Edit` and remove only the source you do not use (for example, Japanese - Kana). Keep Japanese - Romaji if you type Japanese with a US keyboard.

An input source (such as English or Japanese - Romaji) is different from an input mode inside the Japanese source (such as Hiragana or Katakana). Disabling Katakana as an input mode limits how you can enter Katakana. To shorten the switching list, remove an unwanted input source instead.
