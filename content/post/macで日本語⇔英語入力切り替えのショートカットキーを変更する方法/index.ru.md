# Как изменить сочетание клавиш для переключения японского и английского ввода на Mac

Сочетание клавиш для переключения между японским и английским источниками ввода можно изменить в настройках. Начиная с macOS Ventura приложение называется «Системные настройки», в более ранних версиях — «Системные настройки» (System Preferences). На клавиатуре Apple клавише Alt в Windows соответствует Option (⌥). У внешних клавиатур обозначения и назначение могут отличаться.

## Изменение сочетания клавиш источника ввода

1. Откройте меню Apple, выберите `System Settings`, затем `Keyboard`.

2. Откройте `Keyboard Shortcuts` и выберите `Input Sources`.

3. Дважды щёлкните сочетание рядом с `Select the next source in the Input menu` и нажмите нужную комбинацию. Можно попробовать Option + `, но раскладка клавиатуры или конфликт с другим сочетанием могут помешать.

4. Нажмите `Done`.

## Переключение только между японским и английским

1. Сочетание переключает источники, добавленные в меню ввода. По умолчанию Control + Space выбирает последний использованный источник, а Control + Option + Space — следующий. Проверьте текущие назначения в настройках.

2. Если при переключении отображается несколько японских источников, откройте `Keyboard` > `Text Input` > `Edit` и удалите только неиспользуемый источник (например, Japanese - Kana). Оставьте Japanese - Romaji, если вводите японский на клавиатуре US.

Источник ввода (например, английский или Japanese - Romaji) отличается от режима внутри японского источника (например, хирагана или катакана). Отключение режима катаканы ограничит способы её ввода. Чтобы сократить список переключения, удалите лишний источник ввода, а не режим.
