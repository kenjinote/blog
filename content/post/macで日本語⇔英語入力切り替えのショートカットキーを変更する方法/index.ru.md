# Введение

Я использую американскую клавиатуру (US), и в Windows я переключаюсь на японский ввод с помощью `` Alt + ` ``.
Я хотел переключаться с помощью той же клавиши на mac, и, поискав, я обнаружил, что это можно изменить в настройках.

# Как настроить (macOS Ventura)

1. Откройте Системные настройки
2. Выберите Клавиатура
3. Выберите Сочетания клавиш
4. Выберите Источники ввода
5. Дважды щелкните по обозначению сочетания клавиш справа от "Выбрать следующий источник в меню ввода"
6. Введите `` Alt + ` ``
7. Нажмите Готово

Теперь вы сможете переключаться между английским ⇔ японским с помощью `` Alt + ` ``.
Однако по умолчанию катакана включена в переключение, поэтому я удалил катакану из источников ввода, выполнив следующие действия.

1. Откройте Системные настройки
2. Выберите Клавиатура
3. Нажмите "Изменить" справа от `Японский - Ввод ромадзи` в источниках ввода
4. Нажмите `Японский - Ввод ромадзи`
5. Снимите флажок "Катакана" в режимах ввода
6. Нажмите Готово

На этом все
